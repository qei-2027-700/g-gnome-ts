# 既存任務の地図を原作に合わせる

このフォルダから `../../..` がリポジトリのルート。対応規則は [任務地図とウェイポイント](../../../docs/gameplay/mission-map-and-waypoints.md) の「原作地図との対応」。このスキルは是正の順番だけを持つ。新しい任務を作るとき、または配置変更で新たにずらさないときは [gnome-mission-authoring](../gnome-mission-authoring/SKILL.md)。機体の見た目は [gnome-model-match](../gnome-model-match/SKILL.md)。

## 対象を一つ決める

1. ユーザーが任務を指定していれば、その任務だけを対象にする。指定がなければ、原作画像があり、任務資料が未一致または仮値と書いている任務を挙げ、一つに決めてから直す。
2. その任務の `docs/missions/`、引用されている原作画像、`src/game/content/missions/mission-<番号>.ts` の地形・開始位置・橋・施設だけを見る。武器、機体性能、敵の攻撃は変えない。
3. 座標から描く地図か、原作画像を貼る地図かを、対応規則の表で区別する。

## 見えたずれだけを書く

原作画像と現行の配置を比べ、差を5項目以内で書く。各項目は「関係 / 原作 / 現行」。画像に写っていない位置や、縮尺のないメートルは足さない。添付が無い画像は未確認のままにする。

## その差だけ直す

- 地形、開始位置、橋、施設、地図の切り出し、現在地の対応だけを変える。
- 原作画像を貼る任務では、開始前に見えている範囲と任務中に見えている範囲を、その画像の同じ目印へ合わせる。他任務の比率を流用しない。
- 尾根を矩形の崖のまま残すときは、任務資料に近似であることを残す。崖を増やすときは [密集した障害物と更新コスト](../../../docs/technical/simulation-cost.md) に従う。
- 直した関係を、その任務の既存テストへ追加する。新しいテストファイルは作らない。
- 対象以外の任務の配置は動かさない。

## 確認

影響する既存テストだけを実行する。合わせた関係と、仮のままの縮尺を任務資料に短く残す。任務ごとの座標や縮尺をこのスキルへ書かない。実ブラウザで地図を見ていなければ、未確認と報告する。
