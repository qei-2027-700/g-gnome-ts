# 既存任務の地図を原作に合わせる

このフォルダから `../../..` がリポジトリのルート。対応規則は [任務地図とウェイポイント](../../../docs/gameplay/mission-map-and-waypoints.md#原作画像からフィールドまでの対応手順)。このスキルは是正の順番だけを持つ。新しい任務を作るとき、または配置変更で新たにずらさないときは [gnome-mission-authoring](../gnome-mission-authoring/SKILL.md)。機体の見た目は [gnome-model-match](../gnome-model-match/SKILL.md)。

## 対象を一つ決める

1. ユーザーが任務を指定していれば、その任務だけを対象にする。指定がなければ、原作画像があり、任務資料が未一致または仮値と書いている任務を挙げ、一つに決めてから直す。
2. その任務の `docs/missions/`、引用されている原作画像、`src/game/content/missions/mission-<番号>.ts` の地形・開始位置・橋・施設だけを見る。武器、機体性能、敵の攻撃は変えない。
3. 座標から描く地図か、原作画像を貼る地図かを、対応規則の表で区別する。任務資料に元画像の画素位置・切り出し範囲・方位・縮尺・対応点があれば再利用し、欠けているものは原作画像から確認できる範囲で記録する。

## 見えたずれだけを書く

原作画像と現行の配置を比べ、差を5項目以内で書く。各項目は「目印・色領域・輪郭 / 原作画像の画素位置 / 地形の種類と通行可否 / 現行の任務座標と表示・判定 / 見えた差」。川だけでなく、色が分かれる平地と山・斜面の境界、通路、橋、施設、開始位置のうち画像に見えるものを優先する。色の明暗だけで通行可否を決めず、根拠がない領域は未確認とする。画像に写っていない位置や、縮尺のないメートルは足さない。添付が無い画像は未確認のままにする。

## その差だけ直す

- 地形、開始位置、橋、施設、地図の切り出し、現在地の対応だけを変える。色領域の通行境界と画素・任務座標の対応点、向き、仮の縮尺を一緒に更新し、川だけ、山だけに別の倍率を使わない。
- 原作画像を貼る任務では、開始前に見えている範囲と任務中に見えている範囲を、その画像の同じ目印へ合わせる。他任務の比率を流用しない。
- 尾根を矩形の崖のまま残すときは、任務資料に近似であることを残す。崖を増やすときは [密集した障害物と更新コスト](../../../docs/technical/simulation-cost.md) に従う。
- 直した関係を、その任務の既存テストへ追加する。新しいテストファイルは作らない。
- 対象以外の任務の配置は動かさない。

## 確認

影響する既存テストだけを実行する。原作画像、座標から描く地図、実ブラウザの3D表示を同じ目印と色領域の境界で照合する。平地を通れ、山・斜面へ入れず、境界沿いの経路を進めることも確認する。合わせた関係、画素と任務座標の対応、残る輪郭差と仮の縮尺を任務資料に残す。任務ごとの座標や縮尺をこのスキルへ書かない。実ブラウザで地図やフィールドを見ていなければ、その範囲を未確認と報告する。
