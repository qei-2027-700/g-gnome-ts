# 外観・ホログラム・動きの再現

前面・側面・後面・機内からの目視を、同じ機種か確認してから組み合わせる。手がかりは部位の輪郭、幅と高さの比、砲口の位置、脚・履帯・支柱の配置。以下のパスはリポジトリのルート基準。

## 共有寸法から形状を作る

胴体、コックピット、武装、脚・支持材の主要寸法は`src/game/content/vehicle-shapes.ts`を基準にする。機体の高さ・性能・所属は`src/game/content/vehicles.ts`と対応する資料を照合する。透視による見かけの大きさだけで、原作の実寸や性能値を変えない。

`src/game/presentation/renderer.ts`の対応する機種へ形状と配色を反映する。モデルの基準点、地面からの高さ、前方軸、車体と上半身の親子関係を既存機種と照合する。固定の支柱・台座と、旋回する砲塔を分け、砲身だけ上下する場合も対応する節へ接続する。

新規機種では外観だけを加えて終わらず、型・機体定義・共有形状・生成分岐・乗降時の表示・必要な索引を接続する。性能が未確認なら既存の同系統から補った値を仮設定として記録する。別勢力の同名設備を同じモデルで代用する前にユーザー指定と資料を確認する。

## 見た目と戦闘の位置を合わせる

| 対象 | 合わせる内容 |
| --- | --- |
| 部位の描画と損傷 | 装飾を含むメッシュを対応する部位へ割り当てる。破損色・発煙・破壊で別部位へ波及させない |
| 命中領域 | `src/game/simulation/parts.ts`で共有寸法を使い、胴体・頭部・武装・脚の新しい位置に対応させる |
| 砲口 | モデルと発射位置を同じ寸法から求める。車体・砲塔の旋回と上下照準でも位置を合わせる |
| ホログラム | `src/game/presentation/hologram.ts`の自機と目標へ輪郭を反映し、部位ごとの損傷色を保つ |
| 地面・接触 | 足先・履帯・支柱の接地と、施設や他機体への接触距離を確認する |

細部を増やす場合も、既存の部位別耐久・発射枠・機種識別を保つ。資料が示す部位と命中領域の対応に粗い近似を使う場合は、その範囲を記録する。

## 動きの資料を扱う

静止画からは関節の位置と到達姿勢を読み、速度・歩行周期を実測済みとは扱わない。ユーザーが指定した「脚だけ振る」「胴体は傾けない」「浮遊中に上下する」などを対象の部位に反映する。

歩行は移動距離・速度と同期させ、停止時は必要に応じて元の姿勢へ収める。接地中の足、持ち上げる足、股・膝の接続を確認する。脚を横へ動かす指定を、胴体の横揺れだけで満たしたと判断しない。

`src/game/presentation/locomotion.ts`と描画側の更新処理で調整し、旋回・歩行・浮遊と、照準や反動による姿勢変化の重なりを見る。外観のために実移動や武器性能を変えない。機内の揺れも指定された場合は、外観の動きと分けて接続・検証する。

## 外観に固有の確認

共有寸法・部位を変えたら、変更部位への命中、旋回後の命中位置、砲口、損傷表示から必要な条件を選ぶ。旧座標を使うテストは新しい共有寸法に照らして更新し、単に失敗を消すために判定を緩めない。

実ブラウザで機体全体が分かる視点を取り、資料の方向から輪郭・比率・配色を見る。側面や背面、歩行や射撃など、今回変えた部分が分かる状態も確認する。構造テストの成功を、画像どおりの外観を確認した証拠にはしない。
