# 武器の威力と弾の表現を変える

このスキルの配置先から `../../..` がG-Nomeのルート。[AGENTS.md](../../../AGENTS.md) に従う。性能の正本は [武器仕様](../../../docs/gameplay/weapons-and-missile-camera.md) と `src/game/content/weapons.ts`。数値をこのスキルへ複製しない。

## 変える場所

| 依頼 | 編集する場所 |
| --- | --- |
| 威力・射程・最小射程・充填・発射間隔・エネルギー・弾速 | `src/game/content/weapons.ts` の `LASERS`・`MACHINE_GUNS`・`MISSILES` |
| どの機体が持つか、砲門数 | `src/game/content/vehicles.ts` と `weaponMountCount` |
| 任務だけの性能差 | その任務の `weaponOverrides`。共通定義の初期値は維持する |
| 弾の形・色・銃口・着弾 | `src/game/presentation/renderer.ts` |
| 発射音の波形 | `src/game/presentation/weapon-fire-audio.ts`。その他の発射音は `src/game/presentation/audio.ts` と `assets/audio/sfx/` も確認する |
| 発射音の選択・再生・音量・距離減衰 | `src/game/presentation/audio.ts` |

`simulation.ts` の `fireLaser` は武器定義の `damage` を弾へ写すだけである。威力の調整で、そこへ倍率や武器別の分岐を足さない。

## 共有している表現

見た目・音・速さを共有する組は、仕様とコードの定数を読んでから片方だけを変えない。色だけ分かれる組は、色の定数だけを分ける。現在の組と定数名は武器仕様の共通レーザー表現に従う。

共有定数を変えるときは、その定数を使う武器がすべて変わることを確認する。威力・射程・充填・発射間隔は、見た目を共有していても武器ごとに残す。見た目だけの依頼で威力を変えず、威力だけの依頼で形や音を変えない。

## 発射音を原作へ近づける

[音声資料](../../../docs/audio/mission-controls-and-audio.md#聴感ごとの発射音2026-11-10)にある聴感名は、原作音源の代わりにはならない。原作との一致を求められたら、対象の武器IDと、それを発射していると確認できる原作の動画・録音の時刻を対応づける。別の武器、着弾音、BGMや台詞が重なる区間を根拠に音色を決めない。参照音が確認できない場合は、試作調整と明記し、一致したとは報告しない。

参照音と現行音を同じ再生条件で聴き比べ、発射の立ち上がり、長さ、音程の動き、低音とノイズ、連射時の間隔から、聞き取れた差を記録する。原作を聴いて特徴を捉え、合成音で再現する方法を選べる。波形やスペクトルは判断の補助に使い、実ブラウザで試聴して差を確認する。合成で再現しにくい場合は、利用できる原作音源を加工する方法も検討する。音源の権利や配布条件が未確認なら、同梱可能とは扱わない。

修正時は既存の武器IDと聴感の共有関係を保ち、発射音以外の性能や着弾音を変えない。参照箇所、確認できた差、変更内容、試聴結果、未確認点を音声資料へ残す。

## 検証

変更した武器の既存テストを更新して実行する。発射音を変えたときは、武器IDの選択、共有する音、音量・距離減衰、一時停止に関係する既存テストを選ぶ。速さや命中タイミングを変えたときは、飛翔後に当たるテストの待ち時間も合わせる。描画の共有寸法を変えたときは `renderer.test.ts` の当該武器も実行する。

実ブラウザの色・音は未確認なら、その旨を報告する。仕様の変更は `docs/gameplay/weapons-and-missile-camera.md` へ反映する。
