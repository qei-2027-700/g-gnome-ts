# 原作プレイ動画からSEを切り出して再利用する手順

原作動画の発射音・命中音・破壊音などを、ゲーム内で繰り返し使える素材として採集する。動画内の時刻だけで短い音を決め打ちすると、別のSE、BGM、台詞を拾いやすい。[4-5の観察記録](../reference/observations/mission-4-5/observations.md)では、HAWC破壊音はユーザーが採用した一方、VISOMは男性の声が入り、P2MECとTCREAPは狙った音を拾えていなかった。音声を切り出せたことと、対象SEを採集できたことを分けて扱う。

## 採集する前に

1. 出典URL、任務、動画の版・言語、動画内の候補時刻を記録する。映像でHUDの武器名、選択スロット、残弾・充填の変化、弾道、着弾・破壊の瞬間を確認する。映像から武器が確定しない場合は候補とする。
2. 元の動画ファイルと音声を残す。全編MP3は時刻を探すために使えるが、切り出しは可能なら元の動画音声から行い、MP3の再圧縮を重ねない。動画時刻をゲーム内の経過時間と混同しない。
3. 候補の前後を数秒ずつ聴き、狙う音の開始・終了、同時に鳴る台詞・BGM・別のSEを記録する。短い断片を先に決めず、前・中心・後の比較から範囲を狭める。波形やスペクトルは時刻探しの補助とし、聴感の代わりにしない。試聴できない環境なら、音色・分離の成否を確認済みとせず、人の試聴結果を待つ。

## 切り出しと採否

候補区間からWAVを切り出し、元の動画と比べながら端を調整する。たとえば次のコマンドは、元動画の指定秒から指定秒数を44.1kHzのWAVに保存する。開始秒と長さは、実際に聴いて決める。

```sh
ffmpeg -ss <開始秒> -i <元動画.mp4> -t <長さ秒> -vn -c:a pcm_s16le -ar 44100 -ac 1 <候補.wav>
```

採用前に、単体再生と連続再生で次を確かめる。

- 目的の武器・イベントの音が入り、声や別の武器音を対象SEとして取り込んでいない。
- 音の立ち上がりと余韻が切れていない。繰り返すとBGMや環境音が不自然に反復しない。
- 複数回鳴らしたときの音量と間隔が適切で、クリップや破綻がない。ゲーム内でもSE音量、距離減衰、一時停止、同時発音を確認する。
- 録画に音が重なって分離しきれない場合は、同じ武器の別場面を探す。音源分離やフィルターを試す場合も、処理後の音を試聴して採否を決める。混合音声を単独SEと呼ばない。

## ゲームへ接続する

切り出し時刻、元URL、対象の武器IDまたはイベント、加工内容、試聴結果、採否を観察記録へ残す。武器の発射・飛翔・命中、機体の被弾・破壊は別の音として対応づける。聴感が似ていても、別武器へ共有する前に原作の使用関係を確認する。

採用した音だけを再生処理へつなぎ、従来の合成音や素材は残す。素材が読めない場合の代替音、音量設定、距離減衰、一時停止、連射時の重なりを検証する。ローカルでの試聴素材と、リポジトリに同梱する素材を区別する。原作動画から切り出した音源は、権利と配布条件を確認するまで配布可能と扱わない。

4-5の元動画、全編MP3、候補WAV、試聴用の時刻を含む個別の結果は[観察記録](../reference/observations/mission-4-5/observations.md)に置く。共通の音色・再生処理は[ミッション中断と音の制作方針](mission-controls-and-audio.md)を参照する。
