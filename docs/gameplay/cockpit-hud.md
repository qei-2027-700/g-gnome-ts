## 表示機能

| 表示 | マニュアルで確認した仕様 |
| --- | --- |
| 武器パネル | 最大4種類。1は左上、2は左下、3は右上、4は右下。エネルギー武器は充填状況、弾薬武器は残弾数を表示 |
| 武器のReady Light | 選択した目標がその武器の射程内なら緑、それ以外は赤。武器の充填表示とは分ける |
| 目標表示 | 選択目標が画面内なら追従する黄色の照準、画面外なら左右の方向矢印 |
| 中央のTarget Cursor | 目標を見ていれば黄色、ロック時は赤と距離表示。選択とロックを同一にしない |
| Pitch Indicator | 武器の上下角。機体そのものの向きとは分ける |
| Heading Indicator | 機体の進行方向は緑、見ている方向は黄。胴体をひねっていなければ重なる |
| Throttle Indicator | 黒線が指令速度、黄色のバーが実速度。速度を1つの値にまとめない |
| 自機Holo | 右側。機種・エネルギー・シールド・部位の損傷状態を表示 |
| 目標Holo | 左側。選択対象のシールドと部位の損傷を表示 |
| Radar | 味方は緑、敵は赤、無人機は青、選択目標は黄。ウェイポイントも表示 |
| Ping Light | 敵が自機を狙っているときに赤く点滅。被弾した瞬間だけの表示とは別 |
| IFF | 4桁の8進数。配置は機体により異なる |

IFFは表示するだけでなく、敵味方の認識、通信、任務の進行へ反映する。レーダーとAIは同じ識別結果を参照し、選択目標の黄色と友軍判定を分ける。[IFF・通信仕様](iff-and-communications.md)を参照。

シールド・部位の状態には緑・黄・赤が使われるが、色が変わる数値の境界は未確認。エネルギー容量、残弾、充填、シールド、装甲、内部系統をそれぞれ別の状態として表示に渡す。

## レーダーの細部とキー

マニュアルではHAWC、塔、建物、歩兵、ウェイポイントを異なる記号で表す。ウェイポイントは平行な2本線。歩兵は武器の再充填中に点として映るという説明があり、常時表示するかどうかを実機で確認する。

原作マニュアル上、Xはレーダー縮小、Zは拡大。範囲の数値と段階、歩兵状態での利用、範囲外の扱いは照合する。Zについて外部カメラ操作とする攻略資料の記述もあるため、製品版・設定プリセットごとの対応を確認する。マニュアルのキーとWeb版の案を混同しない。

## 原作の資源・損傷と表示

指令速度と実速度、シールドとエネルギーを分ける。マニュアルには移動・シールド生成・武器充填がエネルギー配分に関係し、減速で武器の再充填が速くなるとの説明がある。正確な配分式は未確認。

部位損傷は見た目だけでなく、武器・レーダー・通信・シールド生成・推進などの機能へ影響する。全体HPだけでHoloを描く完成仕様にはしない。最初の戦闘検証で簡略化する場合は、未実装の部位機能を明記する。

シールド低下と重大損傷の女性音声は、[警告音声仕様](../audio/mission-controls-and-audio.md)で別のイベントとして扱う。Holoが赤いことだけから、音声の発声条件や文言を推定しない。

## Union Sentryでの完成条件

1-1で使うUnion Sentryの機内ビューを最初に照合する。窓枠と計器位置を再現し、FIL30・FLECHの配置・充填・残弾、レーダー、指令と実速度、自機・目標Holoがゲーム状態と一致することを確認する。

Union Sentryはユーザー確認に基づき、武器1をFLECH機関銃、武器2をFIL-30レーザーとして表示・操作する。2種類の武器を各砲門ごとの4スロットへ分割しない。最大4種類に対応するHUDであっても、この機体には未装備の武器3・4を生成しない。

目標なし、目標の画面内外、射程境界、弾切れ、エネルギー不足、部位損傷、照準と胴体旋回、全速出力、Bキーの任務表示を操作して確認する。画面比率を変えても照準と射線がずれず、計器が読めるようにする。外部ビューへ切り替えて何を表示するかは、機内表示とは別に原作で照合する。


## 試作版の目標表示（2026-10-23）

Q/Eの選択を左Holo・選択対象のシールドバー・黄色い追従マーク・画面外の左右矢印・レーダーへ反映した。中央照準の黄／赤の変化と、射程内の距離表示も追加した。Holoは機種別の図と部位ごとの損傷状態で表現する。内部システムの故障による機能低下は未実装。[操作と実装範囲](../technical/playable-1-1.md)を参照。



自機と目標のHoloは、本体・コックピット・左右武装・左右脚を独立して色分けする。命中位置に対応する部位だけを損傷させ、全身を同時に黄色・赤へ変える処理は廃止した。シールドで防いだ分は部位を損傷させない。FIL-30の表示には発射で減少し、時間で回復する充填ゲージを追加した。原作の部位耐久値・充填時間は引き続き照合が必要。


## 命中時の自動目標選択（共通仕様・2026-10-30）

ユーザー指定の共通仕様として、全任務・全武器に適用する。徒歩・搭乗中・機内ビュー・外部ビューで条件を変えない。

目標が未選択の状態でプレイヤーの攻撃が命中したら、生存している命中対象を必ず自動選択する。外れた場合は選択しない。すでに別の目標を選択している場合は、その選択を維持し、命中した相手へ切り替えない。

選択状態は左Holo・シールドバー・照準・レーダーへ反映する。外部ビュー中にも選択状態は更新するが、HUDは表示せず、機内へ戻ったときに反映する。

通常銃・TCREAP・レーザー（GAUSを含む）・ミサイル・徒歩のPRIF44／GASHR／EGGERの命中処理へ接続済み。飛翔弾は発射時にプレイヤーの攻撃かを記録し、着弾前に降機・乗り換えしても扱いを維持する。敵・味方AIの攻撃ではプレイヤーの選択状態を変更しない。


## 敵の検知ランプと選択対象の距離（2026-10-23）

敵に気づかれると赤いランプが光ることと、機種共通であることをユーザーが確認した。試作版では、生存・搭乗中で敵対する敵が警戒状態にある間、全機種共通のコックピット上のPINGランプを赤く点滅させる。自機自身・無人機・撃破済みの敵は判定から除き、IFFによる敵味方識別も参照する。外部ビューではほかの計器と同様に非表示。一時停止中は点滅も停止する。ランプの正確な配置と点滅周期は仮設定。

目標を選択している間は、ロックの成立に関係なく中央照準付近へ距離を表示する。ロック時は赤、それ以外は黄色。左Holoの距離も維持する。目標選択の解除・対象の撃破で消し、外部ビューでは表示しない。


## 部位への集中攻撃と破壊（2026-10-23）

ユーザー指定として、傷んだ部位へ攻撃を集中すると機体を早く破壊でき、別の部位へ攻撃を分散すると破壊まで時間がかかる。命中位置から部位を判定し、シールドを貫通した分だけ、その部位の耐久を減らす。自機・敵機で共通の処理を使う。

試作では、いずれかの部位の耐久が尽きると機体を破壊する。全身の合計被ダメージだけでは破壊せず、ARMOR表示は各部位の残存率の平均から計算する。ダメージクリティカルの警告は最も傷んだ部位を基準にする。部位ごとの耐久値、破壊の境界、表示の集計方式は仮設定であり、原作の内部数値を確認したものではない。


## 損傷色の強調（2026-10-23）

ホログラムは残存耐久60%以下を黄色（`#ffe000`）、25%以下を純赤（`#ff0000`）で表示する。数値の境界は試作の仮設定。

2026-10-24のユーザーの最新指定により、実際の3D機体は損傷した部位の塗装が黒ずむ表現へ変更した。損傷が大きいほど暗くし、黄色・赤の損傷色による発光は付けない。各部位を独立して表示し、無傷の部位の色は維持する。自機・味方・敵・固定タワーで共通とし、外側ビューだけでなく機内から見える他機にも適用する。命中直後の短い発光と重度損傷の煙は維持する。ホログラムの損傷色と警告条件は変更しない。

ユーザー指定の[merc-assault.png](../../assets/cockpits/merc-assault.png)をMerc Heavy Assault HAWC（Venom）のコックピットとして使用する。青い金属フレームと左右の支柱を残し、元画像の雪原・山・照準・出力バー・武器と残弾・IFF・人物像と名前・自機像・レーダーをマスクする。窓外には現在の3D戦場を表示する。

上部左に武器1・2、右に武器3・4、中央にIFF、左下に選択目標、右下に自機ホログラムとエネルギー・シールド、中央下にレーダーを配置する。充填・残弾・IFF・目標・自機損傷は実際の状態を参照する。画像の1882:1424の比率を維持し、機外視点・降機・VISOMビューでは専用フレームを解除する。元画像にあるThaneの像・名前を固定表示しない。人物選択時の全身像と名前位置を原作へ合わせる変更は別途行う。

歩行時は4脚と同じ周期で、機内のフレームと計器を左右へ最大幅の0.6%ずつ揺らす。速度が下がると揺れも小さくなり、停止後は滑らかに収まる。一時停止中は現在の揺れを保ち、降機・外部視点・VISOM・任務終了演出では解除する。照準と目標マーカー、実際の照準方向は揺らさない。振幅はユーザーの「やや左右に揺れる」という指定に合わせた試作値。

外部3Dモデルとホログラムは、追加された[側面画像とユーザー指定](../reference/vehicles/merc-assault/README.md)に基づく蜘蛛のような4本脚へ更新した。RUPPのレーザーは黄色。正確な寸法・装甲・旋回範囲・歩行周期・エンジン音・AIは仮設定。RUPPの射程325m・エネルギー2・対装甲18とPUGの射程625m・対装甲38は同マニュアル本文p.46を参照し、発射間隔・弾速のゲーム内換算・誘導・爆風などの未測定値は試作として扱う。RUPPの射程は既存の攻略記事由来の表にある525mと異なるため、マニュアル値を使用し、資料差を残す。

確認用URLは`/?previewVehicle=merc-assault`。2-4の地形を使う独立した確認画面で、本編任務としては登録しない。LAUNCH後に搭乗状態で始まり、Cで視点切替、Backspaceで降機できる。既存任務の機体配置・装備は変更しない。

## 遮蔽物越しの目標選択とQの判定範囲（2026-10-24）

ユーザー指定により、岩・建物・崖に遮られていても目標を選択できる。Qは照準の左右各12度・上下各8度、距離800m以内へ判定を広げた。近距離で機体の輪郭がこの角度より大きい場合は、その輪郭も判定に含める。候補が複数なら照準中心に近い対象を優先し、角度が同じなら近い対象を選ぶ。値は操作しやすさを調整するための試作値で、`CROSSHAIR_SELECTION`に置く。

Eの最寄り敵選択、Tabの対象切り替えも遮蔽物を理由には拒否しない。選択と射線の判定は分け、遮られている対象にはロック成立の表示を出さず、弾も遮蔽物に遮られる。味方・無人機・歩兵の選択、選択した対象へのF5追従にも利用できる。

## 旋回・照準操作と黄色の速度バー（2026-10-24）

ユーザー指定により、黄色のバーは移動の実速度に加え、車体の旋回、砲塔・上半身の横旋回、上下照準でも少しだけ上昇する。旋回・照準だけの上乗せは最大7%の試作値とし、操作が止まると滑らかに下がる。表示上の反応によって機体を前進させたり、最高速度や当たり判定を変えたりしない。

停止時は指令出力が0になっても、惰性走行の実速度に合わせてバーを徐々に下げる。搭乗先が変わったときに角度差だけでバーが跳ね上がらないようにする。表示処理は`presentation/cockpit-motion.ts`で管理し、実際の移動とは分ける。

## タワーの旋回と中央レーダー（2026-10-30）

ミーゾン・ガードタワーとScorpロケットタワーの中央レーダーは、動かない土台の向きではなく砲塔の現在の向きを基準にする。砲塔を右へ向けると、それまで正面にいた目標はレーダーの左へ移る。キー操作・右ドラッグ・自動追尾で同じ現在角度を使う。

目標の現在位置とプレイヤーの現在位置から相対位置を計算し、周囲の機体や歩兵の移動も反映する。タワー自体は移動しない。通常機体のレーダーは従来どおり車体の向きを基準とし、通常機体の移動も現在位置から反映する。表示座標の計算は`presentation/radar.ts`で管理する。

目標選択中のマーカー位置は、カメラと同じ描画フレームごとに更新する。ホログラムや数値パネルの定期更新を待たせず、動く対象のマーカーが段階的に動くのを抑える。
