- 作品：G-Nome再現
- 媒体：PC向けブラウザゲーム
- 対象：1-1のMerc Sentry・Merc Tactical Defenseの索敵、移動、射撃、状態変化
- 状態：実装構造の案と調査項目を整理。原作どおりの行動パラメータは未確定、実装未着手
- 記録日：2026-10-22
- 関連：[1-1](../missions/mission-1-1.md)、[IFF・通信](iff-and-communications.md)、[機体・武器](../reference/vehicles-and-weapons.md)、[難易度](settings.md)

## 現在決まっている範囲

最初の敵機種はMerc SentryとMerc Tactical Defense。最高速度や標準装備の掲載値はあるが、1-1に配置された敵の経路・実際の速度・攻撃開始条件・武器選択は確定していない。IFFによる識別をAIとレーダーで共有する方針は定義済み。

これまでの資料は「敵AIを作る」という計画までで、原作と比較できる行動仕様は不足している。本資料の状態遷移を原作から抽出済みのアルゴリズムとして扱わない。

## 攻略資料にある観察

[提供動画1:06の観察](../reference/observations/mission-1-1/observations.md)に、ユーザーが敵Sentryに気づかれたと報告した場面を画像付きで保存した。索敵に関する最初の具体的な観察例だが、距離・難易度・反応条件の確定値としては扱わない。

[1-1の攻略資料](https://gamefaqs.gamespot.com/pc/197456-g-nome/faqs/14087)には、先に交戦する敵は周囲を回り約5秒ごとに撃ち、次の敵はジグザグ移動後に停止して撃つという説明がある。

ただし、この説明だけでは各行動がSentryとTactical Defenseのどちらに対応するか、選択したゲーム難易度、距離や経路、使用武器、毎回同じ行動になるかが確定しない。資料の難易度評を、そのままゲーム内のMedium設定として扱わない。「敵はすべて常に5秒間隔で撃つ」と共通化もしない。

## 原作で確認する5項目

| 項目 | 必要な観察 |
| --- | --- |
| 出現・索敵 | 初期位置と数、待機・巡回、ウェイポイントや接近による行動開始、視界・距離・IFFの条件 |
| 移動 | 接近・周回・ジグザグと機種の対応、維持する距離、速度・旋回・停止時間、障害物への対応 |
| 射撃 | 使用武器、距離による切り替え、照準と射線、発射間隔、同時発射、命中精度・予測射撃、弾切れ・エネルギー不足 |
| 状態変化 | 目標を見失った後、IFF変更後、損傷・足の破壊、降機・乗っ取り、プレイヤーが徒歩になったときの反応 |
| 任務・難易度 | 2機の行動の連動、撃破と次のイベントの関係、Easy・Medium・Hardで変わる条件 |

最初はEasyの1-1を基準に、開始から終了までの映像・実機観察を行う。機種、距離、時間、使用武器、プレイヤーの操作を一緒に記録する。追跡中に隠れる、停止する、降機する、IFFを変えるなど、違いが分かる条件も比較する。

1回の映像で発射間隔が約5秒に見えても、充填・照準・射程の待ち時間なのか、行動自体の待ち時間なのかは分からない。必要な場面は複数回確認する。Easyの基準が整理できてから、他の難易度の差を調べる。

## 実装構造の案

ここでいうAIは、LLMを呼び出す仕組みではなく、条件に応じて行動を選ぶゲーム内処理。ブラウザ内で動かす。

ミッション側が敵の配置と行動開始イベントを管理し、敵側が索敵・目標選択・移動・照準・射撃を管理する。敵がどこへ行くかと、どこへ武器を向けるかは分ける。移動中の射撃も表現できる構成にする。

| 状態・処理 | 内容と移行条件の案 |
| --- | --- |
| 待機・巡回 | ミッションの指示された位置・経路に従う。攻撃対象を検知するか、行動開始イベントを受けて交戦へ |
| 接近・距離調整 | 目標との距離を調整する。機種・配置ごとの行動定義を参照する |
| 交戦 | 周回、ジグザグ、停止射撃などを組み合わせ、照準と射撃可否を個別に評価する |
| 見失い・再評価 | 最終確認位置、IFF、射程・視界を再評価する。追跡継続・待機への復帰などは原作照合後に決める |
| 操縦不能・無人・破壊 | 損傷・降機・操縦者死亡に応じてAIの操縦と発射を止める。歩兵になった操縦者の行動は別に扱う |

「盾が減れば撤退する」「残弾が減れば乗り換える」など、未確認の賢い行動を追加しない。障害物回避を改善するか、原作の単純な動きを再現するかも、挙動の比較を踏まえて決める。

最高速度・旋回可能な範囲・射程・充填・弾薬は、プレイヤーと共通の機体・武器処理を参照する。AIにだけ無制限の弾や可動範囲を与えない。原作に例外があれば、対象と根拠を記録して個別に定義する。

[車体と上部の旋回](vehicle-articulation.md)を分け、砲塔が回り切らなければ射撃できない、機体全体の向き直しが必要などの条件を照準処理へ反映する。各機体の角度・旋回速度は未確認。

行動定義は機種だけに固定せず、ミッションの配置単位でも指定できるようにする。同じSentryでも、待ち伏せ・巡回など役割を変えられる構造にする。難易度補正は確認できた項目へ限定する。

## 検証と着手条件

実装時には現在の行動状態、目標、選択武器、距離、発射できない理由、IFFによる識別を確認できる表示・記録を用意する。描画速度によって移動や発射間隔が変わらないことも確認する。

まず待機→発見→接近・射撃の仮AIで戦闘を試作することはできる。ただし原作準拠とするには、上の5項目をEasyの1-1で照合し、2機それぞれの行動表と配置データを埋める必要がある。未確認の数値は仮値として明示する。


## 1-1試作版への反映（2026-10-23）

ユーザーのプレイ確認で、開始直後に敵が気付く問題が判明した。開始位置と搭乗直後では索敵距離外になるよう調整し、前進して接近すると発見される条件へ変更した。被弾した敵は先に警戒状態へ移る。

敵のミサイルは線の表示と即時ダメージから、実際に移動して衝突する飛翔体へ変更した。発射時は目標位置へ照準のばらつきを加え、追尾は旋回上限と目標位置の更新間隔を持たせる。脱出中の人物にはさらに精度と追従性を落とす。移動による回避と、岩・機体・歩兵への着弾を判定する。索敵距離・速度・発射順序などは仮設定。[実装範囲と検証](../technical/playable-1-1.md)を参照。


## Merc Sentryの速度・上半身（2026-10-23）

ユーザーから、Merc Sentryは二足歩行機の中でも速い機体で、上半身も旋回できるとの確認があった。マニュアルの最高速度85km/hを維持し、AIの速度を一律32%へ落としていた処理を変更した。ユーザー指定により距離110m以内の85%速度補正も削除し、移動中は無損傷なら85km/hまで加速する。脚の損傷による減速も共通に適用する。

上半身は車体とは別の角度・旋回速度で狙い、機体ごとの角度制限内で動かす。銃口の向きが合ってから射撃する。原作の旋回速度・発射許容角・周回速度の正確な再現は引き続き照合が必要。


## Merc Tactical Defenseの最高速度（2026-10-23）

原作マニュアル本文p.51の最高速度は72km/h。敵AIへ18%の補正を適用して実質12.96km/hにしていた処理を削除した。移動中は無損傷なら72km/hまで加速し、脚の損傷・接触・停止判断は既存の処理を使う。加速時間と停止を判断する距離は原作で未確認の仮設定であり、原作のAI走行パターンが一致したという意味ではない。


## AIミサイルの命中精度（2026-10-24）

敵・味方AIの命中率が高すぎるというユーザー指定を受け、共通の照準誤差と遅れのある追尾へ変更した。脱出して飛行中の人物は、地上の人物や機体よりも狙いにくくする。プレイヤーの脱出だけを特別に無敵にせず、NPCの脱出兵にも同じ処理を適用する。設定値と範囲は[ミサイルの自動追尾](weapons-and-missile-camera.md#通常ミサイルの自動追尾2026-10-24)を参照。命中時のダメージ、当たり判定、発射頻度は変更しない。
