## 難易度と初期値

難易度はEasy・Medium・Hardの3段階とする。段階名はマニュアル本文p.9、初期値Easyはユーザーの指定に基づく。保存済み設定がなければEasy、既存の有効な設定があればその選択を復元する。「初期値に戻す」でもEasyに戻す。

マニュアルには、高難易度では弾薬が限られる場合があり、敵数が増える場合があり、敵を撃破しにくくなるとある。影響する計算項目や値は未確認であり、勝手に「敵HP2倍」「速度1.5倍」などを原作仕様として設定しない。

| 項目 | 確認状況 | 実装方針 |
| --- | --- | --- |
| 初期難易度 | Easyをユーザーが指定 | 新規設定とリセット時の既定値 |
| 弾薬 | マニュアルに難易度による制限の説明あり | 1-1の機種・武器ごとの初期弾数を照合する |
| 敵数 | マニュアルに高難易度で増える場合があるとの説明あり | ミッションごとの出現定義として管理する |
| 撃破しやすさ | マニュアルに差があるとの説明あり | 装甲・損傷計算・防御など、何が変わるかを特定する |
| AI・命中精度・発射頻度 | 難易度による変化の有無は未確認 | 調査対象。補正の存在も数値も未確定 |
| 最高速度・武器射程 | 難易度による変化の有無は未確認 | 基本性能を保持し、根拠がなければ難易度で変えない |

難易度による違いを実装するまでは、3つの表示だけを用意して完成扱いにしない。検証用に暫定値を使う場合は、その値と適用範囲を原作の値から区別して記録する。

## 初回の設定画面

出撃前に設定画面へ入れるようにし、プレイ中もポーズ画面から音・表示・操作を調整できる構成を検討する。以下のうち、原作確認済みの項目とWeb版で追加する案を区別する。

| 分類 | 項目 | 初期値・適用案 |
| --- | --- | --- |
| ゲーム | 難易度 | Easy。変更は次の出撃・再挑戦から適用 |
| 音 | BGMオン・オフ | 原作マニュアルのCD Musicはオン。音源がなければ未登録と表示 |
| 音 | 効果音・台詞オン・オフ | 原作のEF/X Dialogueはオン |
| 音 | BGM・効果音・台詞の音量 | Web版の調整項目案。音量の数値と分離方法は未確定 |
| 表示 | 描画品質 | 原作にはLow・Medium・Highがあり既定はMedium。Web版の対応する設定内容は別途定義 |
| 操作 | キー割り当て・感度 | Windows・macOSとテンキーレスに対応。[原作キーと共通プリセット案](../technical/keybindings.md)を参照。原作操作と現代的な操作を混同しない |
| 操作 | カメラ切り替え | 機内・外部斜め・外部真後ろの3種類。原作キーと初期ビューは未確認。[カメラ仕様](cameras-and-cockpits.md)を参照 |
| 操作 | ミッション中断確認 | 女性の「よろしいですか」の音声と確認後のYで中断。呼び出しキーは未確認。[中断仕様](../audio/mission-controls-and-audio.md)を参照 |

ボタンは適用・キャンセル・初期値に戻すを用意する。編集中の値は適用まで確定させず、キャンセルで元の設定を維持する。初期値に戻す操作も、適用するまでは保存済み設定を変更しない。

日本語版を先行し、後から英語版を追加する。設定データは言語の項目を持てる構造とし、日本語を初期値にする。英語の表示・音声が実装される前に、対応済みの言語として選択可能にはしない。2種類の女性案内は機体・施設などの対象に応じて決まり、設定で任意の声へ置き換える機能は現時点の要件に含めない。[言語と声種の設計](../audio/mission-controls-and-audio.md)を参照。

## パラメータの分離

| データ | 管理するもの |
| --- | --- |
| 機体の基本定義 | 原作の最高速度、シールド、エネルギーなど |
| 武器の基本定義 | 原作の射程、威力、弾速など |
| ミッションの配置・装備 | 1-1の敵配置、出現条件、搭載武器・初期弾数 |
| 難易度別定義 | 確認できた難易度差。必要ならミッションごとの定義で上書きする |
| ユーザー設定 | 選択した難易度、音量、画面、操作。機体の基本値を直接変更しない |

出撃時にミッションと難易度を確定し、そのプレイ中は保持する。設定画面で次回の難易度を変更しても、進行中の敵・弾薬・装甲を途中で書き換えない。再挑戦時に適用する難易度を画面上で確認できるようにする。

音量と消音は適用後すぐに反映する案とする。音声の開始にはブラウザで必要なユーザー操作を用意し、読み込みや再生の失敗時には状態を表示する。BGM未登録でも戦闘は開始できる。

## 保存と検証

設定はバージョン付きのデータとしてブラウザに保存する。保存失敗時もプレイを続けられるようにし、保存できなかったことを表示する。読み込み時は型・範囲・列挙値を検証する。難易度の不正値はEasyへ、音量などの不正値は定義済みの初期値へ戻す。

検証では、初回Easy、有効な保存値の復元、適用とキャンセル、初期値復元、不正な保存データ、保存失敗、出撃中の難易度維持を確認する。Easy・Medium・Hardそれぞれについて、定義した敵数・装備・補正が反映されることと、1-1を開始から終了まで進められることを確認する。音量・消音、再挑戦時のBGM重複再生も確認する。


## 難易度と基本性能（2026-10-23）

ユーザー指定により、Easy・Medium・Hardで機体の速度と攻撃威力は変えない。機体ごとの最高速度と加速処理、武器ごとの基本ダメージを共通で使う。敵のミサイル・レーザー・機関銃・歩兵射撃も対象。Easyの威力60%、Hardの140%という試作補正を削除した。Merc Sentryの近距離移動を85%にする仮補正も削除した。脚の損傷・接触・停止による速度低下は既存のゲーム仕様として維持する。

現在は敵AIの攻撃間隔だけに難易度別の仮値が残る。これは原作で確認済みの難易度差ではない。武器の基本威力自体も未照合の値を含むため、難易度補正の廃止を全数値の原作一致とは扱わない。
