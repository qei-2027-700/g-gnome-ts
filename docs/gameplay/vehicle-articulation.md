# 機体・上半身・砲塔の旋回

- 作品：G-Nome再現
- 媒体：PC向けブラウザゲーム
- 対象：車体・脚側と上半身・砲塔の向き、可動範囲、照準
- 状態：可動方式を機体別に持つ方針。角度・速度・例外は原作で照合する
- 記録日：2026-10-22
- 関連：[機体性能](../reference/vehicles-and-weapons.md)、[機内表示](cockpit-hud.md)、[カメラ](cameras-and-cockpits.md)、[敵AI](enemy-behavior.md)、[キー設定](../technical/keybindings.md)

## 記録する原作情報

ユーザーの説明では、ホバー機体や戦車機体は上部が360度回転でき、歩行系は最大でも90度程度だった記憶があり、旋回できない機体もある。この違いを再現対象とする。

[マニュアル](../reference/manuals/G-Nome_Manual_Win_EN.pdf)本文p.12にも、上半身をひねれる機体があり、可動範囲は機体ごとに異なると記載されている。正確な機種別角度は別途確認する。

「90度」が正面から片側90度なのか、左右合計90度なのかは未確定。全歩行機を一律に左右90度にせず、ホバー・戦車も含め機体別の範囲として管理する。旋回できる上半身・砲塔と、個別武器の可動範囲も同一とは決めつけない。

## 3種類の可動方式

| 方式 | 定義するもの |
| --- | --- |
| 連続回転 | 上半身・砲塔が360度を越えて回り続けられるか。旋回速度と初期方向 |
| 角度制限あり | 車体正面に対する左端・右端の角度、旋回速度、正面へ戻す動作 |
| 固定 | 上部の独立した横旋回なし。機体全体の旋回と武器の上下可動は別途定義 |

角度制限ありの上部では、端に達したらそれ以上は回さない。端に達したとき自動で機体全体も回るか、照準追従がどう振る舞うかは原作で調べる。固定方式でも俯仰や別の武器が可動する可能性を残す。

## 分離する状態とデータ

車体・脚側の方位、上半身・砲塔の相対角、各武器の可動角、カメラの向きを分ける。移動方向は車体側、発射位置と射線は武器側を参照し、上部の旋回だけで移動方向が変わる実装にしない。

機体定義は上部可動方式、左右限界、旋回速度、初期角、旋回入力への反応、正面復帰の有無を持てる構造にする。個別武器には取り付け位置・向きと横方向・上下方向の制限を持たせる。未確認値は仮値・確認済みを分ける。

モデルも車体・上部・武器の回転軸を分ける。機内ビュー、外部斜め・真後ろビューは、その機体の実際の向きに従って表示する。機体の向きと視線の方向はHUDでも別々に示す。

敵AIも同じ可動範囲と旋回速度を使う。後方の敵を狙う際、砲塔が360度回る機体と機体全体を向け直す必要がある機体では、射撃できる時機が変わる。原作で未確認の即時旋回や、射角を無視した攻撃を実装しない。

原作のカンマ・ピリオドによる上半身旋回と、上下照準の操作を区別する。マニュアルのSpaceは上下照準を中央へ戻す説明であり、上半身の横角も正面へ戻すと無条件には解釈しない。

## 最初に照合する機体と検証

1-1のUnion Sentry、Merc Sentry、Merc Tactical Defenseについて、横旋回の有無、左右限界、旋回速度、上下の射角を個別に確認する。前進しながら横へ撃つ、正面と視線をずらす、後方へ向けるなどの動画・実機観察を記録する。

360度回転では角度の境目を越えても急に反転しないこと、制限付きでは端を越えないこと、固定機では車体と独立して横を向かないことを確認する。カメラを変えても射角が広がらず、プレイヤーと敵AIに同じ制限が適用されることも検証する。


## Merc Sentryの反映（2026-10-23）

ユーザーがMerc Sentryの上半身旋回を確認した。試作では車体と上半身を分け、敵AIにも機体プロファイルの左右限界と旋回速度を適用した。銃口が標的へ向くまでは発射せず、背後へ即座に撃つ動作を防ぐ。現在の左右60度・旋回速度は調整値で、正確な原作可動範囲を実測したものではない。


## Union Sentryの確定仕様（2026-10-24）

ユーザーの補足により、Union Sentry HAWCは車体の方向転換が可能で、上半身・照準だけの独立した横旋回はできないと確定した。上部の可動方式は固定。上下照準の可否・範囲は今回の指定からは決めない。根拠は[機体資料](../reference/vehicles/union-sentry/README.md#旋回についてのユーザー指定2026-10-24)に記録する。

共通機体定義を`torsoLimit: 0`へ変更し、プレイヤーの横照準・追尾照準・味方AI・敵AIへ反映した。左右の移動入力による車体全体の方向転換は維持する。上半身の描画と命中領域も車体の向きに固定し、独立旋回させない。上下照準は既存の範囲を維持する。

## 正面衝突と浅い接触（2026-10-24）

機体同士、岩、建物・崖・固定施設の残骸との接触では、移動区間の最初の接触点を求める。正面から大きく当たった場合は停止し、浅い接触では残りの移動から障害物へ食い込む成分を除き、接触面に沿って滑って進む。車体の向きを勝手に変えず、移動方向を接触面で制約する。プレイヤー機とAI機で共通の処理を使う。

現在の機体外周は既存の円形近似を使い、接触面へ向かう成分が移動量の75%以上なら正面衝突とする。このしきい値と壁の余裕幅は試作値。滑り先も再判定し、別の機体や壁をすり抜けないようにする。接触だけではダメージを加えず、後退して離れることができる。通常機体の破壊後に残骸を通過できる仕様と、固定施設の残骸が残る仕様は維持する。

正面衝突では短く低い鈍音を鳴らす。同じ接触で押し続けても鳴らし続けず、離れて再接触すると再び鳴る。自機が関係する衝突と、プレイヤーから80m以内の衝突を再生対象とする。音量と消音はSE設定に従う。


## 停止と惰性走行（2026-10-24）

停止・味方へのF7・追従目標の消失では、駆動を止めて残った速度を徐々に落とす。ガスで操縦者が脱出した無人機も惰性走行する。衝突による停止と機体破壊は、この通常の減速とは分ける。最高速度と武器性能は維持する。歩兵も含めた具体的な挙動は[歩兵・乗降仕様](infantry.md#停止時の慣性と機体への接触共通仕様2026-10-24)を参照する。

## 狭い場所での離脱（2026-10-24）

建物・崖・設備の残骸の判定と少し重なっている場合は、重なりを減らす方向や壁沿いの移動を許可し、さらに食い込む方向は止める。壁との接触面は移動区間から求め、角では当たった面を合わせて扱う。別の機体や岩へ接触した後も、残りの移動を判定する。正面衝突の停止と音、浅い接触で滑る条件は維持する。歩兵の同じ問題と確認範囲は[遮蔽物と機体の間からの移動](infantry.md#遮蔽物と機体の間からの移動2026-10-24)を参照する。


## タワーの旋回速度（2026-10-29）

横移動する敵に照準が追いつかないというユーザー指定により、ミーゾン・ガードタワーとスコープ・ロケットタワーの左右キーによる旋回を0.6rad/秒から1.5rad/秒へ変更した。追尾照準も1.3rad/秒から2.0rad/秒へ変更し、近距離を横切るAIPを追えるようにする。一度速めた後、速すぎるというユーザーの指摘に合わせ、左右旋回・追尾とも約17%落とした。これらは操作調整用の仮値で、原作の実測値ではない。

塔の土台は回転・移動させず、砲塔だけを旋回する。通常機体・徒歩・マウス照準の感度は既存の値を維持する。


## HAWCの共通横視点操作（2026-10-29）

ユーザー指定により、全HAWCの左右キー・マウス横方向の視点速度を[共通設定](../technical/keybindings.md#hawc共通の横方向の視点速度2026-10-29)へ統一した。右ドラッグでは上半身の左右限界を超える分だけ車体を旋回させ、視点の移動速度を保つ。上半身固定のHAWCは車体ごと向きを変える。機体ごとの可動範囲と、移動入力なしで前進しない動作は維持する。
