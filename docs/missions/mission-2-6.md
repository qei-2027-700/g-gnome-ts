# 2-6 Battle of Clouds

- 作品：G-Nome再現
- 媒体：PC向けブラウザゲーム
- 対象：2基のミーゾンタワーでMerc AIPを迎撃し、ターンを回収する任務
- 状態：プレイ可能な試作。開始状況・機種・迎撃と回収の流れはユーザー指定。配置、AIP数、進軍時刻、必要撃破数、回収後の終了条件は仮設定
- 関連：[任務定義](../../src/game/content/missions/mission-2-6.ts)、[任務追加の共通仕様](../technical/mission-definitions.md)、[ミーゾンタワー](../reference/vehicles/merc-meson-tower/README.md)、[Merc AIPとCruiser](../reference/vehicles/merc-aip/README.md)

## ユーザー指定の進行

主人公は徒歩で開始する。正面のミーゾン・ガードタワーへ進み、敵の攻撃が始まる前に搭乗する。キリーは右側の別の塔へ向かい、序盤に自動搭乗して迎撃を始める。ターンは中央の巨大要塞内で作業している。この間は外の歩兵として描画・攻撃対象にせず、味方の状態欄と通信に作業中と表示する。

敵はMerc軍のAirborne Insurgence Platform（Razor）。ユーザー指定により、TAR12のレーザー弾・銃口と着弾の光は黄色とする。高空を飛ぶ飛行機として扱わず、緑色の菱形の機体が低空を浮いて四方八方から近づく。移動中は小さく上下に揺れる。GASHR命中後は操縦者が排出され、減速しながら高度を徐々に下げて接地する。接地後に搭乗すると浮遊を再開する。塔と建物を貫通せず、要塞が経路を塞ぐ場合は迂回する。無人のMerc Assault HAWCとMerc Cruiser HAWCも配置する。

一定数のAIPを撃破すると、ターンは要塞の出口から外へ出て、主人公の機体へ向かう。塔には同乗席がないため、同乗可能なHAWCを確保して迎える。主人公が機体を乗り換えた場合は新しい同乗先へ向かう。施設や障害物は迂回し、実際に近づいてから同乗する。射撃が続いている場合はターンにも被弾の危険がある。

## 操作と武器

徒歩開始位置からWで正面の塔へ進む。塔は移動せず、A/D・左右キーで旋回、上下キーまたは右ドラッグで上下照準、1でGAUS30を発射する。Eで敵を選択し、Tで追尾する。敵を倒すと追尾が解除されるため、次の敵を選び直してTで追尾を再開する。遮蔽物の陰の敵は選択を切り替えて狙う。

GAUSは群青色の静かなレーザーとする。ユーザー指定により、GAUS30の飛翔体は長さ24m・幅0.12m・厚さ0.008mの薄く細い板状にし、水色の芯は付けない。寸法・色は見た目の調整値で、射程・速度・命中判定は変更しない。発射と着弾は小さな青い光と控えめな合成音で表現し、ロケットの機体・推進炎・煙・誘導は使わない。原作録音は使用しない。Merc所属でもミーゾン・ガードタワーの破壊時には搭乗者が生きて脱出する。MercのHAWCやAIPの脱出装置の有無とは分けて管理する。

2-6にはMerc電力プラントを配置し、2基のミーゾンタワーを接続する。プラントが破壊されると両塔の射撃・充填を停止する。給電中は、共通の[外部給電仕様](../reference/vehicles/merc-meson-tower/README.md#射撃と給電の共通仕様2026-10-29)により、弾数・蓄積エネルギーによる射撃制限はない。通常の一時停止・設定画面は停止し、地図と中断確認中は任務を継続する。成功・失敗・中断は共通の扉演出へ接続し、同じ任務の出撃前メニューへ戻る。

## 試作の仮設定

| 項目 | 現在値・条件 |
| --- | --- |
| 初期配置 | 主人公は塔の18m手前、キリーは右の塔の12m手前、ターンは中央要塞内 |
| 予備機 | 無人のMerc Assault HAWCとMerc Cruiser HAWCを各1機 |
| 敵 | Merc AIP 8機。要塞を中心とした8方向へ初期配置 |
| 進軍開始 | 4機ずつ、任務時間12秒・27秒。待機中の敵も攻撃できる |
| AIPの高さと揺れ | 根元の浮遊高0.8m、移動中の上下動は約±0.15m。機体高3.7mとは別の値 |
| ターンの脱出 | 対象AIPのうち4機を排除すると開始。原作の必要撃破数は未確認 |
| 試作の成功 | 脱出したターンが主人公の操縦する機体へ同乗すると成功 |
| 失敗 | 主人公・ターンの死亡、または防衛段階での中央要塞の破壊 |
| 耐久・地形 | 中央要塞の耐久1200、雪原・曇天と周囲の岩山。青いMerc要塞・Merc電力プラント・Merc Latlon通信基地を左から並べる。座標・寸法・追加施設の耐久は仮設定 |

任務中のHUDには防衛段階の排除数・要塞の耐久率と、ターンの回収状態を表示する。必要撃破数に達した後は迎撃だけで任務を終了しない。防衛段階の達成を記録し、その後はターンの同乗を待つ。回収用のAssault HAWCとCruiserは、この任務の配置に限り同乗席を1つ設定する。原作の乗員数の全面照合は未完了。

AIPは2基の塔へ向かい、攻撃されると既存の報復行動で主人公を狙う。任務の説明・キリーの塔への搭乗・ターンの退出と接近は、任務IDを共通処理へ埋め込まず、配置・人物・進軍・回収の定義から実行する。

## マニュアルと実装の範囲

保存済みの[英語マニュアル](../reference/manuals/G-Nome_Manual_Win_EN.pdf)本文p.54のMerc Meson TowerはGAUS30を1門備え、電力施設から給電される。本文p.57の射程800m・速度1000・エネルギー消費5・装甲ダメージ17をGAUS30の武器定義へ反映する。ただし、ミーゾンタワーでの使用時はユーザー指定の共通外部給電仕様に従い、蓄積エネルギーを消費しない。2-6でも電力プラントへ接続する。シールドダメージ・拡散率・範囲ダメージの個別再現は未実装で、共通の損傷処理を使う。充填・最短発射間隔はユーザー指定の調整で1.6秒、飛翔速度は600m/sとする。[青い光線の調整](../reference/vehicles/merc-meson-tower/README.md#射撃速度と青い光線の調整2026-10-29)を参照。塔の耐久・寸法・配色は試作値。

本文p.53のMerc AIPはホバー機Razorで、速度103.5km/h、シールド18、エネルギー1400、高さ3.7m、TAR12・TCREAP・DASY各1門、TCREAP 500発・DASY 510発、自動脱出なし。本文p.51のMerc CruiserはWidowMakerで、速度45km/h、シールド40、エネルギー1000、高さ12.4m、FLECH 2門・各150発とGAUS20、自動脱出なし。これらの掲載値を共通機種定義へ反映する。装甲値・AI・細部形状・配色の未確認部分は仮設定とする。Razorの緑色と菱形、低い浮遊と揺れはユーザー指定を優先する。

## BGM（2026-10-30）

出撃直後から、配置済みの「Fighting on the Tundra」（投稿動画の表記）を再生する。音量はユーザーの追加指定によりBGM設定値の0.8倍とし、従来より20%下げる。ファイル全体をループし、一時停止・設定中は停止、再開時は続きから再生する。任務地図と中断確認中は継続し、任務終了で停止する。再出撃では先頭から再生する。開始時刻とループ方法は今回の実装上の設定で、原作の厳密な再生条件は未照合。[出典と検査値](../audio/bgm-mapping.md#配置済みのmerc最終戦用音源2026-10-29)を参照。

実ブラウザで2-6の開始を確認した。同じ任務定義と共通音声処理を使う検証画面では、実MP3の読み込み、再生時間の進行、一時停止・再開・終了停止を確認した。実際に耳で聞く聴感確認は未実施。


Merc AIPの旋回と加減速は[機種共通の応答設定](../reference/vehicles/merc-aip/README.md#merc-aipの旋回と慣性2026-10-30)を使う。ユーザー指定により、AIの急旋回を抑え、加速・減速を緩やかにする。最高速度は変更しない。
