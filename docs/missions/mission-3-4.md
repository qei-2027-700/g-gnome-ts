## 任務進行の確認事項

ユーザー指定の完成形では、GASHRで橋制御棟の敵歩兵を排出して倒し、入棟して表示される敵IFFを確認し、橋を下ろす。自機へ戻ってIFFを手動で変更し、通信の「use my IFF」でターンにも同じコードを設定させてから渡河する。第2ウェイポイントを経て第3ウェイポイントに到達すると、TD HAWCのキリーとASVのシェリダンが登場し、通信で連携できる。最終地点のUr-Alr司令部へ向かう。

敵歩兵は橋制御棟内の操縦者として配置した。GASHR命中で棟の外へ出て、倒した後に入棟・橋操作が可能になる。現段階では入棟時に主人公とターンのTD HAWCへ敵IFF `3317` を自動設定する。施設内の表示には施設のIFFを出す。自機に戻ると敵IFFが表示され、同じコードの敵はレーダーで緑になり、通常は攻撃してこない。主人公とターンは降機時に歩兵IFF `4033` へ戻り、敵から識別される。ターンが再搭乗した場合は自動設定した機体IFFへ戻る。

第3ウェイポイント到達時にScorp TD HAWCのキリーとScorp ASVのシェリダンを生成し、追従と通信を有効にする。到達前は2人の機体がフィールドに存在せず、通信先は未合流と表示する。基地へ向かう際の右側に、薄い赤色の点で地雷6個を仮配置した。個々の地雷位置は画像から特定できていない。踏むと機体が破壊される。地雷原コントロール施設の破壊で地雷が停止し、赤い点が消え、施設跡から煙が上がる。基地には司令部・シールドジェネレーター・地雷原コントロール施設の3施設と、奥にロケットタワーと発進用エレベーターを置いた。エレベーターは外観のみで発進機能は未実装。各施設の詳細位置と地雷の数は仮値。

タワーはIFFが異なる相手を攻撃する。開始位置からの即時射撃を避け、接近時には攻撃するよう、3-4での警戒距離を仮に140mとした。手動のIFF変更と「use my IFF」通信命令の操作・キー、敵IFFの原作値、司令部内での操作は未確定。開始IFF `4033` は機内画面で確認済み。敵IFF `3317` は仮値。

## 達成条件

原作の任務画面に表示される4項目に、次の暫定判定を対応させた。進行に応じて画面のチェックが自動で付く。

| 画面の項目 | 現在の判定 |
| --- | --- |
| シェリダンの司令部侵入を援護 | 第3ウェイポイントで合流したシェリダンが、生存した機体で司令部から52m以内へ到達する。ほかの必須項目も完了していること |
| Erreskat川の渡河と橋の防衛ラインの無力化 | 橋を下ろし、対岸のミーゾン・ガードタワーを無力化する |
| Ur-Alrへの接近 | 第2ウェイポイントへ到達する |
| Ur-Alrへの攻撃 | シールドジェネレーター、地雷原コントロール施設、奥のロケットタワーを無力化する |

4項目を満たすと任務成功とし、研究所の座標を取得した旨を表示する。合流後にシェリダン本人が死亡すると任務失敗とする。機体から生きて脱出した場合は、徒歩で司令部へ到達しても達成できる。シェリダンが司令部内で操作する演出は未実装。施設破壊の組み合わせと52mの到達範囲は原作画面だけでは確定できないため、遊べる任務にするための仮条件とする。
