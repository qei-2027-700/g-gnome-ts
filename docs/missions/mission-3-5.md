# Mission 3-5「Ion-Strike」実装計画

## 根拠と確認できる範囲

- [任務選択画面](<../../assets/map/3-5/sc- 2026-11-12 0.42.40.png>)は1140×850画素。地図枠は元画像の左上を原点として、およそ `(224, 59)` から `(591, 429)`。枠内の黄色い `X` は約 `(434, 77)`、緑の `1` は約 `(491, 362)` に見える。`X` は[任務地図の共通表記](../gameplay/mission-map-and-waypoints.md#任務表示)では現在位置を表すため、開始地点の候補とする。`1` は第1ウェイポイントの候補。両者の役割と正確な画素中心は、任務中の地図で照合する。
- 画面の目標は「G-NOMEの研究所を破壊」「ロケットタワーの防衛ラインを突破」「イオン砲を用いて研究所を破壊」の3項目。ユーザー指定により研究所は地図の南東、すなわち右下にある。第1ウェイポイントと研究所の正確な距離、1項目目と3項目目が別々に完了する条件、ロケットタワーの数は未確認。
- ユーザー指定により、地図の黒い領域は歩行可能。曲がった淡緑・黄緑の帯には等高線が沿い、[開始直後の機内画面](<../../assets/map/3-5/sc- 2026-11-12 0.43.29.png>)には正面の山並みと草地が写るため、明るい帯を高い地形の候補と読む。帯の詳細な高低と通行可否は未確認。機内画面のIFFは `1381`、武器欄はzWASP・LRIP・VISOM・SREM。[外部視点1](<../../assets/map/3-5/sc- 2026-11-12 0.44.18.png>)と[外部視点2](<../../assets/map/3-5/sc- 2026-11-12 0.45.32.png>)にも草地と山並み、複数の機体が写る。ユーザー指定により、開始時はキリーがScorp AIP、ターンがScorp TD HAWC、シェリダンがScorp Sentry HAWCに搭乗して主人公のそばにいる。画面から3人それぞれの正確な座標は読めない。
- [任務一覧](campaign-catalog.md)には、シェリダンによるイオン攻撃要請と退避を確認事項として記録済み。[公開動画](https://www.youtube.com/watch?v=10mSGF0ZZ5c)の索引はあるが、この計画では内容を照合していない。動画の秒数をゲーム内時間として扱わない。

## フィールド作成の実行計画

1. 地図領域を元画像の `(224, 59)` から `(591, 429)` で切り出し、`X`、`1`、黒い歩行可能域の輪郭と狭い部分、明るい帯の外縁・内縁を画素点列として記録する。元画像の上に点列を重ね、南東へ続く黒い領域のつながりを見直す。
2. 原作の移動場面または実機で、明るい帯へ入れる範囲、開始時の向きと山の見え方、南東の研究所とロケットタワーの位置を確認する。地図の上下左右を任務座標へ対応させる目印を二つ以上選び、縮尺がなければ一つの仮の画素対メートル比を全体に使う。黒い領域は歩行可能として扱い、明るい帯の衝突境界は確認結果から決める。
3. 確認した高地と黒い歩行可能域を `mission-3-5-map.ts` の地形定義へ写し、開始位置・第1ウェイポイント・南東の研究所と防衛施設を同じ変換で置く。曲線を既存の `peaks` や `cliffs` で近似できない箇所は、表示・移動・経路探索・射線が同じ輪郭を使う共通の地形表現を追加する。背景の山はプレイ可能領域へ重ねない。
4. 原作画像と座標から描く地図を `X`、`1`、南東の研究所、帯の屈曲部で重ねて比べる。実ブラウザで開始時の山の位置、黒い領域の移動、南東への到達を確認する。斜面の接地輪郭と衝突境界、敵AIの経路、射線を関連テストで確認し、残る輪郭差と仮の縮尺をこの文書へ記録する。

## フィールドの現行実装

`mission-3-5-map.ts` で地図の内側 `(232, 68)` から352×352画素を8画素ごとに読み、明るい帯を通行できない斜面へ仮に近似した。黒い部分は空け、WP1の緑色の印は斜面として扱わない。画像の右を東、下を南として、中心 `(408, 244)` を任務座標 `(0, 0)`、1画素を仮に4mとする。換算は `x=(画像x−408)×4`、`z=(244−画像y)×4`。高さ64mと画素対メートル比は試作値。原作の距離・斜面高ではない。

通路が狭く移動しづらいというユーザーの操作上の指摘を受け、開始地点から第2ロケットタワーまでの曲がり角は、中心線から画像上18画素以内の斜面を通行可能にした。任務内では中心線の各確認点から少なくとも32mの空きがある。出撃前に表示する原作画像は変更していない。この広げ方は操作性のための試作調整で、原作地形との厳密な一致ではない。

開始時の味方3人はScorp製の機体に搭乗しているが、降機後の人物はUnion兵の白い装備で表示する。敵のScorp機から出た兵士は緑のままとする。キリー、ターン、シェリダン、主人公は敵のScorp機へ乗り換えて再び降りてもUnion兵のまま。機体の外観色とIFFは、この歩兵の所属色では変えない。

## 研究所破壊後の裏切りと勝敗

ユーザー指定では、イオン砲はScorp軍に対して使う予定だった。しかしシェリダンは研究所へ着く前に「Baby、やられた。戦線を離脱する」と無線で伝え、本人だけがフィールドから離脱する。搭乗中のHAWKはその場に無人機として残る。すでに徒歩なら本人が消え、HAWKは残る。その後の通信には応じない。研究所破壊時、ターンが「ガンツ！Gnomeを見失ったわ！」、続いてキリーが「ガンツ！お前が狙われてるぞ。脱出脱出脱出だ！」と無線で警告する。

研究所を破壊してから約20秒後、シェリダンのイオン砲が主人公機を捕捉する。赤い光柱と「イオンキャノン準備完了」の音声を同時に出し、1秒後に標的機を破壊する。主人公がその時点で機体を降り、標的機から十分離れて生存していれば任務成功。搭乗中、または降りても近すぎる場合は失敗。現在の安全距離80m、シェリダンの離脱発生距離220m、20秒という正確な間隔、光柱の寸法は試作値。シェリダン本人の離脱に飛行演出はない。

共通処理は任務の `ionStrike` 設定を参照し、任務IDで分岐しない。研究所破壊を起点に一度だけ計時し、無線も一度だけ発生する。標的機の破壊と主人公の勝敗は同じ着弾時点で判定する。通常の施設破壊と、退避してイオン砲を生き延びる目標を分けた。原作の開始画面にある「イオン砲を用いて研究所を破壊せよ」は、シェリダンの実際の攻撃対象を反映していない。
