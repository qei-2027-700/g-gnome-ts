## 今回の勝敗

ユーザー指定の進行だけを目標にする。

| 条件 | 処理 |
| --- | --- |
| 徒歩で武器4のLaserSiteを研究所へ当てる | 研究所をその1発で破壊する。キリー本人が生きていれば、キリーの無線から約4秒後にキリーが死に、その約1秒後に任務完了 |
| 搭乗したまま研究所を選択し、レーザー1番を射程内で射線が通った状態で10秒押し続ける | キリーを機体ごと破壊し、任務完了 |
| 研究所を別の手段で破壊し、その時点でキリー本人が生きている | キリーの無線から約4秒後にキリーが死に、その約1秒後に任務完了 |
| そのマークか破壊より前に、キリー本人が死ぬ | 任務失敗。既存の失敗処理で強制終了 |
| キリーのASV、またはウィルキンスのTD HAWKだけを破壊する | 脱出して任務は続く。失敗にはならない |

研究所破壊後のキリーの無線は「やられた！ベイビー、ベイビー、ベイビー！」。その無線から約4秒後にキリーが死亡し、さらに約1秒後に任務成功となる。搭乗レーザーでマークした場合は、従来どおりキリーが機体ごと倒れた時点で任務成功となる。

徒歩のときだけ、武器1はPRIF44、武器2はGASHR・5発のまま、武器3にEGGR、武器4にLaserSiteを足す。表示名はヘルメットのEGGRとLaserSite。EGGRの初期2発は、そのヘルメット画面の残数。共通のEGGER初期5発は3-3の武器2のまま変えない。LaserSiteは開始時に充填済みである。同じ画面の0は、打ち切ったあとのバーであり、開始時の残数にはしない。再充填1秒は未計測で、`INFANTRY_LASER_SITE.cooldown`に置く。射程220mはマークと同じ未計測値。照準の線が`genetics-lab`に当たり、射程内で遮蔽されていないとき、その施設の残耐久を1発で削り切る。一覧にない建物、射程の外、途中の遮蔽では壊さない。この射撃ではキリーは即死せず、無線の約4秒後に脚本で死亡する。イオン攻撃でもない。

搭乗レーザーのマーク秒数は、攻略で言われている「10秒照らす」を採用した値で、充填バーの実測ではない。距離220mは未計測。レーザーはユニオン・アサルトの1番、P2MECで、左右2門。長押しは充填完了を待たず、機体別設定の0.6秒間隔で繰り返す。ボタンを離す、選択を外す、距離を出る、射線が切れると秒数は0に戻る。同じ更新でキリー本人が先に倒れている場合は失敗とし、完了にしない。研究所の破壊とその更新でのキリーの死亡が重なった場合も、先に死んでいるものとして失敗にする。攻撃者が敵かプレイヤーかは分けない。キリーのASVは脱出席あり。搭乗レーザーのマークでは機体とキリーが同時に倒れる。研究所の破壊後は、キリーの無線から約4秒後に、搭乗中なら機体ごと、脱出後なら歩兵のキリーが倒れる。その約1秒後に任務が完了する。達成フラグ `completeOnDestroy` は目標データの共通項目で、4-5の任務IDでは分岐しない。付けないマーク目標は、施設を壊しただけでは達成しない。

## 開始と経路

プレイヤーは登録済みの `union-assault`（Union Assault HAWC）に乗る。画面上の名前は Union Assault HAWC / ユニオン軍 アサルト ホーク。ブリーフィングでは、ウィルキンス将軍がこの機体をライオンホークとも呼ぶ。マニュアルの Union Heavy Assault HAWC（Lion）に合わせ、最高速度90km/h、シールド90、エネルギー2200、全高14.7m。装甲はカードにない。実装の240は仮値。質量57tは定義の項目がないので資料だけに残す。武装はP2MEC 2門、TCREAP 各1500発を合算した3000発、VISOM 30発、TCROCK 50発。脱出装置の有無はカードにないので未設定。向きは西（`-π/2`）。

地図に橋の記号はない。開始は配置図の「初期位置」の黄色十字のそばである。十字の中心はブリーフィング画素 (403, 204) 付近で、尾根にかかっている。プレイヤーは十字の南西、尾根の外の暗い通路 (398, 208) に置く。画素 (360, 258) は東側の尾根の南、茶色の地形の外の暗赤で、使わない。以前の通路上の仮位置 (334, 216) も、十字から離れているので使わない。画面下の緑の矢印は開始に使わない。緑の「2」もない。第2ウェイポイントは南の放射能記号で、研究所と同じ画素である。

配置図の赤文字を、同じ緑の「1」と南の放射能記号でブリーフィング画像へ合わせた。配置図の画素 (x, y) は、ブリーフィング画素 (27 + x * 414/948, 48 + y * 412/946) である。敵と施設は、各ラベルに最も近い、尾根の楕円の外の暗い地面に置く。プレイヤー、キリー、ターン、ウィルキンスはラベルには置かず、東側の初期位置に揃える。ロケット2基は、2つの「高台のロケットタワー」の下の高台矩形に置く。中央北のラベルのない黄色のX（ブリーフィング画素およそ (212, 157)）には機体を置かない。

高台の北に敵のユニオンAIP、その東に敵のユニオンASV。高台の西に敵のユニオンTD（登録済みの `union-tactical`）。高台の東にユニオン・セントリーとミーゾン・ガードタワー。北西にスイープタレット、ユニオン・セントリー、ミーゾン・ガードタワー、電力プラント。北東にユニオン・セントリー。西端の第1ウェイポイントに司令部とミーゾン・ガードタワー。南にスイープタレット。スイープタレットに対応する機体種はない。既存の建物 `sweep-turret` を置き、この種は撃たない。名前は Union Sweep Turret。寸法 8×8×6、耐久200は仮。

キリーはユニオンASV、ターンはユニオン・セントリー、ウィルキンスはユニオン・タクティカル・ディフェンス・ホーク。3人とも通信の宛先で、F2・F3・F4。ウィルキンスは将軍で、返答は低い男性の声。F4は「今から向かう！」、F5は目標があっても「後方に回る。オーバー！」。乗る機体を選んでいないF4では、客席のないプレイヤー機へ乗り換えず、プレイヤーのもとへ向かう。4人は東側の初期位置の暗い通路に揃う。ターンは開始の西、キリーはその間、ウィルキンスは開始の南で、互いにこの仮縮尺で80m以内である。配置図の ASV と TD のラベルは敵で、仲間の開始位置ではない。東側ミーゾンの警戒160mの外から開始する。

空のクリア色は、[ユニオン・アサルトの操縦席](../../assets/cockpits/union-assault-hawk.png)の中央窓で、枠と山にかかっていない空（画素 x 560–760、y 300–380、16000画素）の中央値 `#bc8664`（188, 134, 100）である。平均は（188, 131, 100）で、中央値と揃う。同じ横範囲の上の方（y 280–320）は `#a07162` と少し灰色がかり、下の方（y 330–380）は `#c58866` と少し明るい。クリア色は一色なので、空いている範囲の中央値を使う。共有の夕焼け `#c77a1f` は使わない。遠景の霧は火山地形の `#55483b` のまま。

白っぽい尾根は山・谷・崖で、歩行できない。中央の赤い箇所は歩ける高台で、仮の高さ36の矩形7枚にしている。ロケットタワーはそこに2基立ち、足は台の上面にある。基数2は配置図のラベル数で、以前の仮の3基は置かない。台は移動・射線・弾道・経路探索の障害物にしていない。見つかった状態で止まると、UNKPAの誘導（機体の初期値1.2）で弾が当たる。近づいて射程に入れば、プレイヤーも塔を撃つ。尾根で盆地を塞ぐと射線が切れるため、盆地は尾根にしていない。開始はこの高台の上には置かない。ミサイルが台の見た目の中を通り抜けることがある。8画素の階段で、画素 (234, 254) のあたりを含む南縁に切れ込みが残る。

ミーゾン3基は1つの電力プラントを電源にする。プラントを壊すと既存の給電停止で塔は撃たなくなる。それは目標にしていない。警戒距離160mは仮値。機体の初期値は1000mで、そのままでは地図の広い範囲を撃つ。東側の開始から最も近いミーゾンまでは、この仮縮尺で約443mなので、開始直後には警戒の外にいる。ロケットタワーの警戒240mにも、開始の4人は入らない。敵のユニオンTDは高台のすぐ西で、北の塔から約201m、南の塔から約221mにある。仮の警戒240mの内側なので、塔から撃たれる。仲間のウィルキンスのTDが壊れても、それだけでは失敗にならない。

敵の機体と建物のIFFは `4502`。プレイヤーと仲間は `4501`。どちらも仮の4桁。通信距離2000も仮値。
