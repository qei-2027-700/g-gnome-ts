## 基地をScorp ASVから見た参照画像（2026-10-24）

作品：G-Nome／媒体：原作のプレイ画面・ブラウザ再現／対象：Ur-Ulit基地の施設とScorp ASVによる地雷探知／状態：ユーザー説明と提供画像を確認。施設の寸法・座標・個々の建物との対応は未確定。

[「3-3-司令部左側-ul-urit基地突入.png」](<../../vehicles/scope-asv/3-3-司令部左側-ul-urit基地突入.png>)は、ユーザーがScorp ASVに搭乗して基地を見ている画面。左右にロケットタワーがあり、その奥に低い施設、その手前や間に機体が見える。基地の背後には黄土色の岩山が連なり、手前には草地が広がる。コックピットと右下の自機ホログラムは搭乗中のScorp ASVであり、窓外の施設や機体と区別する。

ユーザー説明により、基地には左右のロケットタワーに加え、司令部と地雷原コントロール施設がある。「異例部」は「司令部」を指すと確認した。どの建物が各施設に当たるか、正確な配置・寸法・入口は、この画像だけでは確定しない。当初仮置きした格納庫形状は、司令部や制御施設の原作形状として扱わない。

地雷原は、敵のScorp ASVを奪って搭乗すると地雷を見つけられ、探知表示を見て回避できる。これはユーザーが説明した乗り換えの目的であり、Scorp ASVなら地雷を踏んでも安全という意味ではない。この画像には地雷の探知マークや制御施設の操作結果が明瞭には写っていないため、表示形式・探知距離・制御操作の詳細は画像から確定しない。

[任務仕様](../../../missions/mission-3-3.md)へ施設の役割と乗り換えの目的を反映した。ユーザーの追加指定「倉庫やコンクリートエリアはない」を受け、コンクリート敷地・倉庫扉・外周壁を削除した。草地に低い司令部と横長の地雷原コントロール施設を置き、追加指定により、左右のロケットタワーを施設の手前へ移し、間隔を詰めた。寸法・座標・各施設への外観の割り当ては仮設定。司令部・地雷原コントロール施設の個別機能は未実装。

## 開始機体と基地の方角（2026-10-24追加指定）

[開始画面](3-3-launch-view.png)の左手前は、ユーザー指定によりシェリダンのUnion Tactical Defense HAWC（Rampage）。Union Sentryとは別機種として扱う。中央と右奥にも味方機が見えるが、人物の割り当てと細かい角度は画像だけでは確定しない。

自機は後方から見たUnion ASV。後部の横長の黒い窓と枠、低い車体、左右の履帯、上の武装を識別した。画面左には高い岩肌と緑の斑のある斜面があり、奥には茶色〜黄土色の山が見える。ユーザー指定によりUl-Urit基地は初期の左手であり、正面の敵ASVを目印に一直線に進む配置にはしない。

試作では左を西として基地・地雷原・敵ASVを回転配置した。座標、崖や山の高さ、背面の細部は未実測の仮値。機体の向きは開始時データから再挑戦時も復元する。
