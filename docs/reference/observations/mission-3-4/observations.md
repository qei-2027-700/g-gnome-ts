# 3-4 Ur-Alr：任務地図の色と通行範囲

- 資料：[ユーザー提供の任務画面](../../../../assets/map/3-4/3-4.png)
- 対象：左側の地形図。右側の施設画像は地形の色分けに含めない
- 状態：色と徒歩での通行可否はユーザー説明で確認。輪郭の座標化と3Dフィールドへの反映は未実施
- 記録日：2026-11-11

## 色領域の意味

| 地図上の領域 | 地形と徒歩での通行 | 根拠・残る確認 |
| --- | --- | --- |
| 黒地 | 平地。徒歩で通れる | ユーザー説明。機体ごとの通行条件は未確認 |
| 光る黄緑 | 山などの斜面。通行できない | ユーザー説明。高さと斜面の断面形状は未確認 |
| 中央などの深緑 | 高台。徒歩では入れない | ユーザー説明。機体の進入可否と高さは未確認 |
| 青い線 | 川の表示 | 画像で確認。渡河地点と通行条件は未確認 |

ユーザーによると、敵のロケットタワーやミーゾン・ガードタワーは深緑の高台に配置されていることが多い。この説明だけで、画像内の各高台に塔がある、または特定の印が塔を示すとは決めない。

フィールドを作る際は、[原作画像からフィールドまでの対応手順](../../../gameplay/mission-map-and-waypoints.md#原作画像からフィールドまでの対応手順)に従い、黒地の通路、黄緑の斜面、深緑の高台の輪郭を別々に座標へ写す。表示と徒歩の衝突・経路探索を同じ地形定義に合わせる。地図の縮尺、方位、マーカーの意味、塔の正確な位置は未確認として残す。
