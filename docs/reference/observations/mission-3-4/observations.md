## 色領域の意味

| 地図上の領域 | 地形と徒歩での通行 | 根拠・残る確認 |
| --- | --- | --- |
| 黒地 | 平地。徒歩で通れる | ユーザー説明。機体ごとの通行条件は未確認 |
| 光る黄緑 | 山などの斜面。通行できない | ユーザー説明。高さと斜面の断面形状は未確認 |
| 中央などの深緑 | 高台。徒歩では入れない | ユーザー説明。機体の進入可否と高さは未確認 |
| 青い線 | 川の表示 | 画像で確認。中央よりやや北の第1ウェイポイントに橋があり、西岸から東岸へ渡ることはユーザー確認 |

ユーザーによると、敵のロケットタワーやミーゾン・ガードタワーは深緑の高台に配置されていることが多い。この説明だけで、画像内の各高台に塔がある、または特定の印が塔を示すとは決めない。

橋制御棟は橋の西岸にある。橋付近の機内画像では、左の灰色の建物が橋制御棟、右の赤青の板状の構造物が上がった橋。外部視点の中央はScorp TD HAWCの後ろ姿。開始直後の機内画像では左に山肌が見え、IFF表示は `4033`。地図右下の黄色い印は敵基地と司令部がある最終地点。これらの識別はユーザーによるもの。

第3ウェイポイントに移動すると、TD HAWCのキリーとASVのシェリダンが初めて登場し、その頃から通信で連携できる。追加画像の奥が第3ウェイポイントの基地で、右側の薄い赤色は踏むと機体を破壊する地雷。基地の奥にロケットタワーとビークル発進用エレベーターがあり、基地の施設はシールドジェネレーター、地雷原コントロール施設、司令部の3つ。地雷原コントロール施設を破壊すると地雷が無効になり、煙が上がる。位置関係と役割はユーザー確認。個々の施設の地図上の座標は仮置き。

フィールドは[原作画像からフィールドまでの対応手順](../../../gameplay/mission-map-and-waypoints.md#原作画像からフィールドまでの対応手順)に従い、黒地の通路、黄緑の斜面、深緑の高台の輪郭を別々に座標へ写す。表示と徒歩の衝突・経路探索を同じ地形定義に合わせる。地図の縮尺、開始方位、塔の正確な位置は未確認として残す。
