# 機体性能・武器仕様の調査

- 作品：G-Nome（1997年）再現
- 媒体：PC向けブラウザゲーム
- 対象：4勢力の機体性能、武器、装備構成
- 状態：公開資料による暫定調査。マニュアルを取得しMerc Sentryを照合済み。全項目・実機での照合は未完了
- 調査日：2026-10-22
- 関連：[企画](../../README.md)、[実装計画](../technical/implementation-plan.md)

## 調査の前提と出典

ユーザーから、Merc軍のSentryは速い機体であり、各機体の速度や多様な武器設定を把握するよう指定があった。速度・武装の差を再現対象として扱い、共通の仮性能で最終版を作らない。

### Merc Tactical Defenseの速度照合（2026-10-23）

原作英語マニュアル本文p.51（PDF53ページ目）のMerc Tactical Defense HAWC（Minotaur）を画像で確認し、最高速度72km/h、シールド50、エネルギー1700、全高9.5m、質量26tと照合した。V2の記載も最高速度72km/hで一致する。今回の実装では最高速度の値に加え、敵AIに残っていた18%の速度補正を削除し、無損傷・障害物なしの走行で72km/hに到達することをテストした。

数値は原作と一致させるというユーザー方針を優先する。原作資料で確認できた値と、加速時間・部位耐久など未確認の仮値を混同せず、仮値を一致済みとは扱わない。

### Merc Sentryの確認例

V1・V2では、Merc Sentryの最高速度は85km/h、シールド22、エネルギー1100。V2には全高6.9m、重量17.9t、RAIDレーザー2門とCHUMミサイル1門・25発、自動脱出装置なしとの記載がある。

取得したM1の本文p.50でも、この仕様を確認できた。これによりMerc Sentryの当該諸元・標準装備はマニュアル照合済みとする。実機の挙動は未検証。

実装時は、速度だけを上げるのではなく、耐久・武装・照準可能な範囲・脱出仕様と組み合わせて再現する。加速、後退速度、旋回速度、斜面での挙動は、この最高速度からは決まらないため別に調べる。

## 武器ごとの挙動と未掲載項目

N1には、VISOMをカメラで手動誘導している間は機体を操縦できず、誘導を切って発射する操作もあるとの解説がある。また、デモ版は製品版と武器射程・再充填速度が異なるとされている。製品版の挙動と数値を基準に照合する。

RAID、CETI、LRIP、TAR12、zWASP、SREM、HSSO、UNKPA、GAUS20、GAUS30、PRIF系、GASHR、EGGERなども調査対象。これらについて、W1に数値がないものを他の武器から推定しない。

N1ではECMP・AIM9は説明書やLABにあっても本編では登場しないとの報告がある。記事に載る兵器をすべてキャンペーンに配置せず、「マニュアル掲載」「LAB掲載」「製品版ミッション登場」「デモ版登場」を個別に確認する。

## 実装データに必要な項目

以下は再現のための設計案。資料で存在・値を確認した原作項目と、内部実装に必要な項目を混同しない。

| 定義 | 保持する情報 |
| --- | --- |
| 機体 | 勢力、機種、最高前進・後退速度、加減速、機体旋回、砲塔旋回・仰俯角、当たり判定寸法 |
| 防御・動力 | 部位別装甲、シールド最大値と回復、エネルギー容量と回復、移動・射撃との関係、損傷時の制限、自動脱出の有無 |
| 武器 | 種類、弾速と単位、射程、対盾・対装甲・対人作用、爆風、誘導方式、充填・発射間隔、消費エネルギー |
| 搭載装備 | 武器ID、砲門数、取り付け位置と可動範囲、弾数、弾薬の共有範囲、同時・交互発射、装備バリエーション |
| ミッション配置 | 機体の基本定義を参照し、そのミッション固有の装備・弾数・所属・損傷状態を指定する |
| 調査履歴 | 項目単位の出典、製品版／デモ版、掲載値／実測値、確認日、矛盾、確認状態 |

最高速度の原記録はkm/hのまま保持する。実装を1単位＝1mとする場合は、ゲーム内計算用に3.6で割ってm/sへ変換する。85km/hなら約23.61m/s。物理エンジンの既定値を原作の速度として使わない。

## 照合と検証の順序

1. 製品版マニュアルとLABで、上の機体一覧・数値・武器名・装備構成を照合する。
2. Merc Sentryを最初の比較対象にし、最高速度、加減速、旋回、RAIDとCHUMの発射、強制排出と機体破壊時の処理を確認する。
3. 標準装備と各ミッションの実際の装備を分け、弾数が1門あたりか機体全体かも確認する。
4. 固定した距離で射程、固定した時間で速度・充填間隔を測り、シールド・エネルギー・損傷による変化を比較する。
5. データとゲーム処理を結び付けた後、速度差、射程差、弾切れ、誘導中の操作切り替えを検証する。

現時点では原作値の実測、全武器の網羅、全ミッションの装備照合は未完了。この調査表を暫定仕様として使い、確認できた項目から更新する。


## Scorp Rocket Towerの外観（2026-10-24）

[ユーザー提供の接写](<vehicles/scorp-rocket-tower/3-3-scopeロケットタワー.png>)に基づき、青緑の多角形の胴体、黄土色の帯とパネル、外へ開く灰色の支柱、幅広い傘状の金属屋根と中央の突出部を描画する。以前の柱と左右の大きな発射ポッドの形状を置き換えた。

形状の共通定義は`src/game/content/vehicle-shapes.ts`、配色は`vehicles.ts`、描画とホログラムは`src/game/presentation/`で管理する。支柱の命中領域を足し、屋根・胴体・発射部・左右の支持部を分ける。基礎は照準・射撃反動で回さず、命中領域も同じ固定方向を使う。移動用の接触領域は張り出す支柱を含む。

全高12mと各寸法、8角形・支柱4本・背面の細部は試作値。速度・耐久・武装・弾数・最小射程などの性能値は今回の外観変更では変更しない。確認できた特徴と未確認箇所は[観察記録](observations/mission-3-3/observations.md#ロケットタワーの接写2026-10-24)を参照。

## Union Tactical Defense HAWCの識別と実装（2026-10-24）

[マニュアル本文p.22](manuals/manual-p22.png)の下段はUnion Tactical Defense HAWC（Rampage）。上段のUnion Sentry（Prowler）とは別機種である。最高速度60km/h、シールド36、エネルギー1200、高さ7.5mを共通定義へ登録した。装備はP2MEC×2、TCREAP×2・各150発、TCROCK・10発、SAG5T・26発。双砲・双銃は各1スロットにまとめ、TCREAPは300発として扱う。

3-3の左手前でシェリダンが搭乗する。幅広い武装部、中央の暗いキャビン、太い脚をSentryと分け、灰色〜くすんだ金属と赤褐色の武装部を参照画面に合わせた。装甲値、可動範囲、歩行演出、AI、細かな形状と塗装は試作値。P2MECは既存調査表の最大射程315m・最大威力18・消費エネルギー2を使うレーザーとして追加し、充填時間・発射間隔・飛翔速度は仮設定とする。


Merc機の脱出装置は、ユーザーの最新指定に基づきMerc Sentry・Merc Tacticalとも`ejectionSeat: false`へ反映した。これはGASHRへの耐性を意味しない。ガスでは生存する歩兵が地上へ退出し、NPC搭乗機の破壊では自動脱出しない。主人公の扱いと歩兵の青・白・黒・グレーの配色は[歩兵仕様](../gameplay/infantry.md#merc機の脱出装置と歩兵の配色共通仕様2026-10-24)を参照する。
