## 実装への反映

### Scorp ASVの正面デザイン

[ユーザー提供のLAB画面](../scope-asv/user-scorp-asv-lab-2026-10-24.png)に表示されるScorp Armored Support Vehicle（Stinger）を参照した。画面全体はミッション前メニューのデザイン資料も兼ねる。今回の変更対象は3-3のScorp ASVで、メニュー画面の実装は含めない。

左右に大きく離れた幅広の履帯、中央下の深い空間、傾斜した車体装甲、上部の小さな武装部を反映した。白〜グレーの装甲と黒い履帯を基調に、中央前面を青緑、縁と斜めの補強部を黄土色にした。履帯の正面に横桟と縁のレールを追加し、ホログラムも中央下の空間が見える輪郭に分けた。

主要寸法は `src/game/content/vehicle-shapes.ts`、配色は `src/game/content/vehicles.ts` の `SCORP_ASV_PALETTE` に置く。描画と命中判定で同じ寸法を使い、履帯の前後位置も揃えた。色コード・幅・奥行き・背面の細部は画像から補った試作値。最高速度64km/h、シールド24、エネルギー1200、全高4.2m、武器性能は今回の外観変更で変えていない。

描画・命中判定・機体同士の接触・VISOMによる誘引の関連テスト36件と、型チェック付きの本番ビルドが成功した。Chromeで正面・斜めを確認した。確認画面と画像・JSON記録は `.artifacts/scorp-asv-design/`、ログは `.artifacts/scorp-asv-design-tests.log` と `.artifacts/scorp-asv-design-build.log`。全体テストは今回の外観変更では再実行していない。

### 共通処理と残る試作仕様

速度・シールド・エネルギー・高さを共通の `content/vehicles.ts` に登録した。車体と履帯の配置は `content/vehicle-shapes.ts` を描画と当たり判定で共有する。履帯には従来の部位ID `leftLeg`・`rightLeg` を使い、既存の損傷状態と表示を維持する。歩行の脚振りや上下動は適用しない。自機・目標のホログラムも履帯式に分ける。

Union ASVのTCROCKは試作では合計60発を1枠で扱う。Scorp ASVのzWASPは左右各800発を独立管理する。武器は機種の配列で管理し、入力・表示は最大4枠に対応する。連装武器の同時発射の厳密な再現は未完了。

車体の幅・奥行き、装甲耐久、塗装の色コード、AI設定、TCREAP・TCROCK・SREM・UNKPA・zWASPの射撃用パラメータは試作値であり、原作値との照合済みとは扱わない。Scorp ASVの配色と正面形状は上記のカラー画像を参照する。3-3検証版のUnion ASVは任務限定の例外としてVISOMを搭載し、標準装備を変更しない。

ASVの図は保存済みPDFを参照し、今回画像化した確認用ページはGit対象外の `.artifacts/bysom/` に置く。

作品：G-Nome／媒体：ブラウザゲーム／対象：Union ASVの操縦席／状態：ユーザー提供画像を反映。元画像の右下の青い物体は対象外。

[参照画像「3-3-union-ASV内.png」](../union-asv/3-3-union-ASV%E5%86%85.png)はUnion ASVの機内とユーザーが指定した。赤茶色の上部装甲、左右の大きなモニター、中央のIFF、横長の窓、窓下の折れた装甲、左右に傾斜した下部計器盤と中央の楕円形レーダーを再現対象とする。画像の右下に重なる青い物体は操縦席の一部に含めない。

操縦席の金属部分は元画像を参照する表示層とし、窓の外・モニター・既存の数値・右下の青い物体をマスクで除外した。窓の外は実際の3D描画を透過表示し、武器名と残弾、IFF、照準、出力、目標の損傷、自機の損傷・エネルギー・シールド、レーダーはゲーム状態から表示する。原画像の武器名・IFF・残弾を現在値として固定しない。右上のモニターには任務情報と味方の状態を表示する。通信応答の字幕は表示しない。

Union ASVに搭乗した機内視点だけに適用し、外部視点やVISOM視点では表示しない。Scorp ASVとUnion Sentryの機内表示へ一律適用しない。実装は`src/game/presentation/asv-cockpit.ts`と`src/asv-cockpit.css`、計器との接続は`src/main.ts`。武器性能・機体性能・ミッション固有装備は今回の見た目調整では変更していない。画面比率への拡縮と、元画像から読み取れない細部には試作上の補完がある。


## Scorp ASVの機内表示（2026-10-24）

作品：G-Nome／媒体：ブラウザゲーム／対象：Scorp ASVの操縦席と武器枠／状態：ユーザー指定を反映。

[ユーザー提供の機内画像](../scope-asv/3-3-%E5%8F%B8%E4%BB%A4%E9%83%A8%E5%B7%A6%E5%81%B4-ul-urit%E5%9F%BA%E5%9C%B0%E7%AA%81%E5%85%A5.png)を参照し、金属の支柱、左右の格子、露出した配管、赤茶色の下部装甲と金色の縁取りを画像層で表示する。左右のぼかされた余白、右下の青い人物、青・紫の画面端、元の窓外の景色と照準・地雷・数値は除外する。窓は現在の3Dフィールドを透過表示する。

左上に武器1・2のzWASP（各800発）、右上に武器3のSREM（20発）と4のUNKPA（10発）を表示する。吊り下げ式IFF、傾斜した目標・自機モニター、中央の縦長レーダーは画像の座標に合わせる。残弾・射撃待機状態・IFF・目標・部位損傷・エネルギー・シールド・レーダーはゲーム状態に連動する。表示範囲は1422:1000で中央配置し、計器と窓枠を同じ比率で拡縮する。余白は黒。Scorp ASVの機内だけに適用し、外部・徒歩・VISOMでは解除する。

`src/game/presentation/scorp-cockpit.ts`、`src/scorp-cockpit.css`と`src/main.ts`で表示する。残弾の正本は各機体の`slotAmmo`。従来の`ammunition`と`ammo`は合計値の読み書きとして維持し、合計への代入時は同名武器の各枠へ均等配分する。射撃・AI・HUD・搭乗前の装備表示はスロットを参照する。再搭乗では残弾を保持し、任務の再挑戦では初期化する。キー変更設定と武器・機体の性能値は維持する。

検証画像とJSON記録、全体テスト・ビルドのログは`.artifacts/scorp-cockpit/`に保存する。専用の一時検証画面でScorp搭乗と画面比率を確認し、通常任務でUnion ASV・VISOM・徒歩の表示切り替えを確認した。3D外観と基地配置は今回の対象に含めない。


Scorp ASVのSREM（武器3）は左、UNKPA（武器4）は右に配備する。モデルにある左右の武装部の共通座標を発射点へ使い、AIの射線確認と実際の発射位置を揃える。砲塔の向きに合わせて左右の発射点を回転し、両方を右側から発射していた処理を修正した。装弾数・弾速・威力は変更しない。発射位置と旋回後の左右関係は自動テストで確認する。
