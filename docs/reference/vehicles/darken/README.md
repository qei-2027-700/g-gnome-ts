# Darken Sentry HAWCの観察資料

ユーザー提供の[外観画像](../../../../assets/hawk-building/darken/1-2-darken-sentry01.png)と[複数機が写る画像](../../../../assets/hawk-building/darken/1-4-fsada.png)を確認した。Sentryは、狭い橙色の胴体と、その上の頭部から左右へ水平に張り出す緑色の箱形発射口を持つ。頭部の上には青い縦長の部品があり、脚は橙色と灰色に分かれた細い2本である。後方からの姿は[別画像](../../../../assets/hawk-building/darken/1-4-asdfsafsa.png)で確認できる。各画像の地形や塔は機体の一部ではない。

[機内画像](../../../../assets/hawk-building/darken/1-2-darken-sentry-cocpit.png)の武器表示はCHUM 50発とRUPP。[別の機内画像](darken-sentry.png)にもCHUMとRUPPが表示される。これらは画像内の装備表示であり、全任務で同じ初期残弾になることまでは確認できない。

外観モデルは上記の輪郭と配色を基にした簡略形状で、緑色の発射口は頭部の高さで左右に接続し、脚は橙色と灰色の細い柱として描く。脚の幅、発射口の奥行き、灰色の色は画像の比率からの試作値で、原作の実寸は未計測。機内では[保存済みの画像](../../../../assets/cockpits/darken-sentry-hawk.png)から金属フレームを表示し、窓外の地形、武器・IFF、レーダー、ホログラムは現在のゲーム状態を表示する。背面の細部、砲身内部、原作での正確な寸法は未確認。

## Tactical Defense HAWC（Stalker）

ユーザー提供の[機体紹介画像](../../../../assets/hawk-building/darken/darken-td-front-hawk.png)、[側面](../../../../assets/hawk-building/darken/1-5-td-hawk-横.png)、[側面の近景](../../../../assets/hawk-building/darken/1-5-td-hawk-横2.png)、[斜め](../../../../assets/hawk-building/darken/1-5-td-斜め.png)、[背面](../../../../assets/hawk-building/darken/darken-td-behind.png)では、左右に大きな灰色の武器ポッド、中央に細い金色の胴体、その上の小さい頭、長い金色の脚と足が見える。ポッド正面には赤い横線が3本ある。背面は縦の灰色ポッドと暗い中央、その上の小さい頭、金の太もも、灰色のすね、金の踝と暗い足裏である。側面と斜めは歩行中で、胴が大きく前へ倒れ、腰が高く、膝が深く曲がっている。最高速度67.5 km/h、シールド50、エネルギー1500、高さ7.9 m。武装はHOMP11レーザー2門とDASY機銃2門で、機銃は各200発。外観は胴体幅を1とした試作比で、後ろからは縦の灰色ポッド、暗い中央、その上の小さい頭と薄い金、金の太もも、灰色のすね、金の踝と暗い足裏である。赤い横線3本はポッドの前面にある。背面画像ではポッド幅が約1.1で中央の隙間が約3あり、脚と足はポッドより細い。ポッド幅・左右位置・奥行き・脚と足の幅は、その背面に合わせた試作値。停止中も胴を前へ倒し、腰を高く保つ。膝は前へ鋭く折れ、金の太ももが股から前下方へ出て、灰色のすねが踝まで下りる。足は上面が金、底が暗い前後に長い板で、左右対称に股より前の地面へ平らに付く。背面画像の足の前後差は歩行の一歩である。太もも 3.15、すね 1.7、停止時に足を股より 1.75 前へ出す値は、胴体幅を 1 とした試作値。この前傾と腰の高さは側面の近景に合わせた試作値。メートル寸法、ポッド内部と砲身の細部は試作のまま。装甲値、旋回・加速は画像から確認できないため試作値を維持する。HOMP11の射程・対装甲威力・消費エネルギーは[武器資料](../../vehicles-and-weapons.md#武器の数値設定)を参照し、充填時間は仮値とする。ユーザー指定により、レーザーの弾・銃口・着弾は黄色にし、飛翔速度はRUPPなどの黄色レーザーと同じ72 m/sにする。READY表示を待たずに発射でき、射撃ボタンの長押し中は0.25秒間隔で連射する。この発射間隔は試作値。

[機内画像](../../../../assets/cockpits/darken-sentry-hawk.png)の左側にはTactical Defense HAWCのホログラムが表示されている。機内の金属フレームはこの画像を使い、武器表示とホログラムを搭乗中の機体に合わせて描き直す。画像内のCHUM 40発とRUPPは、Tactical Defense HAWCの武装として扱わない。
