# Merc AIP（Razor）とCruiser（WidowMaker）

- 作品：G-Nome再現／媒体：ブラウザゲームの原作資料
- 対象：2-6の敵AIPと無人Cruiser
- 状態：原作マニュアルとユーザー指定に基づく試作
- 関連：[2-6の仕様](../../../missions/mission-2-6.md)、[英語マニュアル](../../manuals/G-Nome_Manual_Win_EN.pdf)

本文p.53のMerc Airborne Insurgence Platform（Razor）はホバー機。ユーザー指定では緑の菱形で、地面の近くを浮いて移動し、移動中に少し上下へ揺れる。高空の飛行機の翼・尾翼で代用しない。GASHRで操縦者が排出されると、移動速度と高度を徐々に下げて接地する。描画・弾の発射位置・目標高度・命中領域は同じ現在高度を参照する。再搭乗後は徐々に浮遊高へ戻る。機体高3.7mと、試作用の浮遊高0.8m・上下動約±0.15mを分ける。原作値の速度・シールド・エネルギーと単装のTAR12・TCREAP・DASYを反映する。発射間隔・AI・装甲耐久・細部は未確認。

本文p.51のMerc Cruiser HAWC（WidowMaker）は高い胴体と細長い複数の脚を持つ。マニュアルの小さな画像から確認できる輪郭をモデルとホログラムへ反映する。速度45km/h、シールド40、エネルギー1000、高さ12.4m、FLECH 2門・各150発とGAUS20を使う。装甲・細部形状・配色は試作値。

どちらも自動脱出なし。ミーゾン・ガードタワーの生存脱出とは区別する。資料PDFは複製せず参照し、確認用の画像と実ブラウザ画面は`.artifacts/mission-2-6/`に保存する。


## ミーゾンタワーの提供画像に写るAIP（2026-10-29）

ユーザーが[ミーゾンタワーの機内画像](../../../../assets/cockpits/merc-mison-guard-tower.png)にMerc AIPも写っていると指定した。右前方の低い機影を参照し、横へ尖った菱形の船体と暗い傾斜した中央キャノピーへ調整した。既存の緑系の配色・低空浮遊・移動中の上下動は維持する。遠方の小さな機影なので細部は仮形状とし、武装と性能は変更しない。船体・操縦席の描画は既存の共有寸法内に収め、命中領域の寸法は維持する。ホログラムも低い菱形の輪郭へ合わせる。


## AIPのレーザー色（2026-10-30）

ユーザー指定により、Merc AIP（Razor）のレーザーTAR12は黄色にする。飛翔するレーザー弾・銃口の光・着弾の光に同じ黄色を使い、プレイヤー・味方・敵で共通にする。緑色の機体と、TCREAP・DASYの赤い射撃は既存の表示を維持する。武器性能は変更しない。


## Merc AIPの旋回と慣性（2026-10-30）

ユーザーの「アジリティが強すぎる」という指定により、Merc AIPのAIの機体旋回を最大0.55rad/s（約31.5度/秒）、照準旋回を最大0.9rad/sへ抑える。大きく向きを変える時も急に振り向かず、大きな弧を描く。敵の迎撃移動と、味方・奪取機の追従や攻撃移動に同じ上限を使う。

Merc AIPだけ、加速の応答係数を1.8から0.7、減速の応答係数を1.4から0.65へ下げ、発進と切り返しを緩やかにする。操縦者が乗った場合も同じ加減速を使う。GASHRで浮遊機能が止まった後は、従来どおり減速して接地する。最高速度103.5km/h、浮遊高、武器性能は維持する。徒歩・HAWC・Union AIPの応答は変更しない。数値は使用感に合わせた試作値で、原作アニメーションからの実測値ではない。設定元は`src/game/simulation/movement.ts`の`MERC_AIP_RESPONSE`。
