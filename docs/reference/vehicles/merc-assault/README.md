## 側面画像から反映した特徴（2026-10-29）

低く前後に長い胴体と、青紫の上面・灰白色の外板・暗い窓を持つ。脚は左右の前後に各1本、合計4本。胴体から外側の高い関節へせり上がり、そこから細長い下脚が接地する、蜘蛛のような輪郭を再現する。上脚の節には帯状の外板を付ける。元画像の照準・ゴーグル枠・右下の人物画像を機体の装飾と解釈しない。

2本脚の共通モデルを専用の4脚モデルへ置き換えた。脚の位置は`vehicle-shapes.ts`の共有寸法から求め、移動時は対角の脚を交互に上げる。停止時は4本とも接地する。上脚・下脚・足先は左右の損傷部位へ割り当て、前後の脚は従来の左右別耐久を共有する。命中領域は脚の向きに沿う傾いた箱で近似し、建物との接触距離も同じ寸法から求める。

自機・選択目標のホログラムにも、胴体より高い関節と前後4本の脚を反映する。側面画像で見えない背面の細部と正確な断面、実寸比率は未確認で、最高速度・武器威力・エネルギーなどの性能値は変更しない。

## 黄色のレーザー

ユーザー指定により、Merc AssaultのRUPPレーザーは黄色。飛翔するレーザー、発射光、着弾光を黄色にする。RAIDなど他の赤いレーザー、CETIの緑、GAUS系の青は既存の扱いを維持する。黄色の正確なRGB値は実測していない。

## 実装と検証

形状と脚の座標は`src/game/content/vehicle-shapes.ts`、モデル・歩行・レーザーの描画は`src/game/presentation/renderer.ts`、ホログラムは`hologram.ts`、脚の命中領域は`src/game/simulation/parts.ts`で管理する。低い操縦席と武装の高さへ視点・レーザーの発射位置も合わせる。

4本の脚と接地、対角の脚上げ、前後左右の脚への命中、黄色のレーザー・着弾光、搭乗・降機・2-6の建物との接触を検査する。実ブラウザでは専用の確認画面で外部斜め視点を確認する。ログと画面は`.artifacts/merc-assault-four-legs-20261029/`へ保存する。

## 歩行時の横揺れ（2026-10-30）

ユーザー指定により、中央の胴体は左右へ振らず、傾けず、高さも保つ。歩行時は4本の脚の高い関節を内外へ最大0.95ずつ、上下へ最大0.55ずつ振る。持ち上げた足先は外側へ最大1.1、上へ最大0.95運び、接地中は横へ滑らせない。対角の脚が交互に動き、停止すると元の姿勢へ滑らかに戻る。振幅は試作値で、原作からの実測値ではない。

これはMerc Assaultの外観上の歩行演出。機体の実移動と照準方向、ほかの機種は変更しない。機内では枠と計器を固定し、窓の外の景色だけを左右へ揺らす。その表示は[操縦席の仕様](../../../gameplay/cockpit-hud.md#merc-assault-hawcの操縦席2026-10-29)に従う別の表示演出とする。
