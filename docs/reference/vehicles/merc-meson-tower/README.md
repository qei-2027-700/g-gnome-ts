# Merc Meson Guard Tower

- 作品：G-Nome再現／媒体：ブラウザゲームの原作資料
- 対象：Mercミーゾン・ガードタワーの識別、外観、武装と脱出
- 状態：マニュアルとユーザー提供画像を参照。2026-10-30の追加画像で外観を確認、追加の形状・塗装はモデルへ未反映
- 関連：[2-6の任務仕様](../../../missions/mission-2-6.md)、[英語マニュアル](../../manuals/G-Nome_Manual_Win_EN.pdf)

マニュアル本文p.54のMeson Towerを対象とする。細い胴部、上部が広がった頭部、前方へ伸びる単装砲をモデルとホログラムへ反映する。ロケットタワーの多連装発射口とは区別する。白黒画像から配色を確定せず、背面・細部・全高12mは試作とする。機内はユーザー提供画像を参照する。主要寸法は`src/game/content/vehicle-shapes.ts`を共有し、砲の旋回・上下照準を描画と命中領域へ反映する。

武装はGAUS30を1門。ユーザー指定により青い静かなレーザーとして表現し、Merc所属でも塔の破壊時には搭乗者が生きて脱出する。通常のMerc HAWCの脱出装置とは別の仕様とする。電力施設からの給電、性能値と未再現部分は任務仕様を参照する。

通常の退出・破壊時の生存脱出は、[建物・固定設備の共通仕様](../../../gameplay/infantry.md#建物固定タワーからの地上退出共通仕様2026-10-29)に従い、塔の脇の地上へ直接出る。上空へ射出せず、着地待ちなしですぐ移動できる。

## 射撃と給電の共通仕様（2026-10-29）

ユーザー指定により、ミーゾン・ガードタワーは給電が続く限り回数制限なく射撃できる。弾数を消費せず、蓄積エネルギーの不足でも射撃を止めない。発射間隔と充填時間は維持し、連続して無制限に同時発射する意味にはしない。

機種定義の`powerSupply: 'external'`をプレイヤー・味方・敵の共通処理で使用する。任務で`powerSourceId`を指定した塔は、接続先の電力プラントが破壊されると射撃・充填を停止する。プラントを配置しない任務では接続指定を付けず、給電は継続する。2-6にもMerc電力プラントを配置し、2基の塔を接続する。

GAUS30自体の通常のエネルギー消費値は維持する。無制限の射撃はミーゾンタワー側の給電方式で決まり、同じ武器を載せた通常の機体を無制限にはしない。検証ログは`.artifacts/meson-continuous-power-20261029/`へ保存する。

## 射撃速度と青い光線の調整（2026-10-29）

ユーザー指定により、GAUS30の充填・最短発射間隔を1.2から1.6秒、飛翔速度を当初1000から800m/sへ調整し、追加指定で600m/sへ下げた。射程800m、威力、外部給電による回数制限のない射撃は維持する。マニュアル掲載の速度1000と、今回のゲーム内の調整値600を区別する。

描画は長さ24m・幅0.12m・厚さ0.008mの薄い板状の光線とする。群青色にしてほしいというユーザー指定により、光線・発射口・着弾の光を、赤みを含む濃い青`#2015a6`へ統一する。白や水色の芯は重ねない。外部ビューで薄い側面しか見えなくなる問題を避けるため、光線の進行軸を維持したまま板の面をカメラへ向ける。遠方では画面上の幅を最低3ピクセルへ補正し、高密度ディスプレイでも同じ見え方を保つ。照明や霧によって色が薄くなるのを抑える。GAUS20の従来の描画とは分ける。数値は見え方を調整するための試作値であり、原作の実測値ではない。

全体の手動旋回・上下照準・マウス照準は[操作仕様](../../../technical/keybindings.md#手動照準の細かさ2026-10-29)の細かい設定を使う。検証ログと実ブラウザの確認画像は`.artifacts/fine-aim-meson-20261029/`へ保存する。

元のPDFを複製せず、上記の共通資料を参照する。今回のレンダリング画像と実ブラウザ画面は`.artifacts/mission-2-6/`へ保存する。


## 提供画像に基づく機内（2026-10-29）

ユーザーが[merc-mison-guard-tower.png](../../../../assets/cockpits/merc-mison-guard-tower.png)を、この塔の機内とMerc AIPが写る画像と指定した。機体の識別はこの指定を優先する。濃紺の窓枠、銀色の斜め支柱、左右の計器と中央レーダーを[専用機内表示](../../../gameplay/cockpit-hud.md#mercミーゾンガードタワーの機内2026-10-29)へ反映する。画像の数値・風景・敵は固定表示に使わない。

タワーの射撃には反動を付けない。本体・砲身の後退や揺れ、射撃によるカメラの揺れを発生させず、照準操作による旋回・上下動は維持する。被弾時の表現は別に扱う。GAUS30の発射光は直径0.6m・0.14秒の試作値とする。

狙いやすさの追加調整として、GAUS30の機体・歩兵への命中判定を各方向45cm広げる。射程・威力・弾の物理半径は維持し、岩や建物の遮蔽判定にはこの余裕を加えない。明確に外れた弾は外れる。目標マーカーの位置は毎フレーム更新し、手動で左右・上下を向いた場合は自動追尾を解除して、選択した目標を維持する。

## 徒歩視点からの外観追加資料（2026-10-30）

出典はユーザー提供の[merc-mison-guard-tower3.png](../../../../assets/cockpits/merc-mison-guard-tower3.png)。ユーザーが窓外の対象をMercミーゾン・ガードタワーと指定した。PRIF44・GASHRと徒歩用の枠が表示されており、塔の外観を地上から見た資料として扱う。塔の機内フレームの参照画像とは分ける。

画像で確認できる外観は次のとおり。

- 頭部は幅広く、下側が支柱へ向かって絞られた多面体。手前の面に濃紺の大きな装甲面があり、縁や上面には灰色の部材が見える。
- 頭部上に灰色の砲身・機構が載り、黒い砲口が画像の左上側へ向く。単装砲というマニュアルの識別を維持し、砲口内の暗い部分を別の砲と数えない。
- 頭部の下は細くくびれ、灰色の支柱・脚元が地面へ向かって広がる。支柱には縦長の赤い模様と暗い継ぎ目が見える。
- 塔全体は角張った装甲面で構成される。正確な面数、裏面、模様の意味、実寸はこの画像から確定しない。

画面左寄りに大きく写る手前の塔があり、その右奥に同形の小さな塔が見える。さらに右奥には青い縦長の構造物と、赤い面・斜面・上部突起を持つ構造物が並ぶ。これは撮影方向から見た位置関係であり、マップ上の東西・南北や正確な距離には置き換えない。2基の塔の見かけの大きさの差を、そのまま実寸の差と扱わない。

赤い選択枠と「62m」の表示は奥の小さな塔の周囲にある。手前の大きな塔までの距離として使わない。右奥の構造物が、画像2で識別した要塞・電力プラント・Latlon通信基地のどれに対応するかは未照合とする。[2-6の建物識別](../../../missions/mission-2-6.md#参照画像の建物識別ユーザー指定2026-10-29)と併用し、今回の画像だけで各施設の名称や絶対座標を入れ替えない。

今回は外観・位置関係の資料を追記した。実装中の全高12m、施設座標、塔同士の間隔は引き続き試作値とする。


## merc-mison.pngに基づく専用外観（2026-10-30）

ユーザー指定の[merc-mison.png](../../../../assets/merc-mison.png)をMercミーゾン・ガードタワーの外観の基準にする。Scorp側の[緑・青緑のミーゾンタワー](../scorp-meson-tower/README.md)とは別のモデルにする。

頭部は上が広く、下へ絞られた濃紺の多面体。灰色の上縁、上端の暗い縦の切り込み、小さな金属の留め具、灰色の屋根部品を加える。屋根上には単装砲と黒い砲口を置く。下部は細い腰から地面へ広がる風化した灰色の台座とし、正面に赤い縦の塗装片と暗い小窓・継ぎ目を付ける。Scorp側の斜めに張り出す支持材を流用しない。

形状の比率を合わせるため、試作上の全高12mは維持し、台座を高さ6.1m、頭部を幅6.8m・高さ4m・奥行き6.4mへ調整した。砲身は長さ3.4mとする。八角形の面構成、裏面、各寸法、風化模様は画像をもとにした試作で、原作の実測値ではない。

主要寸法は`vehicle-shapes.ts`で共有し、台座・頭部・屋根・砲身と砲の基部を命中領域へ対応させる。砲口と実際のGAUS30発射位置も同じ形状定義を使う。ホログラムの輪郭を新しい比率へ合わせ、部位ごとの損傷表示を維持する。機内の緑色照準、群青色のGAUS30、武器性能、給電と退出のルールは既存の仕様を使う。
