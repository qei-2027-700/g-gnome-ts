## 試作モデルへの反映

| 部分 | 表現 |
| --- | --- |
| 外装・肩・脚の縁 | 白 |
| 肩上部・脚の装甲パネル | 水色 |
| 接続部・帯・フレーム | グレー |
| 上部キャビン・開口部・足 | 黒 |

従来の茶色の外装とオレンジの発光窓を変更した。上部キャビンは下側が狭い形にし、肩の武装を高く配置した。ホログラムも上部と腰の幅の違いを反映する。

配色は `src/game/content/vehicles.ts` の `MERC_TACTICAL_PALETTE`、主要寸法は `vehicle-shapes.ts` に置く。3D表示と部位の命中判定は同じ寸法定義を参照する。色コード・寸法・背面の細部は試作値で、原作のモデルデータを復元したものではない。最高速度・全高・武器性能は今回の外観変更では変更していない。

## 確認

既存の開発サーバーで、参照画像と正面・斜めのモデルを比較できる `.artifacts/tactical-design/review.html` を用意した。Chromeで正面の配色・輪郭を確認した。部位の損傷表現、キャビン・肩・腰・脚の命中領域と、上半身旋回後の命中領域は自動テストで確認する。

## 走り方（確定仕様・2026-10-24）

ユーザー指定により、走行時は後方視点から足裏が見えるほど足を跳ね上げ、どたどたと走る。Merc Tactical Defenseだけに適用し、遊脚の持ち上げと膝の曲げ、足首の回転、胴体の上下動・左右の揺れを強める。支持脚の足裏は地面へ向け、停止時は足首を通常姿勢へ戻す。足裏には溝の表現を加える。

歩幅7.4m・最大持ち上げ2.15m・遊脚の足裏の傾き約80度は、後ろ姿の参照画像に見える大きな足上げを出すための調整値。原作のアニメーションデータから得た値ではない。歩行位相は実際の移動距離から進め、停止や一時停止で足踏みし続けない。最高速度・射撃性能は変えない。背面装甲と足の走行ポーズはMerc Tactical Defenseだけに適用する。設定元は`src/game/presentation/renderer.ts`と`src/game/presentation/locomotion.ts`。
