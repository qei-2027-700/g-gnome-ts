# Scorp Sentry HAWCの観察資料

[機体カード](../../../../assets/reference/scope-sentry/scope-sentry-hawk.png)の正面を確認した。灰色の胴の上に暗い青の丸い頭があり、左右の肩から黄橙色の上腕と淡い緑の前腕が脚の付け根まで下がる。脚は太く、腿は橙色、すねは灰緑、足は白い爪先で外側へ向く。胸の中央は青灰色。

外観モデルはこの輪郭に合わせてある。頭の幅と高さ、腕の長さ、脚の幅、各色はカードの比率からの試作値で、原作の実寸は未計測。速度56.25 km/h、シールド42、エネルギー800、高さ6.3 m、武装（CETI、zWASP、SREM）はカードの記載に合わせた既存値のまま。背面、腕の内側、爪先の正確な角度は未確認。以前の機内観察は[別画面](sc-%202026-10-24%2023.05.45.png)。

機内の金属フレームは[保存済みの画像](../../../../assets/cockpits/scope-sentry-hawk.png)を使う。窓の外、武器の充填と残弾、IFF、左右のホログラム、照準・速度バー・方位目盛りは現在のゲーム状態から描く。画像の残弾200・20とIFF 5562、窓の地形は固定表示にしない。中央下の木目の計器台はレーダーの位置である。写真に皿が写っていないことは、レーダーを省く理由にしない。規則は[写真の計器を固定表示にしない](../../../gameplay/cockpit-hud.md#写真の計器を固定表示にしない)。現行の枠は `.radar-instrument` を隠しており、この規則には未対応である。中央の窓に加え、左右の支柱の外側に写る景色も同じように開ける。赤褐色の支柱と側面の壁、計器台は残す。停止中の速度バーは空の黄色枠になり、画像の塗りつぶしは速度がゼロでないときの状態である。画素単位の一致は未確認。
