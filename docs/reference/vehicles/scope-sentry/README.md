# Scorp Sentry HAWCの観察資料

[機体カード](../../../../assets/hawk-building/scope/scope-sentry-hawk.png)の正面を確認した。灰色の胴の上に暗い青の丸い頭があり、左右の肩から黄橙色の上腕と淡い緑の前腕が脚の付け根まで下がる。脚は太く、腿は橙色、すねは灰緑、足は白い爪先で外側へ向く。胸の中央は青灰色。

外観モデルはこの輪郭に合わせてある。頭の幅と高さ、腕の長さ、脚の幅、各色はカードの比率からの試作値で、原作の実寸は未計測。速度56.25 km/h、シールド42、エネルギー800、高さ6.3 m、武装（CETI、zWASP、SREM）はカードの記載に合わせた既存値のまま。背面、腕の内側、爪先の正確な角度は未確認。機内画像は[別画面](sc-%202026-10-24%2023.05.45.png)。
