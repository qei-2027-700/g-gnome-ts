# Scorp Assault HAWC

- 根拠：[3-5の機内画像](<../../../../assets/map/3-5/sc- 2026-11-12 0.43.29.png>)
- 対象：3-2に配置するScorp Assault HAWC

提供画像の武器欄には、1番から順にzWASP、LRIP、VISOM、SREMが表示される。残弾表示はzWASPが1000、VISOMが20、SREMが80。LRIPレーザーはユーザー指定により左右二丁から緑色の弾を同時に射出する。発射間隔は連射性能の調整により0.7秒から0.6秒に短縮した試作値。LRIPの射程・威力・充填速度は資料から読めないため試作値。脱出装置があることもユーザー指定による。

外観の根拠は[斜め前方の画像](<../../../../assets/map/3-5/sc- 2026-11-12 0.45.32.png>)と[後方の画像](<../../../../assets/map/3-5/sc- 2026-11-12 0.44.18.png>)。前方へ伸びる低い船体、黄のキャノピー、上向きの中央砲、左右3本ずつの脚を反映した。背面の細部と歩行周期は画像から確定できないため試作形状・動作とする。性能値はMerc Assault HAWCを基にした仮値のまま。脱出装置はユーザー指定で有効にしている。

機内ビューには[提供画像](../../../../assets/reference/scope-assault/scope-assault-hawk.png)から操縦席の金属枠を使用する。窓、武器表示、IFF、ホログラム、レーダーはゲーム状態から描画する。`?previewVehicle=scorp-assault` で搭乗状態から確認できる。
