# Scorp Assault HAWC

- 根拠：[3-5の機内画像](<../../../../assets/map/3-5/sc- 2026-11-12 0.43.29.png>)
- 対象：3-2に配置するScorp Assault HAWC

提供画像の武器欄には、1番から順にzWASP、LRIP、VISOM、SREMが表示される。残弾表示はzWASPが1000、VISOMが20、SREMが80。LRIPレーザーはユーザー指定により緑色で描画する。LRIPの射程・威力・充填速度は資料から読めないため試作値。脱出装置があることもユーザー指定による。

現行の外観と性能はMerc Assault HAWCを基にした仮実装。機内画像はScorp Assaultの操縦席であり、外観の正面・背面形状を示す資料ではない。
