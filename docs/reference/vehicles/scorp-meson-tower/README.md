参照元はユーザー提供の[4-2-scope.png](../../../../assets/reference/missions/4-2-scope.png)。右側の機体プレビューを、ユーザー指定によりScorpミーゾン・ガードタワーとして扱う。Mercの塔とは外観が異なるという指定を優先し、既存のScorpロケットタワーやMercのミーゾンタワーと同じモデルにはしない。

武装のGAUS30はMerc側と共通の充填規則を使う。充填量にかかわらず射程は一定で、発射時の威力はREADYで28、充填ゼロで0、その間は充填率に比例する試作値。Easy・MediumのAIとHardの初弾はREADYまで待つ。HardのAIは近距離で充填50%以上なら未充填の再射撃も行い、威力が下がる。プレイヤーも未充填で発射できる。

## 画像で確認できる外観

- 上部は幅広く低い屋根状の金属部材。灰色の面、黄土色の縁、その下の細かな区切りが見える。
- 屋根上から画面左へ長い砲身状の部材が伸び、途中に茶・黄土色の帯と暗い先端が見える。
- 中央の胴体は緑から青緑の装甲面で構成され、下へ細くなる。縦長の黄土色の帯や暗い継ぎ目がある。
- 左右には明るい灰色の斜めの支持部材が張り出す。薄い翼状・脚状の輪郭だが、機能や裏面の構造は未確認。

## Merc側と分けて再現する点

| 部位 | Scorp側の画像 | Merc側の既存資料 |
| --- | --- | --- |
| 主な色 | 緑・青緑、黄土色、灰色 | 濃紺の頭部、灰色の支柱、赤い模様 |
| 上部 | 低く幅広い屋根と縁の細かな部材 | 下側が絞られた幅広い多面体の頭部 |
| 下部と側面 | 下へ細くなる胴体、斜めに張り出す明色の支持材 | 細くくびれた中央部と、地面へ広がる灰色の支柱 |

小さなプレビューなので、正確な面数、全高、幅、背面、可動範囲、武器の性能は未確定とする。模型の見かけの大きさをMerc側と同じ全高とする根拠には使わない。

`scorp-meson-tower`として、機体定義・共有形状・描画・ホログラム・命中領域を追加した。固定タワーの移動制限、砲塔旋回、砲塔の向きに連動するレーダー、退出は共通処理を使い、外観は専用にする。

## 追加の外観・機内資料（2026-11-26）

[正面寄りのカード](<../../../../assets/reference/scope-mison-guard-tower/sc- 2026-11-25 23.53.21.png>)と[側面寄りのカード](<../../../../assets/reference/scope-mison-guard-tower/sc- 2026-11-25 23.54.00.png>)では、分割された黄土色の屋根縁、上部の左右の青緑パネル、下へ細くなる胴体、幅のある灰色の外側支持部が見える。側面では低い砲塔と右へ伸びる砲身を確認できる。正面カードでは外側支持部の端から端まで約330画素、上部胴体の幅が約238画素。修正後の固定画角では約363画素と約251画素で、比率はそれぞれ約1.39と約1.45。原作の撮影条件は不明のため、実寸の根拠には使わない。

カードにはGAUS30を1門備え、電力プラントから外部給電を受けると記載されている。武器名と給電方式は現行定義と合う。射程・弾速・威力はカードから測定できないため仮値のままにする。

[機内画像](../../../../assets/reference/scope-mison-guard-tower/internal.png)を実行用の枠にした。窓に写る地形と写真のIFF・武器表示・ホログラム・レーダーをマスクし、現在の状態を重ねる。画像内のIFF `0127` は初期値に使わない。下側の曲線状の計器台は、窓を抜くため一部をSVGで補う。

## 4-2での用途と開始状態（2026-10-30）

ユーザー指定により、4-2では徒歩で出撃した後、このScorpミーゾン・ガードタワーへ搭乗して、Scorp軍とともにシェリダン率いるUnion軍を迎撃する。[出撃直後の画像](../../../../assets/reference/scorp-rocket-tower/4-2-開始時-右手にscopeロケットタワー.png)の右手に写る塔は、ユーザーがScorpロケットタワーと指定した別の設備。ミーゾンタワーの外観や搭乗位置の根拠として混用しない。正確な位置と移動経路は[4-2の任務仕様](../../../missions/mission-4-2.md#出撃直後の視点と迎撃任務ユーザー指定2026-10-30)で管理する。

4-2の試作ではプレイヤー用とターン用の2基を配置し、同じ電力プラントへ接続する。キリーの搭乗先は別機種のロケットタワー。プラント破壊時の停止、反動なし、地上退出は共通仕様を使う。GAUS30と外部給電は追加カードで確認できた。全高12m・シールド120・装甲360・エネルギー1200は仮設定。GAUS30はMercミーゾンタワーと同じ調整（射程1000m、速度200m/s、拡大した命中幅、青い着弾煙）を共有するが、Scorp機の原作性能として確認された値ではない。機内は追加画像の金属枠を使う。

AIが操作する場合は、Merc側と同じ共通設定で40m未満の目標へ射撃しない。40m以上で射撃を再開できる。40mは原作未確認の試作値。
