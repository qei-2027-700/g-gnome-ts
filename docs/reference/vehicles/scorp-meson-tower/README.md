## 画像で確認できる外観

- 上部は幅広く低い屋根状の金属部材。灰色の面、黄土色の縁、その下の細かな区切りが見える。
- 屋根上から画面左へ長い砲身状の部材が伸び、途中に茶・黄土色の帯と暗い先端が見える。
- 中央の胴体は緑から青緑の装甲面で構成され、下へ細くなる。縦長の黄土色の帯や暗い継ぎ目がある。
- 左右には明るい灰色の斜めの支持部材が張り出す。薄い翼状・脚状の輪郭だが、機能や裏面の構造は未確認。

## Merc側と分けて再現する点

| 部位 | Scorp側の画像 | Merc側の既存資料 |
| --- | --- | --- |
| 主な色 | 緑・青緑、黄土色、灰色 | 濃紺の頭部、灰色の支柱、赤い模様 |
| 上部 | 低く幅広い屋根と縁の細かな部材 | 下側が絞られた幅広い多面体の頭部 |
| 下部と側面 | 下へ細くなる胴体、斜めに張り出す明色の支持材 | 細くくびれた中央部と、地面へ広がる灰色の支柱 |

小さなプレビューなので、正確な面数、砲口数、全高、幅、背面、内部視点、可動範囲、発射する武器の型番・色・性能は未確定とする。模型の見かけの大きさをMerc側と同じ全高とする根拠には使わない。

`scorp-meson-tower`として、機体定義・共有形状・描画・ホログラム・命中領域を追加した。固定タワーの移動制限、砲塔旋回、砲塔の向きに連動するレーダー、退出は共通処理を使い、外観は専用にする。機内も専用の試作表示を使う。原作の機内視点との一致は未確認。

## 4-2での用途と開始状態（2026-10-30）

ユーザー指定により、4-2では徒歩で出撃した後、このScorpミーゾン・ガードタワーへ搭乗して、Scorp軍とともにシェリダン率いるUnion軍を迎撃する。[出撃直後の画像](../../../../assets/4-2-開始時-右手にscopeロケットタワー.png)の右手に写る塔は、ユーザーがScorpロケットタワーと指定した別の設備。ミーゾンタワーの外観や搭乗位置の根拠として混用しない。正確な位置と移動経路は[4-2の任務仕様](../../../missions/mission-4-2.md#出撃直後の視点と迎撃任務ユーザー指定2026-10-30)で管理する。

4-2の試作ではプレイヤー用とターン用の2基を配置し、同じ電力プラントへ接続する。キリーの搭乗先は別機種のロケットタワー。プラント破壊時の停止、反動なし、地上退出は共通仕様を使う。武器型番・性能は原作未確認のため、GAUS30、全高12m・シールド60・装甲180・エネルギー1200で仮設定した。機内は専用の緑・黄土色の仮フレームを使う。
