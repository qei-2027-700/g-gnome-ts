# Scorp ポップアップタレット

Mission 3-5の第2ロケットタワーの手前に、ユーザー指定で約5基を置く。近くのポップアップタレット制御施設を破壊すると、5基とも射撃を停止する。

機関銃はUnion TD HAWC・Union ASVと共通のTCREAP。3-2のUnion AIPにある3cREAPも、現在はTCREAPと同じ性能を仮用する。タレットの索敵・発砲開始距離は試作値70mで、HAWCが80m以上から攻撃する場合は先に撃たれない。TCREAP自体の160mという共通射程は変更していない。

低い台座、せり上がった砲身、旋回する砲塔を仮形状として作った。原作の外観画像、装甲値、昇降の条件と速度は未確認。現在は常に展開した姿で、昇降動作は実装していない。
