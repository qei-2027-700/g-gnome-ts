## 武器枠（2026-10-30）

ユーザー指定により、ミサイルは同じ種類を2枠に複製せず、Scorp ASVと同様にSREMとUNKPAを独立した武器枠で扱う。1キーでSREM、2キーでUNKPAを発射し、残弾も別々に管理する。ユーザーの増弾指定により、初期残弾はSREM 100発・UNKPA 30発とする。UNKPAを10発から30発へ増やした。ロケットタワーの原作残弾数は未確認。


## 武器2の追尾調整（2026-10-30）

ユーザー指定により、ロケットタワーの武器2（UNKPA）の追尾旋回力を通常の1.2倍にする。プレイヤー発射時は0.45rad/sから0.54rad/sへ上がる。AI・味方の発射でも同じ機種・武器の倍率を使い、既存の狙いのばらつきと目標位置の更新間隔は維持する。SREMとScorp ASVのUNKPAは従来の設定に従う。捕捉角30度・追尾維持角45度、弾速・威力・射程は変更しない。

30発と1.2倍は使用感の指定に合わせた試作値で、原作の実測値ではない。発射時に倍率を弾へ記録し、発射後に乗り換えてもその弾の追尾性能は変わらない。乗り降りで残弾を補充せず、再出撃で30発に戻す。
