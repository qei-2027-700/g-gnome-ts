[3-3-scopeロケットタワー.png](3-3-scopeロケットタワー.png)はタワーの接写。青緑の多角形の胴体、黄土色の帯、灰色の屋根と外へ開く支柱を確認する。

[新しい正面カード](../../../../assets/reference/scorp-rocket-tower/sc-%202026-11-25%2023.52.53.png)では、塔頂の左側に2段4列の黒い発射孔、右側に丸い暗色の装置、両側へ張り出す低い灰色の屋根が見える。黄土色の帯の下に青緑の上部外装が続き、下部には外へ開く灰色の支柱と黄土色の縦線がある。以前のモデルは大きな四角錐状の屋根と均等な小パネルだったため、この正面の輪郭と前面部品を修正した。カードには50発入りUNKPAラック2基と自給式電源の記載がある。側面・背面と正確な奥行きは未確認。

ユーザー指定により、2段4列の発射孔が向く側を正面とする。旋回するのは屋根と、その上の発射孔・ラック・丸い部品を備えた部分だけ。屋根の下にある青緑の上部外装、黄土色の帯、中央の胴体、外側の支柱は固定する。屋根上の命中領域は砲塔の向きに追従させ、屋根より下の命中領域は固定する。

ミサイルは胴体からではなく、屋根上の8つの発射孔から出す。SREMとUNKPAのどちらも発射ごとに次の孔を使い、8つ使うと最初の孔に戻る。孔を使う順番は原作画像から確定できないため試作上の設定とし、発射位置は砲塔の旋回角に追従させる。

正面カードでは左右の支柱外端が約290画素、屋根幅が約255画素で、屋根幅は全幅の約0.88。固定画角で撮った修正後の正面では支柱外端が約414画素、屋根幅が約367画素で約0.89。比較画像と撮影条件は `.artifacts/model-match/scorp-rocket-tower/` に保存した。元画像の撮影条件は不明なため、これは輪郭の目安であり、実寸の測定値ではない。

[機内画像](../../../../assets/reference/scorp-rocket-tower/internal.png)には、上左右の黒い武器表示面、中央のIFF、左右の金属枠と下側のホログラム・レーダー面が写る。実行用画像では窓の地形と写真の固定計器をマスクし、現在の戦場と計器を重ねる。画像内のIFF `0127` と残弾は初期値に使わない。

[3-4機内ホログラムの拡大画像](../scorp-tactical/3-4-cockpit-holograms.png)では、左側の目標像をユーザー指定によりScorpロケットタワーとして扱う。幅広く平たい上部、細い中央胴体、左右の張り出しと外へ開く支柱が見える。この輪郭を機種ID `scorp-rocket-tower` のホログラムに反映し、任務ごとの専用表示は作らない。緑はホログラムの状態表示色で、外装の塗装色ではない。

基地内での配置は[3-3の観察記録](../../observations/mission-3-3/observations.md)と[基地突入画面](../scope-asv/3-3-司令部左側-ul-urit基地突入.png)を参照する。実装仕様は[機体・武器資料](../../vehicles-and-weapons.md)へ記録する。

[4-2-開始時-右手にscopeロケットタワー.png](../../../../assets/reference/scorp-rocket-tower/4-2-開始時-右手にscopeロケットタワー.png)は、4-2出撃直後の徒歩視点。画面右手の塔をユーザーがScorpロケットタワーと指定した。4-2で搭乗して迎撃する[Scorpミーゾン・ガードタワー](../scorp-meson-tower/README.md)とは区別する。画面上の右を地理上の東とは決めない。

ユーザーの共通仕様指定により、敵を見つける距離は全任務で240mの試作値とする。従来の280mから下げ、ミサイルの飛翔距離・速度・威力は維持する。

## 武器枠（2026-10-30）

ユーザー指定により、ミサイルは同じ種類を2枠に複製せず、Scorp ASVと同様にSREMとUNKPAを独立した武器枠で扱う。1キーでSREM、2キーでUNKPAを発射し、残弾も別々に管理する。ユーザーの増弾指定により、初期残弾はSREM 100発・UNKPA 30発とする。UNKPAを10発から30発へ増やした。新しいカードの50発入りUNKPAラック2基とは異なるが、今回の外観・機内変更では先のユーザー指定を維持する。


## 武器2の追尾調整（2026-10-30）

ユーザー指定により、ロケットタワーの武器2（UNKPA）の追尾旋回力を通常の1.2倍にする。プレイヤー発射時は0.45rad/sから0.54rad/sへ上がる。AI・味方の発射でも同じ機種・武器の倍率を使う。Scorp ASVのUNKPAは従来の設定に従う。捕捉角30度・追尾維持角45度、弾速・威力・射程は変更しない。

その後の指定により、タワーのSREMとUNKPAは、停止している相手（水平速度0.75m/s以下）へばらつきを付けず、実位置を追尾して命中する。動いている相手には従来のばらつきと更新間隔を残す。詳細は[通常ミサイルの自動追尾](../../../gameplay/weapons-and-missile-camera.md#通常ミサイルの自動追尾2026-10-24)を参照する。

30発と1.2倍は使用感の指定に合わせた試作値で、原作の実測値ではない。発射時に倍率を弾へ記録し、発射後に乗り換えてもその弾の追尾性能は変わらない。乗り降りで残弾を補充せず、再出撃で30発に戻す。
