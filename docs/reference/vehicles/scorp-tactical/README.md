# Scorp Tactical Defense HAWCの外観

[3-4の正面画像](../../../../assets/map/3-4/scope-td-front.png)では、画面中央の機体の左にいる機体を、ユーザー指定によりScorp Tactical Defense HAWCの正面として扱う。小さい灰色の頭、黄土色の胴体の中央に青い面、左右に下がる橙色と青緑の腕、離れた2本の脚と白い足先が見える。脚は人間の直立脚ではなく、膝が深く折れた恐竜のような形をしている。撮影距離と歩行姿勢のため、画像上の寸法を実寸とは扱わない。

[3-4の外部視点](<../../../../assets/map/3-4/sc- 2026-11-11 23.56.04.png>)では、中央の機体を同機種の背面として扱う。灰色の頭の下に黄土色の背面装甲があり、両側の腕は胴体より細い。左右の脚は離れ、灰色と褐色の面が見える。[機内画像](<../../../../assets/map/3-4/sc- 2026-11-11 23.54.41.png>)は操縦席の資料で、外装の形を判断する根拠にはしない。

現行モデルは正面と背面の輪郭に合わせて、頭と中央胴体を細くし、胸の中央を青くし、左右の武器ユニットを低い腕状に変更した。脚は膝を後ろへ折り、すねと白い爪先を描いた。側面画像は未提供のため、膝の曲げ角度と足の前後位置は試作値。外観のメートル寸法と背面の細部も試作値のまま。ユーザー指定により上半身の独立した横旋回は行わず、左右入力で機体全体が向きを変える。性能や武器の数値は変更していない。
