# Union Airborne Insurgence Platform

- 作品・媒体：G-Nome再現／ブラウザゲーム
- 対象：3-2のプレイヤー搭乗機と4-2のUnion AIP 2機
- 状態：ユーザー指定の機種・数・攻撃対象を実装。外観は原作画像と照合中。性能は仮設定
- 関連：[3-2](../../../missions/mission-3-2.md)、[4-2](../../../missions/mission-4-2.md)

3-2ではプレイヤーがUnion AIPに搭乗して開始する。確認済みの機内枠は[assets/reference/union-aip/union-aip.png](../../../../assets/reference/union-aip/union-aip.png)で、[開始直後の機内画像](../../../../assets/map/3-2/3-2-union-aip.png)と同じ画素である。写真にはARC-M、3cREAPの残弾220、IFF 4044、中央レーダーが写っている。実行時画像はこの写真のままで、マスクが窓と計器の井戸を抜く。窓、IFF、武器欄、ホログラム、レーダーは現在のゲーム状態から描く。3-2のプレイヤー機にはARC-Mと3cREAPを設定し、初期弾数を220とした。射程・威力・発射間隔は未確認のため仮値。

[外部視点の背面画像](../../../../assets/map/3-2/3-2-aip-external.png)では、低い横長の胴体と左右二つの丸い後部ユニットが見える。自機ホログラムの輪郭もUnion AIP専用にした。

[原作の正面画像](<../../../../assets/reference/union-aip/正面.png>)では、左右端 x=20〜356 の幅336画素に対し、機体上端 y=48、下端 y=148 で、高さは幅の約0.30倍。中央の操縦席には青い前面窓があり、その両側に大きな暗色の円形ユニットと外へ広がる白い翼状装甲がある。[斜め方向の画像](<../../../../assets/reference/union-aip/sc- 2026-11-26 0.05.08.png>)では、薄い船体、段付きの操縦席、黄土色の帯が見える。これらを専用モデルに反映した。正面の現行モデルは修正前が約0.42倍、修正後が約0.32倍（同じ固定カメラの近似投影）。背面の細部や武器の正確な形は画像から判別できず、試作形状のまま。

4-2ではシェリダン側のUnion AIPが2機登場し、電力プラントを攻撃する。プラントを破壊するとプレイヤーとターンの両ミーゾンタワーが射撃できなくなる。この役割と機数はユーザー指定による。

機種IDは`union-aip`、所属はUnion。既存の低空浮遊、減速・着地、搭乗、地形回避、武器と命中判定を共有する。車体の描画基点は他のAIPと同じ。現在の速度90km/h・浮遊高1.8m・全高3.7m・P2MEC・シールド30・装甲80・エネルギー1200は試作値。[原作の機体紹介画像](<../../../../assets/reference/union-aip/sc- 2026-11-26 0.04.43.png>)には最高速度100km/h、シールド20、エネルギー1900、全高2.7mと記されているが、今回は外観のみ変更し、性能値は未変更。浮遊高は2026-11-19の指定で上げた仮値で、原作の高度は未確認。Mercの画像をUnionの確認済み外観として扱わない。乗客は操縦者とは別に3席で、席数は原作未確認の仮値。
