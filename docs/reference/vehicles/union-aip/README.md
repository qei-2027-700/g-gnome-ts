# Union Airborne Insurgence Platform

- 作品・媒体：G-Nome再現／ブラウザゲーム
- 対象：4-2のUnion AIP 2機と対プラント攻撃
- 状態：ユーザー指定の機種・数・攻撃対象を実装。外観・性能は仮設定
- 関連：[4-2](../../../missions/mission-4-2.md)

4-2ではシェリダン側のUnion AIPが2機登場し、電力プラントを攻撃する。プラントを破壊するとプレイヤーとターンの両ミーゾンタワーが射撃できなくなる。この役割と機数はユーザー指定による。

機種IDは`union-aip`、所属はUnion。既存の低空浮遊、減速・着地、搭乗、地形回避、武器と命中判定を共有する。青灰色の菱形を使う外観、速度90km/h・浮遊高1.2m・全高3.7m・P2MEC・シールド30・装甲80・エネルギー1200は試作値。原作のUnion AIPの画像・性能とは未照合。Mercの画像をUnionの確認済み外観として扱わない。
