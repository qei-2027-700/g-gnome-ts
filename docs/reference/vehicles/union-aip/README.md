# Union Airborne Insurgence Platform

- 作品・媒体：G-Nome再現／ブラウザゲーム
- 対象：3-2のプレイヤー搭乗機と4-2のUnion AIP 2機
- 状態：ユーザー指定の機種・数・攻撃対象を実装。外観・性能は仮設定
- 関連：[3-2](../../../missions/mission-3-2.md)、[4-2](../../../missions/mission-4-2.md)

3-2ではプレイヤーがUnion AIPに搭乗して開始する。提供された[開始直後の機内画像](../../../../assets/map/3-2/3-2-union-aip.png)には、ARC-M、3cREAPの残弾220、IFF 4044、中央レーダーが写っている。レーダーには味方と敵の位置が表示される。金属フレームを専用の機内表示へ取り込み、窓、IFF、武器欄、ホログラム、レーダーは現在のゲーム状態から描く。3-2のプレイヤー機にはARC-Mと3cREAPを設定し、初期弾数を220とした。射程・威力・発射間隔は未確認のため仮値。

[外部視点の背面画像](../../../../assets/map/3-2/3-2-aip-external.png)では、低い横長の胴体、左右二つの丸い後部ユニット、灰白色の装甲と赤い細部が見える。外観モデルの後部に二つの円形ユニットを追加し、自機ホログラムの輪郭もUnion AIP専用にした。見えない前面形状と機体寸法は仮のまま。

4-2ではシェリダン側のUnion AIPが2機登場し、電力プラントを攻撃する。プラントを破壊するとプレイヤーとターンの両ミーゾンタワーが射撃できなくなる。この役割と機数はユーザー指定による。

機種IDは`union-aip`、所属はUnion。既存の低空浮遊、減速・着地、搭乗、地形回避、武器と命中判定を共有する。青灰色の菱形を使う外観、速度90km/h・浮遊高1.2m・全高3.7m・P2MEC・シールド30・装甲80・エネルギー1200は試作値。外観と性能は原作未照合。Mercの画像をUnionの確認済み外観として扱わない。
