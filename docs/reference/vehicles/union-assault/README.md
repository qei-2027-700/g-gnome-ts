## マニュアルと呼び名

英語マニュアルの Union Heavy Assault HAWC（Lion）。分類は Multipedal Assault。最高速度90km/h、シールド90、エネルギー2200、全高14.7m、質量57t。質量の項目は機体定義にないので、資料だけに残す。標準武装はP2MEC砲2門、TCREAP各1500発、TCROCK 50発、VISOM 30発。ゲームのTCREAPは2門分を合わせた3000発。装甲の掲載はない。実装の240は仮値で、メルク軍・スコープ軍アサルトの仮値160より高い。

4-5のブリーフィングでは、ウィルキンス将軍がこの機体をライオンホークとも呼ぶ。画面上の機体名は Union Assault HAWC / ユニオン軍 アサルト ホーク のまま。脱出装置の有無はカードにないので未設定。

## 背面から反映した特徴（2026-11-25）

ユーザー指定により、蜘蛛型ではなく四足歩行の獣とする。前後に長い灰白の胸、前方の頭、腹の下から地面へ降りる赤い脚。後ろの一対だけ横幅を1.08倍にし、真後ろからも4本が分かれる。この倍率は仮。ホログラムの緑・黄・赤は損傷色であり、塗装ではない。正面の細部、内部、脚のメートル比は未計測。全高14.7mだけをマニュアル値にし、それ以外の外形は仮。見た目が重いことを理由に最高速度は変えない。

歩行は四拍子の歩き。順は左後、右前、右後、左前。足は前へ出て接地し、体が前へ進むあいだ後ろへ送る。遊脚では膝が折れて足が上がり、足先が上がる。前脚の膝は後ろへ、後脚の膝は前へ折れる。脚は横へ回さない。幅の面は横を向いたまま、前後にだけ振る。歩幅・足の高さ・周期は仮で、原作の実測ではない。約4m/sで歩幅がいっぱいになり、それより速いときは歩幅を保ったまま周期が短くなる。

[背面](../../../../assets/reference/union-assault/union-assault-hawk-behind.png)では、胴は横に広く縦に低い中央のchassisで、赤い脚が左右の端から地面まで降りる。脚の間は空いている。この輪郭に合わせ、背面の高い一枚壁をやめた。固定カメラの後方では、低い横長の胸と、その両端から下りる4本の脚が見える。側面の長さは残し、鼻先までの全長は使っていない。頭・鼻・砲は箱の仮形状で、背面のパネル模様は足していない。

背面を見た指定で、灰色の腰を少し低くし、横幅を広げた。腹の下面は脚の付け根に残し、脚は胴の外端から降りる。胴の幅9・高さ2.4、股の横位置は仮。側面の原作は膝が折れた獣で、頭と鼻が長い。箱の側面はその配置だけを合わせていて、膝の折れと面の分割は再現していない。

武器はあごの下から前へ出る。P2MECとTCREAPは左右の砲身、VISOMとTCROCKはその下の同じ高さ。機内の視点は全高に対する既存の0.81倍で、約11.9m。機種ごとの特別な視点高さは足していない。頭の窓をこの高さに置いた。

レーザーはP2MEC。長押しは充填完了を待たず、機体別設定の0.6秒間隔で二門を繰り返す。この連射は機種の例外であり、任務IDでは分岐しない。4-5だけがこの機種を置く。武器共通の0.8秒間隔と威力は変えていない。TCREAPもこの機体では0.5秒間隔で発射する。
