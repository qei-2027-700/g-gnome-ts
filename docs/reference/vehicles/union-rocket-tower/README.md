# Union Rocket Tower

[外観カード](../../../../assets/reference/union-rocket-tower/sc-%202026-11-25%2023.51.47.png)の正面には、灰色の角塔、赤い屋根縁と四隅の線、上部の黒い窓3つ、中段の左右のロケットラック、下部中央の入口が見える。カードには「2基の60発入りTCROCKロケットラック」と自給式電源の記載がある。側面、背面、奥行き、実寸はこの画像から確認できない。

[機内画像](../../../../assets/reference/union-rocket-tower/internal.png)には、上側の広い窓、左右の赤白の支柱、下側の灰色の計器台が写る。窓の外の地形と写真に焼き込まれた計器は表示に使わず、実行用画像をマスクしてゲームの映像と計器を重ねる。

4-4と4-5のUnion側のタワーは `union-rocket-tower` を使う。外観と機内枠は専用にし、武器はカードに合わせてTCROCKを2スロット、各60発にした。TCROCKの弾速・威力は既存定義を使う。当たり判定寸法とその他の戦闘性能はScorpロケットタワー由来の仮値。4-4の追尾無効と4-5の追尾倍率は任務ごとの従来設定を維持する。発射音と弾の外観は原作との照合が済んでいない。
