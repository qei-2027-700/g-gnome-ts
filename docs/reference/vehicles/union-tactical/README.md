## 外観の照合（2026-11-26）

[原作の正面画像](../../../../assets/reference/union-tactical/union-td-hawk2.png)では、低い中央操縦席、灰白色の左右肩部、肩から外へ伸びる砲身、離れて立つ細長い脚、膝下の赤い丸印が見える。[斜め方向の画像](../../../../assets/reference/union-tactical/union-td-hawk.png)では、円筒形の肩部と足先の広がりを確認できる。[背面画像](../../../../assets/reference/union-tactical/4-4-union-td-hawk-outside.png)には中央上部の赤い円形ユニットが二つ写る。

正面画像で足の中心を測ると、原作は約 x=108・350（機体の左右端 x=43・417）、固定カメラによる現行描画は修正前が約 x=367・593（左右端 x=263・697）、修正後が約 x=351・609（左右端 x=269・691）。足の中心間隔を機体全幅で割った値は、それぞれ約0.65、0.52、0.61。脚の中心間隔を広げ、操縦席を低くして胴体への支持装甲を付け、灰白色の肩部と横向きの砲身、赤い膝下の丸印と背面の円形ユニットを反映した。側面と背面の詳細は参照画像で隠れる部分が多く、装甲の内側や正確な武器形状は試作のまま。

## 脚の細さと長さ（2026-10-24）

ユーザー指定により、脚を従来より細く、長くした。今回の試作では脚全体の横幅を18％、前後の厚みを10％減らし、長さを10％伸ばす。腰の位置を上げ、太もも・膝下・足先を同じ比率で調整する。上部の胴体・コックピット・武装と公称全高7.5m、機体性能は維持する。

主要な比率・腰の位置・脚の命中領域は`vehicles.ts`の`union-tactical`定義で共有する。歩行時は伸ばした脚の長さと足先の厚みに合わせて接地を計算し、ホログラムにも細長い脚を反映する。Merc・ScorpのTactical Defense HAWCにはこの比率を適用しない。正確な寸法は原作の計測値ではなく、マニュアル下段の機種識別と今回の指定に基づく試作値とする。
