## 開発とプレイの違い

開発中はViteの開発サーバーを起動し、localhostをブラウザで開いて動かす。変更のたびに配布用ビルドを作る必要はない。配布時にはHTML・JavaScript・画像・音などをビルドして、プレイヤー向けに配信する。[Viteの開発・ビルドの説明](https://vite.dev/guide/)

| 段階 | 予定するコマンド | 用途 |
| --- | --- | --- |
| 制作環境の準備 | `pnpm install` | 制作者が依存パッケージを導入する |
| 開発中の起動 | `pnpm dev` | 変更しながらlocalhostでプレイ確認する |
| 配布用ビルド | `pnpm build` | 型検査とビルドを行い、`dist/`へ出力する |
| ビルド後のローカル確認 | `pnpm preview` | 配布物をローカルHTTP経由で確認する |

これらは実装開始時に用意するコマンド案で、現在のフォルダに実行可能なスクリプトがあるという意味ではない。Node.js・pnpmは制作環境に必要だが、公開URLで遊ぶプレイヤーには不要。

## 最初の配布方法

まずは`dist/`をHTTPSの静的ホスティングで配信し、URLを開けばプレイできる形を推奨する。Windows・macOS向けに別々のゲーム本体をビルドする必要はなく、同じWeb配布物を各ブラウザで検証する。

Viteの`preview`はローカル確認用で、本番公開用サーバーには使わない。[Viteの静的配信資料](https://vite.dev/guide/static-deploy.html)

配布先のサービス・URLは未選定。公開前にビルド成功、素材の読み込み、配信先のパス、ブラウザ操作、セーブ、音を確認する。ゲーム本体用のサーバー側APIやDBは、シングルプレイの初期版では不要。

## プレイヤーの環境

Windows・macOSのキーボードとマウスを備えたPCと、WebGLなどゲームで使用する機能が動作するブラウザを対象にする。WindowsのChrome・Edge、macOSのSafari・Chromeを検証対象案とする。必要なOS・ブラウザの最低版とメモリ・GPU条件は、実装と性能測定後に定める。

初回プレイはゲームと素材の読み込みが必要。音声とマウス操作の開始はユーザーの開始操作から行う。設定・セーブはブラウザに保存し、端末間同期は初期版に含めない。

## ダウンロード配布とオフライン

ビルド済みファイルをZIPにするだけでは、展開したHTMLのダブルクリックで安定して遊べるとは扱わない。モジュールや素材読み込みのため、ローカルでもHTTPで配信して検証する。

完全オフライン、PWA、Windows・macOSのアプリ形式の配布は後続の検討事項。インストール不要のWeb配信を最初の経路とし、オフライン対応済みとは案内しない。

配布対象はゲーム用にビルドした`dist/`とする。原作調査用のPDFや制作資料があるプロジェクト全体を、そのまま公開フォルダにしない。ゲーム用の画像・音声は、採用と利用方法が決まった素材を明示的にビルドへ含める。
