# 原作画像からの施設モデル再現

施設の外観を原作画像に合わせる際の手順。施設種の登録先と機能の接続先は[コンテンツ拡張手順](content-extension.md#facility建物)に従う。参考画像は形と色の根拠であり、実行時のテクスチャとして直接読み込まない。

## 1. 対象と画像を確認する

1. 画像を開き、施設名、勢力、撮影方向、見えている面を確認する。ファイル名だけで内容を決めない。
2. 画像の文字や背景を施設の輪郭から分ける。正面像と斜め像を同じ投影図として扱わない。背面や内部など写っていない部分は未確認とする。
3. 現行モデルを画像に近い方向と画角で撮る。修正前後の比較ではカメラ位置、注視点、視野角、画面サイズ、施設の向きをそろえ、画像と一緒に記録する。元画像の正確なカメラが不明なら近似と明記する。
4. 画像上の建物幅か高さを基準に、屋根の頂点、入口、左右端、特徴的な突起や支持部の位置を比率で記録する。遠近で変わる見かけの寸法を実寸と混同せず、隠れた目印の数値は作らない。

比較記録は「施設と画像／方向／基準の両端／目印と比率／現行との差／確認できない箇所」の単位で残す。

## 勢力別デザインと例外

司令部、研究所、電力プラント、シールド生成設備、地雷原制御施設などの外観は、Scorpなど所属する軍によって異なる。同じ施設種でも、他勢力の形を色だけ変えて流用せず、対象の勢力の画像に合わせて輪郭と主要部品を作る。施設種は機能、勢力は外観の選択に関わるため、実装時は施設種と所属勢力をともに確認する。

橋、bridge-control-building、ポップアップタレット、ポップアップタレット制御施設は、この勢力別デザインの原則から除く。これらへ勢力ごとのモデル差を追加する必要が生じた場合は、対象画像で差を確認してから扱う。

## 2. 輪郭から作る

本体と張り出し、塔、配管、支柱のつながりを先に決める。全幅と高さ、屋根や上部構造の形、左右の対称性または非対称性を合わせてから、窓、模様、配色へ進む。原作で連続する部品に画面上の隙間を残さず、見える隙間を推測で埋めない。施設ごとの特徴を汎用の箱や屋根だけで代用しない。

描画は `src/game/presentation/base.ts` の施設モデルと任務定義の寸法・向き・`Base.faction` を対応させる。新しい施設種が必要なら `Base.buildings[].kind`、施設名、ホログラム、対象任務を接続する。モデルの調整だけを理由に耐久値、電力・防護などの機能、任務目標を変更しない。

飾りが既存の施設寸法から大きくはみ出す場合は、見た目と衝突・射線・選択の範囲を照合する。元画像に縮尺がなければ、メートル寸法は仮値として扱う。

## 3. 同じ視点で仕上げる

修正前後のモデルを同じ撮影条件で原作画像と並べ、主要な目印の比率と輪郭の差を確認する。正面画像だけで合わせた施設も、ゲーム内では斜めと側面から接地、部品の貫通、地形との重なりを確認する。ただし、見えない面の造形を原作で確認済みとは記さない。

対象の任務で実ブラウザ表示を確認し、施設の選択、射撃、損傷・破壊、入口や搭乗、任務の進行のうち影響する機能を確認する。変更した描画と施設種の関連テストを実行する。構造テストの成功と画像上の外観一致は別々に報告する。
