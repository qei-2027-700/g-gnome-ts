# Windows・macOSの操作とキーマッピング

- 作品：G-Nome再現
- 媒体：Windows・macOSのPCブラウザ
- 対象：キーボード、マウス、設定画面、全速出力時の確認音声
- 状態：両OS対応・全速出力時の女性音声はユーザー指定。共通キー配置は実装案
- 記録日：2026-10-22
- 関連：[設定](../gameplay/settings.md)、[歩兵](../gameplay/infantry.md)、[カメラ](../gameplay/cameras-and-cockpits.md)、[中断と音](../audio/mission-controls-and-audio.md)

## 原則

テンキーがないWindowsノートPCやMacでも、移動・射撃・全速出力・停止・降機・カメラ切り替え・中断を行えるようにする。原作キーを記録する資料と、Web版で使いやすくするキー配置を分ける。

操作を直接キー名で実装せず、加速・停止・全速出力・降機などのアクションへ割り当てる。Windows版とmacOS版で同じゲーム処理を使い、表示名や利用可能な組み合わせを調整する。CtrlをMacでは無条件にCommandへ置き換える実装にはしない。

## 手動照準の細かさ（2026-10-29）

ユーザー指定により、機体と固定タワーの手動旋回を0.9から0.6rad/s、徒歩時の旋回を2.8から1.8rad/s、上下照準を0.85から0.55rad/sへ落とした。←→・↑↓と、同じ操作に割り当てたA/D・PageUp/PageDownに共通で適用する。短押しの角度を小さくし、キーを離すと旋回・上下照準を止める。

右ドラッグの照準も、1ピクセルあたり0.004から0.0025radへ変更し、既存の感度設定を掛ける。自動追尾とAIの旋回速度、前進速度は変更しない。これらは原作の実測値ではなく、狙いを合わせやすくするための操作調整値。

## VISOM検証版の操作

VISOM検証版では、搭載された武器のキー（3-3では2）で発射すると専用視点へ切り替わる。方向キーまたはWASDで速度を変えずに方向を操作し、Spaceで誘導を終了して機体ビューへ戻る。誘導中の入力は機体へ送らない。ポーズはP。武器発射の入力・HUDは最大4枠に対応する。[VISOMの操作と状態遷移](../gameplay/weapons-and-missile-camera.md)を参照する。

## テンキーレス共通プリセット案

以下は原作のキー配置ではなく、両OSで使うWeb版の候補。キー変更で原作の操縦・射撃の仕組みまで変更しない。原作準拠プリセットとは別に保存し、キー設定画面で選択・変更できる設計にする。

| アクション | 共通キー案 | 有効な状態 |
| --- | --- | --- |
| 前進・後退／スロットル増減 | W・S | 徒歩／搭乗。徒歩は移動、搭乗はスロットル操作 |
| 身体・機体の左右旋回 | A・D | 徒歩／搭乗 |
| 停止 | Enter／テンキーEnter | 徒歩／搭乗。徒歩では全開前進も解除 |
| 全速出力 | Shift（初期実装） | 徒歩／搭乗。押した瞬間に全速出力へ設定 |
| 武器1〜4の発射 | 上段1〜4 | 徒歩／搭乗。存在するスロットだけ有効 |
| 手動降機 | Backspace | 搭乗／同乗／施設内 |
| カメラ切り替え | C | 各状態で利用できるビューのみ |
| 伏せ・起立 | J | 徒歩。原作の姿勢仕様を照合する |
| 最寄りの敵／照準内の目標選択 | E・Q | 対応する目標選択機能がある状態 |
| 目標追従／ウェイポイント切り替え | T・R | 搭乗。原作W・Sとの競合を避ける案 |
| 任務地図・目標の表示 | B | 対応するプレイ状態。[任務表示仕様](../gameplay/mission-map-and-waypoints.md)を参照 |
| レーダー縮小・拡大 | X・Z | レーダーが利用できる状態 |
| 通信パネル | G、画面の通信ボタン | 宛先と命令を順に選ぶ。Fキー不要の代替操作案 |
| ポーズ・設定 | P、画面のメニューボタン | プレイ中。共通プリセットのIFF変更は専用画面で行う案 |
| ミッション中断確認 | 画面の中断ボタン。キーは未定 | プレイ中。原作の中断キーは未確認。Xはレーダー操作に確保する |
| 中断の確定／取り消し | Y／N | 中断確認中のみ。NはWeb版候補 |

マウスによる視点操作、機体の胴体旋回、徒歩の射線は別に定義する。マウス移動へすべてを連動させる前に、原作で身体・カメラ・射線の関係を確認する。ミサイル誘導中は専用の入力へ切り替え、機体の移動へ二重に送らない。

Shift＋Wでは通常のW操作と全速出力を同じ入力で二重に実行せず、全開操作を優先する。全開状態は徒歩・搭乗ともキーを離しても保持する。通常の徒歩移動はキーを離すと止まり、徒歩の全開前進は停止・後退で解除する。歩兵の最高速度は32km/hを維持する。

## 全速出力の女性音声

「出力全開」の声種は、ユーザー指定により女性ボイス2（厳粛な声、`solemn`）とする。字幕は表示しない。

ユーザーから、全速出力で走らせると日本語で女性が「出力前回」と発声するとの説明があった。意図する表記を「出力全開」と解釈し、原音声・字幕の正確な文言は確認対象にする。全速出力に対応する確認音声として実装する。

音声は、全速出力設定が受理されたときに再生する。キーリピートの回数だけ繰り返さない。徒歩でも全開前進の開始時は発声する。メニュー入力時や射出中など、無効な操作では発声しない。

2026-10-29のユーザー指定により、固定タワーと建物内では全開操作を受け付けず、「出力全開」も発声しない。塔または最高速度0の設備では前進・後退入力でスロットルを上げず、移動速度は0を維持する。砲塔の旋回・上下照準・射撃は引き続き使用できる。徒歩と移動可能な機体の全開操作は従来どおり。

すでに全速のときにもう一度押すと発声するか、出力不足・損傷時に別の発声があるかは未確認。スロットル100%の指令と実際の最高速度到達は分け、音声が最高速度到達まで待つのかも原作で確認する。原音声未取得時は代替録音・合成音声と明記し、無音でも操作と表示は成立させる。

## ブラウザ・OSとの衝突

Ctrl／Command＋W・Q・R、Alt＋F4、Command＋Tab、OSが処理するControl＋矢印などを、必須の既定操作にしない。OSやブラウザが予約するショートカットを完全に横取りできる前提では進めない。Fキー・テンキー・特殊記号がなくても主要操作を完結させる。

Escはポインターロック解除にも使われるため、中断確定には割り当てない。2026-10-30のユーザー指定により、別アプリへのフォーカス移動、ウィンドウ非アクティブ、タブ非表示では自動ポーズにしない。任務の進行と音声を続け、キー・マウスの押下状態だけをクリアする。復帰時に移動・旋回・発射が押されたままにならないようにし、指令済みの機体出力は維持する。Pや一時停止ボタン、設定画面による明示的な停止は引き続き使える。手動で停止中にフォーカスが移っても、自動再開はしない。

ゲーム操作では物理位置を表す`KeyboardEvent.code`を基本とし、設定画面の文字入力・確認文字は`key`と文字配列も考慮する。JIS・USで刻印が違う場合には、再割り当て時に実際のキーを押して登録できるようにする。確認のYは、表示した文字と入力が食い違わないようにする。[MDN: code](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/code)、[MDN: key](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/key)

IME変換中やテキスト入力欄への入力は、機体の操作へ流さない。`preventDefault`はゲームが入力を受け取っているときの、処理したキーに限定する。ショートカットの修飾キーは完全一致で判定し、Command＋Wを単なるWとして加速させない。

## キー設定画面と検証

アクションごとの主キー・代替キー、状態別の割り当てを表示する。重複は同じ状態で同時に有効になる場合に検出する。徒歩・搭乗の使い分けは許容し、中断確認のYと施設のIFF操作のYは、画面の優先順位で切り分ける。

適用・キャンセル・初期値に戻す・保存・不正データからの復元は[設定仕様](../gameplay/settings.md)に従う。変更後のHUDとヘルプも実際の割り当てを表示する。

WindowsのChrome・Edge、macOSのSafari・Chromeを検証対象案とする。JIS／US、テンキーあり／なし、キー同時押し、IME、フォーカス喪失、ポインターロック解除、全速出力音声の重複を確認する。単体テストだけでOS・ブラウザ上の入力を検証済みとは扱わない。


## 試作版への反映（2026-10-23）

Qの照準内選択、Eの最寄り敵選択、Tab／Shift＋Tabの対象切り替え、左Holo・照準・方向矢印・レーダーへの反映を実装した。解除はHolo内の×でも行える。Ctrl＋Tabはブラウザのタブ切り替えが優先される場合がある。

Qの照準内選択を操作すると、女性音声で「目標選択」と案内する。照準内に対象がない場合も操作の案内を再生し、候補がない場合は選択を解除した旨を表示する。長押しでは繰り返さず、キー設定を変更した場合は変更後の選択キーへ追従する。EやTabによる選択、自動選択にはこの音声を追加しない。

テンキーEnter・Enter／Returnで停止し、「停止します」は音声だけで案内する。通常は←／→で旋回、↑／↓で上下の照準・視線を動かす。PageUp／PageDownでも上下照準を操作できる。機体の外側カメラでも↑／↓は上下の視線に使う。W/S・A/Dの操作も残す。詳細と検証状況は[試作版の実装範囲](playable-1-1.md)を参照。


### Spaceの修正

ユーザー確認に基づき、Spaceは「センター」とする。上下の視線角をゼロへ戻し、機体では胴体のひねりを解除して車体正面へ照準を戻す。自動追尾は解除し、選択対象と出力は維持する。停止操作はEnter／Return・テンキーEnterへ分離した。以前の保存設定でSpaceが停止になっている場合も、新しい割り当てへ移行する。


### 視点・ウェイポイント・歩兵武器の修正

ユーザー指定を優先し、現在の試作版はCで後方、Zで斜めビューへ切り替える。歩兵・搭乗中で共通。Zのレーダー操作は外し、レーダーの＋／−ボタンを追加した。Rは初期未選択からWP1、非表示へ循環する。歩兵の1はPRIF44、2はGASHR。3-3では2を特別装備のEGGERに切り替える。Backspaceは「脱出」の女性音声と上方射出・落下・着地に対応する。

## センター操作の音声（2026-10-23）

ユーザー指定により、センター操作時は女性音声で「センター」と案内する。初期キーはSpace。上下照準を水平へ戻し、搭乗中は上半身を車体の正面へ戻して追尾を解除する。押し続けた場合は繰り返さず、離して再度押したときに案内する。現在は既存の女性合成音声の `young` プロフィールを使う。声種の詳細と実ブラウザでの発声は未確認。

無人化時の自動復帰は[歩兵・乗降仕様](../gameplay/infantry.md#無人化時のセンター復帰2026-10-23)を参照。ゲーム処理と音声イベントを含む自動テストは `.artifacts/center-tests.log`、型チェック付きビルドは `.artifacts/center-build.log` に記録する。


## 仲間への通信命令

- F1→F1：全員で選択中の敵を攻撃。
- F1→F4：選択中の機体に搭乗。無人機は操縦者として乗り換え、目標なしなら徒歩の仲間が自分のASVへ同乗。
- F1→F6：操縦中・同乗中の仲間が降機。
- F1→F5：選択目標があれば全員がその対象へ移動・追従。未選択ならプレイヤーに追従。
- F1→F7：全員が停止し、命令を解除。
- 3-3のF2／F3／F4：キリー／ターン／シェリダンを個別に選び、同じ命令キーを続ける。
- G／通信ボタン：宛先選択から開始。画面のボタンでも送信できる。

通信中も任務は進行する。Escで閉じ、Pで一時停止。リピート入力を無視し、F5のブラウザ再読み込みを抑止する。詳しい受信条件は[通信仕様](../gameplay/iff-and-communications.md#試作版で実装した仲間への指示2026-10-24)を参照。


## ASVの乗客と外側カメラ（2026-10-24）

Fは近くの搭乗可能な機体を距離順に選ぶ。有人ASVには同じIFF・空席ありの場合に乗客として同乗する。同乗中のBackspaceは乗客本人の脱出であり、操縦者や走行を停止させない。

機体の外側カメラでも、←／→・A/Dで車体を旋回して進行方向を変え、W/Sで前後の出力を操作し、↑／↓で上下を向く。旋回時は砲塔・上半身も車体と同じ角度だけ回り、車体に対する相対角度を維持する。←／→は砲塔・上半身だけを独立して旋回させず、車体の進行方向を変える。↑／↓の上下照準は外部カメラの上下の向きにも反映する。PageUp／PageDownは上下照準、右ドラッグは独立した照準操作。Cの外側カメラは機体・人の現在の向きと位置に追従し、旋回中も常に真後ろから表示する。VISOM誘導中は従来どおり矢印キーでミサイルを操縦する。


## 移動ができなくなる割り当ての修正（2026-10-24）

最新のユーザー指定により、通常の機内・徒歩操作は↑で上、↓で下を向く。前後移動はW/Sで行い、機体は出力と慣性を持つため、Sを押し続けると減速してから後退する。以前の保存設定で↑／↓が前後移動に割り当てられていた場合は移行し、射撃などの有効なカスタム設定は保持する。

HAWC・ASVの外部視点でも、←／→・A/Dが車体旋回、W/Sが前後移動、↑／↓が上下の照準・視線移動となる。砲塔・上半身だけの独立旋回にはしない。VISOM視点の矢印操作は手動誘導へ送り、発射元の車体は動かさない。

| 1 | 左zWASP | 800 |

## 選択した無人機への搭乗手順（2026-10-24）

Qで照準内の無人機を選ぶか、Tabで対象を切り替える。3-3では、続けてF2→F4でキリー、F3→F4でターン、F4→F4でシェリダンへ搭乗を命じる。G／通信ボタンから宛先と命令を画面で選んでも同じ処理を使う。全員へのF1→F4は、無人機の操縦席を最初に予約できた1人だけが受理する。複数機への乗り換えは、機体と仲間をそれぞれ選んで送る。

F7で搭乗先への移動を中止し、予約を解除する。搭乗後は同じ人物へのF5で追従、F1で攻撃、F7で停止、F6で降機を指示できる。選択した機体と、搭乗を命じる仲間の区別を維持する。

## ミッション開始前の操作（2026-10-24）

起動時は3-3の開始前画面を表示する。下部の任務選択で対象を選び、右上の「LAUNCH」をクリックして開始する。Tabでボタンへ移動してEnter／Spaceでも開始できる。開始前のB・P・Escでは任務へ進まず、設定から戻った場合も「LAUNCH」を待つ。項目をクリックして説明を確認できる。表示内容と任務中の地図との違いは[任務地図の仕様](../gameplay/mission-map-and-waypoints.md#ミッション開始前の画面2026-10-24)を参照する。

設定画面ではEscまたはBackspaceで、変更を保存せず元の画面へ戻る。キー割り当ての受付中はEscで受付を取り消し、設定画面に留まる。開始前から開いた設定を閉じても任務は開始しない。


通常画面の最初のF2はキリー、F3はターン、F4は任務ごとのシェリダンまたはウィルキンス、F1は全員を宛先にする。続くF5は送信時の選択目標へ移動・追従し、未選択ならプレイヤーへ追従する。詳しくは[通信仕様](../gameplay/iff-and-communications.md#宛先キーとf5の整理2026-10-24)を参照。

Scorp ASVのミサイルは、武器3のSREMが左、武器4のUNKPAが右から発射される。左右は機体の照準方向を基準にし、砲塔を旋回しても入れ替わらない。


## IFF画面での変更・リセット（2026-10-24）

画面下の「IFF」を押し、0〜7の4桁を入力して「適用」で変更する。「初期コードに戻す」で現在の任務の開始コードへ戻る。操縦中の機体とプレイヤーに適用し、徒歩・同乗中はプレイヤーだけを変更する。仲間や周囲の機体のIFFは変更しない。既存のU・I・Oによる桁変更とPの一時停止は維持し、4桁すべての入力とリセットにはIFF画面を使う。


## 上下キーとセンター（2026-10-24）

| 操作 | 動作 |
| --- | --- |
| ↑ | 上を向く。押している間だけ角度を増やし、離した角度で保持する |
| ↓ | 下を向く。押している間だけ角度を下げ、離した角度で保持する |
| センター（初期キーSpace） | 上下を水平へ戻し、機体の照準を車体正面へ戻す |
| W/S | 前後移動・出力調整 |
| ←／→・A/D | 車体または徒歩の左右旋回 |

↑／↓だけでは前後移動を始めず、出力を変更しない。すでに移動している機体の出力や慣性は維持する。徒歩・機内・外部斜め・外部後方で同じ上下操作を使い、外部カメラも上下の角度へ追従する。PageUp／PageDownと有効な上下照準のカスタムキーも維持する。古い↑／↓の前後移動設定は移行し、他の射撃キーなどを初期化しない。

センターは停止ではなく、出力・位置・選択対象を維持し、上下角と照準のひねりを戻して追尾照準を解除する。VISOM誘導中は既存の矢印キーによるミサイル操縦を維持し、Spaceは機体ビューへの復帰として使う。


Qは遮蔽物越しの目標も選択できる。照準付近の判定は左右各12度・上下各8度、距離800m以内とし、複数の候補では照準中心に近い対象を優先する。選択できても、遮蔽物越しに弾が届いたりロックが成立したりするわけではない。F2〜F4で個別宛先を開くと、任務ごとの人物名を音声で呼ぶ。字幕は出さない。F5追従の迂回と呼びかけは[通信仕様](../gameplay/iff-and-communications.md#f5追従の遮蔽物迂回2026-10-24)を参照。

## 司令部・地雷原コントロール設備の選択（2026-10-24）

施設もQの照準付近選択、Tab／Shift+Tabの順送り・逆送り、Eの近い敵対対象の選択に含める。司令部を選ぶと左下に建物ホログラムと名称・距離を表示する。施設も無人かつ進入保護がなければFで入れる。施設への味方の攻撃命令は未実装のため受理しない。Bの地図では選択中の施設を強調表示する。

## Qの空振りで選択解除（2026-10-24）

全任務共通で、照準付近に選択候補がない状態でQを押すと、現在の目標を未選択へ戻す。追尾照準も解除し、ホログラム・選択枠・目標情報を消す。対象が機体・歩兵・施設のどれでも同じ動作とし、Qの「目標選択」の操作音声は維持する。

## 射撃キーの長押し（2026-10-24）

1〜4の武器キーとマウスは、長押しで攻撃を続けられる。通常の長押しの最短間隔は試作値0.5秒。武器本来の発射間隔、弾数、エネルギーとレーザー充填も判定し、高速な無制限連射は行わない。離せば停止し、押し直しても武器本来の発射間隔は無視できない。カスタムキーにも適用する。

レーザーの長押しでは通常は充填完了を待ち、Scorp Assault・Darken Tactical Defense・Merc Assault・Union Assault HAWCだけを例外とする。4機種のモデル・性能は未登録。詳細は[共通武器仕様](../gameplay/weapons-and-missile-camera.md#長押し射撃と高速連射の制限確定仕様2026-10-24)を参照。


開始メニューのEXITでは「よろしいですか？」の確認後、Yでタブの終了を要求する。N・Esc・Backspaceでメニューへ戻る。ブラウザがタブ終了を許可しない場合は、Ctrl+W（Macは⌘W）の案内を表示する。任務中の中断確認とは別の処理とする。


味方の複数搭乗機へ接触すると、空席があれば乗客として自動で搭乗する。乗客状態のゲーム操作は脱出キーだけを受け付け、操縦・射撃・照準・通信命令・IFF変更は行えない。一時停止と設定画面は利用できる。詳細は[複数搭乗機への接触](../gameplay/infantry.md#複数搭乗機への接触確定仕様2026-10-24)を参照する。

## 建物への進入・退出（2026-10-24）

Fは機体と建物の共通の進入操作とする。無人の建物は壁から4m未満で候補になり、距離順に選ぶ。シールドジェネレーターによる保護中は案内を表示して入らず、スイープタレットは常に禁止する。建物へ入った直後は施設内の一人称視点にし、Backspaceで建物の外へ退出する。施設内では徒歩の移動・射撃入力を受け付けない。


## HAWC共通の横方向の視点速度（2026-10-29）

Merc Assault HAWCの視点移動がまだ遅いというユーザーの指摘と、全HAWCで横方向の速度を共通にする指定を反映した。現行のUnion・Merc・ScorpのSentry／Tactical、Merc Assault、Merc Cruiserは、左右キーを1.5rad/秒、右ドラッグの横方向を感度設定1で1pxあたり0.005radに統一する。Merc Assaultの直前の設定に対し、キー操作は約1.67倍、マウスの横方向は約1.33倍となる。原作の実測値ではなく、共通の操作調整値として扱う。

右ドラッグで上半身の可動範囲を超える分は車体の向きへ反映し、視点が途中で止まらないようにする。上半身が固定されたHAWCは車体ごと向きを変える。上半身の左右限界は機体定義を使い、移動入力なしで前進させない。

上下方向は既存の設定を使う。Merc Assaultは上下キー0.825rad/秒・右ドラッグ縦方向0.00375rad/px、他のHAWCは0.55rad/秒・0.0025rad/pxとする。Scorp ASVは2026-10-30の追加指定により、HAWCと同じ横方向の設定を使う。Union ASV・AIP・タワー・徒歩・ミサイル誘導は既存の操作設定を維持する。


## Scorp ASVの横方向とC視点の距離（2026-10-30）

ユーザー指定により、Scorp ASVの左右キーを0.6rad/秒から1.5rad/秒、右ドラッグの横方向を0.0025rad/pxから0.005rad/pxへ変更した。感度設定1でHAWCと同じ応答になる。左右キーは車体の旋回、右ドラッグは照準の旋回として従来の役割を保つ。機内・外部視点とも同じ操作速度を使う。前後の最高速度、上下の視点速度は変更しない。

Cの後方カメラは、徒歩・搭乗・同乗の距離を従来の1.25倍にする。通常の機体は後方16mから20m、徒歩は5mから6.25m、3-3の任務指定は24mから30mとなる。カメラの高さと注視点、真後ろへの追従は保ち、Zの斜めカメラと一人称・VISOM視点の距離は変更しない。速度と倍率はユーザーの操作感に合わせた試作値。
