# 原作画像からの機体外観再現

機体の外観は、部品の数や装飾より先に、部品同士の接続、全体の輪郭、姿勢を合わせる。原作で見えない内部構造や寸法は確定値にしない。機種ごとの観察結果と仮値は `docs/reference/vehicles/` の該当資料へ残す。

## 1. 画像と姿勢をそろえる

1. 同じ機種の画像を選び、前・横・後・上の方向、外観・機内・ホログラム、停止中・歩行中を区別する。別方向の画像を一枚の投影図として扱わない。
2. 原作と現行モデルを同じ方向、近い画角、同じ姿勢で並べる。透視の差が大きければ、輪郭を比較しやすい固定カメラでも描画する。歩行中の一枚から停止姿勢を決めない。
3. 画像上で頭、中央胴体、左右の武器、腰、股、膝、足の中心と外端を確認する。全高または胴体幅を基準に比率を記録する。透視で変わる見かけの長さは実寸と区別する。

同じ方向の画像ごとに、基準の長さと、ずれが目立つ目印の画素位置を記録する。例えば正面なら「機体の左右端間を1」とし、頭頂の高さ、左右ポッドの内端と外端、股の中心をその幅に対する比率で表す。修正前後の現行画像でも同じ目印を測り、原作との差が縮んだか確かめる。輪郭が隠れる目印は測定値を作らず「見えない」と書く。画角や姿勢が違う画像の比率をそのまま実寸の差と扱わない。

記録は「方向・姿勢／基準の両端／目印／原作の比率／修正前の比率／修正後の比率／根拠画像」でそろえる。画像ごとに基準の両端を測り直し、同じ部位を比較する。

比較画像には機種、方向、カメラ位置、注視点、視野角、画面サイズ、機体の姿勢を対応づける。描画スクリプトは PNG と同名の JSON に撮影条件を保存する。原作に近い視点が必要ならカメラ設定ファイルで該当方向を上書きし、修正前後に同じ設定を使う。原作の正確なカメラ値が不明な場合は、近似視点であることを記録する。

## 2. 接続を先に決める

中央胴体から左右の武器・肩へ、胴体から腰と股へ、股から膝・足へ、原作で見えるつながりを確認する。部位の親子関係は動きの階層であり、画面上の隙間を埋める形状ではない。原作で連続して見える部位の間には、位置と太さを合わせた支持材や装甲を描く。

支持材は、動く側と固定側のどちらに属するか決める。上半身が旋回・前傾する機体では、肩の支持材を上半身、股の接続を脚や腰の動きに対応する節へ置き、停止・旋回・歩行時に分離や不自然な貫通が起きないか見る。原作で隙間が見える場所は埋めない。

## 3. 輪郭から細部へ進める

1. 前・横・後の画像で、全高、左右幅、頭とポッドの高さ、胴体の厚み、脚の折れ方と足の接地を比べる。まず目立つ差を一つずつ直す。
2. 中央と左右、上半身と脚の接続を各方向から確認する。側面の前傾や歩行姿勢で隠れる形状は、別方向の画像も使って判断する。
3. 大きな形状が合ってから、面取り、模様、配色、銃口などの細部を合わせる。細部の追加で輪郭や接続の欠落を隠さない。

比較記録は「部位／原作で確認できる形と目印の比率／現行の差／根拠画像と方向／修正後の確認」の単位で残す。見えない方向や不鮮明な箇所は未確認とし、必要な仮形状を原作の確定形状として記さない。

## 4. 完了を確認する

修正前後を同じ条件で描画し、少なくとも変更した部位が見える方向で比較する。接続の修正では停止状態に加え、該当する旋回・前傾・歩行状態も見る。構造テストでは部位の所属、関節、命中領域、砲口などを確認し、見た目の一致は画像で確認する。

既存テストが旧形状の欠落や仮の輪郭を前提にしている場合は、原作画像で確認した形状に合わせて更新する。テストが通るだけで外観が合ったとは判断しない。画像から判断できない差は、推測で埋めずに残す。
