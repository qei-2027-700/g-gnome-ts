## 起動

Node.js 22.18以降を使用する。以下はプロジェクトのルートで実行する。

```sh
cd g_nome
npm install
npm run dev -- --port 5173
```

起動後、`http://127.0.0.1:5173` を開く。この作業環境には依存パッケージを配置済みなので、同じワークスペースでは `npm run dev -- --port 5173` から試せる。

```sh
npm test
npm run build
npm run preview -- --port 4173
```

ビルド結果は `dist/`。このディレクトリを静的ホスティングへ配置できる。`file://` でHTMLを直接開く方式には対応しない。サーバー側のゲーム処理やデータベースは不要。

## 遊び方

任務開始後、正面のUnion SentryへWで近づくと自動搭乗する。機体ではW/Sで指令出力を上げ下げし、キーを離しても出力を維持する。A/Dで旋回、Enter／Returnで停止、左Shiftで出力全開。

| 操作 | 初期キー・画面操作 |
| --- | --- |
| 機体のFLECH / FIL-30 | 1 / 2を長押し。左クリックは武器1 |
| 歩兵のPRIF44 / GASHR | 1 / 2。GASHRは初期5発、有人のMerc機へ命中すると敵兵を射出 |
| 胴体に対する照準旋回 | 右ボタンを押しながら左右へドラッグ |
| 照準内の目標 / 最寄りの敵 / 追尾照準 | Q / E / T |
| 次／前の対象・解除 | Tab／Shift＋Tab。左Holoの×で解除。Ctrl＋Tabはブラウザ側の操作が優先される場合がある |
| 旋回 / 上下の視線 | ←／→ / ↑／↓ |
| 停止 | テンキーEnter、通常のEnter／Return。音声「停止します」のみで字幕なし |
| 照準をセンターへ | Space。上下角と胴体のひねりを正面へ戻す。出力・目標選択は維持し、自動追尾を解除 |

| 歩兵の姿勢 | J：立つ／伏せる |
| 任務地図 / ウェイポイント表示 | B / R。初期は未選択。RでWP1→非表示を切り替える |

キーは設定画面で変更し、端末内に保存する。U/I/O/Xは固定操作として予約している。Zの初期割り当ては斜めビュー。macOSでは物理キーの`Backspace`コードが降機に対応する。OS側のFキー設定に依存しないよう、通信は画面からも開ける。実機でのWindows・macOS両方の操作確認は未実施。

WP1への到達とMerc2部隊の排除で成功。機体の破壊、またはその機体から脱出した兵士の排除で部隊を数える。自機が破壊されても主人公は脱出して任務を続行し、主人公の体力がゼロになると失敗。成功・失敗・中断では結果文字と上下の扉を表示し、同じ任務の出撃前メニューへ戻る。任務状態は初期化され、再出撃できる。

## 実装したもの

徒歩開始、Union Sentryへの搭乗・降機、3視点、機体の脚の動きと胴体旋回、速度差、出力維持、停止を実装した。Union Sentryの最高速度70 km/h、Merc Sentryの85 km/h、Merc Tactical Defenseの72 km/hなど、資料の諸元と仮の調整値を分けている。

射撃、銃口の発光・機体の反動・赤い曳光弾・立体レーザー、残弾・エネルギー消費、シールドと装甲、遮蔽物による射線遮断、被弾表示、敵の索敵・接近・移動・攻撃、レーダー、IFF変更、任務地図、ウェイポイント、勝敗と再挑戦を接続した。初期IFFはユーザー指定の`2620`。IFFの識別結果はレーダーと敵の攻撃可否で共有する。

Easy・Medium・Hardの3段階を用意し、初期値はEasy。難易度変更は次の任務開始から適用する。設定画面・確認画面の表示中と、タブが非表示・非アクティブの間はゲーム処理を停止する。

SEはWeb Audioの合成音。搭乗時の機体名、出力全開、損傷警告、中断確認、任務結果はOSの音声合成で案内する。操作音声の字幕は表示しない。若い声と厳粛な声のプロフィールを分けているが、OSが提供する声によっては女性の声や声質の違いを保証できない。日本語と英語の切り替えを用意した。原作音源は同梱せず、手元のBGMファイルを端末内で読み込める。

## 索敵と敵のミサイル（2026-10-23更新）

最初の敵は開始地点から約187mにいる。以前は索敵距離190mだったため、任務開始直後にこちらを発見していた。索敵距離をMerc Sentryは125m、Merc Tactical Defenseは145mとし、障害物で射線が遮られる場合は発見しない条件に変更した。初期位置と搭乗直後の位置では待機しても反応せず、最初の敵には搭乗後さらに正面へ約45m接近すると発見される。先に敵へ攻撃を当てた場合は距離にかかわらず警戒に移る。

Merc SentryはCHUMを1発、Merc Tactical DefenseはSAG5Tを2発発射する。ミサイル攻撃と、SentryのRAID／Tactical DefenseのDASYによる射撃を交互に行う。ミサイルには弾体・噴射炎・煙跡・着弾時の発光と煙を付け、発射音と着弾音を分けた。銃口の発光、上半身の反動、自機の射撃・被弾時の小さな視点の揺れも加えた。

ミサイルのダメージは発射時には与えず、飛行後の衝突時に与える。発射時点の位置へ向かう非誘導弾なので、移動して回避できる。フレーム間で弾が対象を通り抜けないよう、移動区間全体で最初の衝突を判定する。一時停止中は飛翔と演出も停止し、再挑戦時に消去する。

索敵距離、ミサイル速度（CHUM 85m/s、SAG5T 100m/s）、命中半径、威力、交互射撃の順序は試作の調整値。原作の数値・発射順序を確認済みとするものではない。原作の武器名と仮の挙動を分けて扱う。

## 目標表示・停止音声・矢印キー（2026-10-23更新）

Qで照準内の対象を選択し、Eで最寄りの敵を選択する。目標が未選択のときに攻撃が命中した場合は、生存している命中対象を自動選択する。別の目標を選択済みなら、その選択を維持する。この処理はGAUSを含む全武器、歩兵・機体・施設への命中に共通とし、命中後も対象が生存・残存している場合に選択する。[共通仕様](../gameplay/cockpit-hud.md#命中時の自動目標選択共通仕様2026-10-30)を参照。以前のEは敵を順送りする動作だったため修正した。Tabで次の機体、Shift＋Tabで前の機体を選ぶ。解除は左のHoloにある×ボタンでも行える。

選択対象に黄色い照準マークを重ね、画面外にいる場合は左右の黄色い矢印を表示する。中央照準は、選択対象に照準が合うと黄色、射線が通り射程内に入ると赤へ変わる。距離は目標の選択中、ロック成立に関係なく照準付近へ表示する。レーダーの選択対象も黄色で表示する。

左Holoには選択した機種に応じた機体の図とシールドバーを表示し、機体名・距離・残シールドを更新する。シールドと装甲の減少に応じて緑・黄・赤に変える。部位ごとに色を変える実装へ更新した。原作の部位耐久値・内部システムの故障は未再現。元の右側の自機表示を左側へ単に複製せず、3機種それぞれの図を用意した。

停止入力は出力ゼロとし、押下1回につき「停止します」を1回案内する。ユーザー指定により、この音声には字幕を付けない。原作のテンキーEnterと、テンキーのない端末向けの通常Enter／Returnで停止できる。Spaceはセンター操作へ修正し、以前の保存設定も移行する。音声は引き続きOSの合成音声であり、原作の録音ではない。

←／→は左右の旋回、↑／↓は上下の視線移動に対応する。W/Sの出力調整とA/Dの旋回も維持する。視線は射撃とQの選択判定へ反映し、Tの追尾照準は上下にも追従する。↑で上、↓で下を向く配置はWeb版の操作。マニュアル掲載の武器ピッチは↑で下、↓で上のため、原作と同じキー配置の完全再現とは区別する。

ユーザー提供の画面で、HUDは表示される一方、窓外が単色になる不具合を確認した。描画モジュールの登録と基本シェーダーを最初のフレームより前に読み込む対処を追加し、シェーダーエラーは画面に表示するようにした。地形が描画処理へ到達することと、3視点で対象の画面座標が得られることをNullEngineで検証した。実ブラウザでの原因特定と改善確認は未実施。

## 難易度による性能補正の廃止（2026-10-23）

Easy・Medium・Hardで機体の速度と攻撃威力は共通にする。敵ミサイル・レーザー・機関銃・歩兵射撃から難易度の威力倍率を削除し、Merc Sentryの近距離速度85%という仮補正も削除した。全3難易度の速度・加速・各攻撃のダメージを比較するテストを追加した。敵AIの攻撃間隔には未確認の難易度別仮値が残る。[設定と基本性能](../gameplay/settings.md)を参照。

変更は再編後の`src/game/content/`・`src/game/simulation/`へ反映した。ファイルを旧構成へ戻していない。

## 原作の速度値との照合（2026-10-23）

Merc Tactical Defenseは原作英語マニュアル本文p.51の72km/hに合わせる。設定値だけでなく実移動も照合し、AIの18%速度補正を削除した。これまでの実質12.96km/hから、無損傷で障害物のない走行時は72km/hまで加速する。原作と数値を一致させるというユーザー方針を記録し、未測定の加速時間・装甲耐久・射程などを一致済みとは扱わない。

## 走行アニメーション（2026-10-23）

脚全体を固定周期で振る方式を改め、実際に移動した距離から歩調を計算する。速度が上がるほど足の踏み替えが速くなり、膝の曲げ伸ばし・遊脚の持ち上げ・足首の角度補正・前傾・左右の小さな揺れを加える。接地の踏み替えで砂煙を出す。停止・機体同士の衝突で移動が止まれば走る動作も収まり、ポーズ中はアニメーションと砂煙の時間が進まない。

ユーザー指定によりMerc SentryとMerc Tactical Defenseは走行中に軽く上下する。Sentryは速い足運びと大きめの脚上げ、Tactical Defenseは低速でも分かる重い上下動を付けた。機内カメラにも歩調に合う小さな上下動を反映する。機体の最高速度・加速・武器の性能はこの演出変更では変更していない。

歩調・前傾・上下動は試作の調整値であり、原作映像から測定したアニメーションではない。実ブラウザでの見た目は未確認。

## 機体同士の衝突とSentryの配色（2026-10-23）

機体の移動経路に他の機体があれば、接触する位置で移動を止める。高速移動・後退・敵AIにも同じ判定を適用し、無人機・味方機・破壊された機体も障害物として扱う。接触で速度はゼロになるが、出力指示は保持する。接触相手から離れる方向への移動は可能。歩兵の踏みつぶし判定は既存の処理を使う。

現在は各機体の大きさに合わせた水平面の円で衝突を判定する。半径はSentryが3.5m、Merc Tactical Defenseが4.1mの仮値。原作の形状を忠実に再現した接触面ではなく、近接時に多少余裕を持って止まる。接触ダメージや押し合いは実装していない。

ユーザーの訂正により、Union Sentryはグレーの装甲と赤い武装ポッド・すね、Merc Sentryは濃い青の装甲と黒いコックピット周りへ変更した。赤い部分の配置と色コードは試作の仮設定。ユーザー指定の配色と原作資料は[デザイン資料](../reference/vehicles/union-sentry/README.md)に記録した。実ブラウザでの外観確認は未実施。

## 発進時の加速と通信開始（2026-10-23）

全速を指示しても、その瞬間に最高速度にはならない。プレイヤー機にあった加速処理を敵機にも共通化し、停止から徐々に速度を上げる。全速指示後、最高速度の約99%に達するまで約2.6秒という試作の仮設定で、実際の原作の加速時間は未測定。通常の出力操作では出力上昇自体にも時間がかかる。部位損傷による最高速度の低下も維持する。

F1・G・画面の通信ボタンで通信パネルを開くと、女性ボイス2（`solemn`）で「通信」と読み上げる。英語では「Communications」。字幕は表示しない。ブラウザでの実聴は未確認。

## 敵機体の耐久調整（2026-10-23）

ユーザー指定で敵機体の装甲耐久の基準値を20%増やした。Merc Sentryは70から84、Merc Tactical Defenseは120から144へ変更し、各部位の耐久も同じ割合で増える。同じ部位への集中攻撃による破壊判定を維持する。この数値は試作の調整値であり、原作の確認済み数値ではない。

## 3D機体の損傷表示（2026-10-23）

コクピットのホログラムと実際の3D機体で、同じ6部位の損傷値を使う。自機・敵機とも、損傷した部位の残存耐久が60%以下なら鮮やかな黄色（`#ffe000`）、25%以下なら純赤（`#ff0000`）にする。コクピットのホログラムも同じ色を使う。軽傷時は元の塗装を少し暗くし、部位の耐久が30%未満なら、その部位から煙が出る。被弾直後は該当部位だけが短く発光する。シールドで防いだ攻撃では、部位の損傷色は進まない。

各部位に独立した材質を持たせ、片脚の損傷が反対の脚や別機体へ波及しないようにした。煙は部位の位置と旋回に追従し、ポーズ中は進まない。再挑戦で損傷表示・煙を初期化する。この損傷色・煙は、ユーザー指定に基づき視認性を高める試作表現で、原作と同一の演出と確認できたものではない。

部位への集中攻撃は損傷を蓄積し、部位耐久が尽きた時点で機体を破壊する。全身の合計ダメージによる破壊判定を廃止し、別の部位への分散攻撃では破壊が遅くなる。[部位と破壊の仕様](../gameplay/cockpit-hud.md)を参照。

レーザー・損傷表示・部位破壊の変更後は`npm test`で70件成功、`npm run build`も成功。ログは`.artifacts/test.log`・`.artifacts/build.log`。Computer Useは停止を維持しており、実ブラウザでの見た目・GPU描画は未確認。

## 部位・任務地図・充填・駆動音・ウェイポイント（2026-10-23更新）

自機と敵機の両方に、本体・コックピット・左右の武装・左右の脚の6部位の損傷状態を持たせた。射撃とミサイルの移動区間を部位ごとの当たり判定に照合し、最初に接触した部位へダメージを反映する。自機と目標のHoloは、該当部分だけを緑・黄・赤に変える。シールドで防いだ分は部位の損傷に加えず、シールドが回復しても部位は修復しない。部位耐久値と当たり判定の寸法は試作値。全体装甲も維持し、脚の損傷は最高速度へ反映する。その他の部位ごとの機能故障は未実装。

Bの任務地図はポーズにしない。開いている間も現在の出力で移動し、敵の索敵・攻撃、ミサイル、被弾、充填が進む。地図の現在位置も更新する。モーダルの入力を操縦・射撃へ送ることは避け、設定・Pによるポーズ・非アクティブ時は停止する。

左上のレーザー武器には充填ゲージを表示する。発射で空になり、停止時より走行中の回復が遅くなる。未充填でも発射できるが、充填率に応じて射程が短くなる。搭乗機の搭載武器に応じてゲージの行を切り替える。FIL-30とRAIDは共通処理を使い、敵のRAIDにも射程制限を適用する。残エネルギーが足りなければ撃てない。回復速度・射程の仮値は[レーザー充填仕様](../gameplay/weapons-and-missile-camera.md)を参照。

機内ビューの搭乗中は、搭乗時の一度だけの効果音とは別に、駆動・エンジンの連続音を鳴らす。Union Sentry、Merc Sentry、Merc Tactical Defenseで基音・倍音・フィルターを分け、速度と指令出力に応じて音程・音量を変える。停止中も低い待機音を残し、降機・C/Zの外部ビュー・ポーズ・任務終了で消音する。機内へ戻ると再開し、機内のBの地図中は継続する。SE設定に連動し、初期音量は射撃音より控えめに設定した。原作録音ではなくWeb Audioの合成音で、実際の聞こえ方は未確認。

初期はウェイポイント未選択とする。RでWP1、次のRで非表示へ切り替える。WP1を選択すると、女性の合成音声で「第一ウェイポイント」と案内する。HUDは目的地の画面座標へ数字「1」を表示し、距離を併記する。画面外なら左右の向きを示し、外部ビューでは非表示。原作の音声・マークの形状・表示タイミングの完全な照合は未完了。

## 敵の検知ランプと距離表示（2026-10-23更新）

全機種共通のPINGランプをコックピットへ追加した。敵対する生存中の敵がプレイヤーを発見し警戒している間、赤く点滅する。敵の撃破・無人化・IFFの変化を反映し、自機は判定に含めない。外部ビューでは非表示、ポーズ中は点滅も停止する。目標選択中の距離は、ロック成立時だけでなく常時、中央照準付近にも表示する。

## 歩兵武器・脱出・脚の速度・視点（2026-10-23更新）

歩兵の1はPRIF44（射程150m）、2はGASHR（ガスアサルトショックライフル、射程100m・初期5発）。PRIF44は通常の射撃として機体・脱出兵へ作用する。PRIF44の弾数は資料で未確定のため、試作では弾数制限なし・再発射間隔ありとした。GASHRは飛翔するガス弾と着弾時の雲で表現し、有人のMerc機へ命中すると搭乗者を射出する。シールド残量にかかわらず強制降機し、機体の装甲・シールドを削らない処理は、今回のユーザー指定に基づく簡略仕様。

脱出した敵兵は別の実体として生存し、着地後に逃走・反撃する。無人機は停止し、主人公が搭乗できる。乗降で歩兵のGASHR弾数や機体の損傷を補充しない。外れ・射程外・遮蔽物・空の機体への命中で兵士を生成せず、連続命中で同じ搭乗者を重複生成しない。脱出兵を倒した場合も、そのMerc部隊を排除したと判定する。

Backspaceによる機体脱出では女性音声「脱出」を流し、コックピット付近から上昇し、横方向へ離れながら落下・着地する。空中では搭乗判定を行わない。地上へ静かに退出するモードは別に用意したが、建物・ミーゾンガードタワーなどの施設への出入り自体は未実装。

脚の損傷は自機・敵機の最高速度へ共通に反映する。係数は`0.2 + 0.8 × 左右脚の残耐久の平均`。無損傷100%、片脚が完全損傷で60%、両脚が完全損傷で20%とした。装甲だけ・武装だけの損傷では減速しない。原作の減速率は未確認で、この係数は試作値。

Cは後方ビューとの切り替え、Zは斜めビューとの切り替え。Cを繰り返しても斜めビューにはならない。歩兵でも自分の姿を外から眺められ、射出中もカメラが追従する。どちらも再度押すと一人称へ戻る。外部ビューではHUDと駆動音を消し、機内へ戻ると再表示・再開する。

Rの選択順はミッションのウェイポイント一覧を参照し、初期の未選択から番号順に選び、最後の次で非表示へ戻る。1-1は1か所なので、未選択→1→非表示となる。搭乗・降機では選択状態を維持し、再挑戦では未選択へ戻す。選択状態と到達・勝利判定は別に扱う。

射出の高さ・速度、兵士AI、GASHRの弾速、PRIF44の威力・再発射間隔は仮設定。実際のGPU表示・音声・操作は未確認。

## 歩兵の致死判定とMerc Sentryの挙動（2026-10-23更新）

敵の有人機との接触・踏みつけは歩兵を即死させる。立ち・伏せとIFFの一致にかかわらず判定し、無人機・破壊済み機体は除外する。相対的な移動区間と高さを使い、フレーム間の通り抜けを防ぎながら、射出されて機体より十分上にいる人物は平面位置だけで死亡させない。

CHUM・SAG5Tの直撃は、全難易度で歩兵を即死させる。プレイヤーだけでなく脱出した敵兵も同様。外れ・岩への着弾、通常銃撃のダメージ、搭乗中の装甲・シールド、GASHRの強制降機は区別する。接触後に操作を続けたり、任務失敗を重複発火したりしないことも確認した。

Merc Sentryの上半身は車体と独立して旋回し、可動範囲と旋回速度を敵AIにも反映する。銃口が対象へ向くまで射撃しない。移動時は最高速度85km/hまで加速し、近距離の85%補正は適用しない。足の損傷も速度に反映する。接触寸法・旋回速度は原作未実測の調整値。
