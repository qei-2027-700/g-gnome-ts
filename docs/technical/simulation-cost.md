# 密集した障害物と更新コスト

稜線や川の区画が多い任務で、経路探索と砲塔の射撃が1ティックに収まるための制約。到達距離などの探索パラメータは `allyRoute` が持ち、再探索の間隔は [IFF・通信・仲間への命令](../gameplay/iff-and-communications.md) が持つ。この文書へ秒数や距離は写さない。

## 経路探索

実装は `src/game/simulation/ally-navigation.ts` の `allyRoute`。味方の追従・攻撃移動と、地上を移動する敵が同じ関数を使う。

崖、川の区画、建物、山、岩はすべて探索の障害物になる。角をすべての角と結ぶと、稜線が密な任務では1回の探索が1ティックを超える。角は近くの角とだけ結び、同じ障害物の角どうしは結んだままにする。移動する側は全部の角を見られ、展開したどの角からも目標を見られる。探索が失敗しても、角を総当たりするグラフを重ねて探索しない。

`speed` が 0 以下の機体は経路を探索しない。照準と射撃は続ける。呼び出す側は `simulation.ts` の `navigateEnemy` と `maneuverAlly`。停止距離が 0 のときは、同じ目標点を何度も探索しない。

## 描画

`src/game/presentation/landscape.ts` の崖は、崖ごとにメッシュ・マテリアル・テクスチャを作る。メッシュ名と `terrainObstacle` は残す。ノイズは x、y、地形 seed だけを見るため、崖ごとのテクスチャは色を変えない。これは任務開始時から一定の描画コストで、敵が動き出す瞬間の停止とは別である。崖を増やすときは、テクスチャの解像度や枚数をさらに増やさない。メッシュはまとめない。

## 確認

敵が警戒し、移動または射撃を始める前後を、その任務のシミュレーションで進める。1ティックが止まらないこと。1-5は `src/game/simulation/missions.test.ts` が、ロケットタワーの交戦開始をまたぐティック時間を固定する。上限の値はそのテストが持ち、フレーム時間の目標ではない。

ブラウザのフレーム時間はこのテストでは確認しない。
