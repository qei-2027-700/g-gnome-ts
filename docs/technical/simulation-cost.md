# 密集した障害物と更新コスト

稜線や川の区画が多い任務で、経路探索と砲塔の射撃が1ティックに収まるための制約。到達距離などの探索パラメータは `allyRoute` が持ち、再探索の間隔は [IFF・通信・仲間への命令](../gameplay/iff-and-communications.md) が持つ。この文書へ秒数や距離は写さない。

## 経路探索

実装は `src/game/simulation/ally-navigation.ts` の `allyRoute`。味方の追従・攻撃移動と、地上を移動する敵が同じ関数を使う。

崖、川の区画、建物、山、岩はすべて探索の障害物になる。`surface` が `deck` の高台は探索の障害物にせず、崖ごとのテクスチャも作らない。角をすべての角と結ぶと、稜線が密な任務では1回の探索が1ティックを超える。角は近くの角とだけ結び、同じ障害物の角どうしは結んだままにする。移動する側は全部の角を見られ、展開したどの角からも目標を見られる。探索が失敗しても、角を総当たりするグラフを重ねて探索しない。線分が障害物に当たるかは、その線分が通る区画の障害物だけを見る。当たる相手と通れる経路は変えない。

敵機が施設の周囲に複数の攻撃位置を持つ場合は、候補ごとに障害物の経路網を作り直さず、一つの探索で到達できる候補を選ぶ。4-2の交戦中に同じ更新で多数の候補を順に探索すると、1ティックが長く止まるため。

`speed` が 0 以下の機体は経路を探索しない。照準と射撃は続ける。呼び出す側は `simulation.ts` の `navigateEnemy` と `maneuverAlly`。停止距離が 0 のときは、同じ目標点を何度も探索しない。

## 描画

`src/game/presentation/landscape.ts` の崖は、崖ごとにメッシュ・マテリアル・テクスチャを作る。メッシュ名と `terrainObstacle` は残す。ノイズは x、y、地形 seed だけを見るため、崖ごとのテクスチャは色を変えない。これは任務開始時から一定の描画コストで、敵が動き出す瞬間の停止とは別である。崖を増やすときは、テクスチャの解像度や枚数をさらに増やさない。崖のメッシュはまとめない。尾根の楕円が多いときは、山の描画を1メッシュにまとめ、格子を粗くする。移動と射線に使う楕円は山ごとに残す。射線、弾、移動は、線分が届き得る楕円だけを同じ高さの式で判定する。届かない楕円を候補から外すだけで、山の高さも接地面も変えない。

## 確認

敵が警戒し、移動または射撃を始める前後を、その任務のシミュレーションで進める。1ティックが止まらないこと。1-5は `src/game/simulation/missions.test.ts` が、ロケットタワーの交戦開始をまたぐティック時間を固定する。上限の値はそのテストが持ち、フレーム時間の目標ではない。

ブラウザのフレーム時間はこのテストでは確認しない。
